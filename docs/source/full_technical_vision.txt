我正在设计一个面向具身智能的视觉空间记忆方法。请严格按照下面的完整技术设想理解和表达，不要为了简化图示而省略关键模块。

# 一、研究背景与核心问题

目前很多具身智能或视觉世界模型更偏向于：

* 当前帧物体识别；
* 静态环境导航；
* 固定 patch / voxel / BEV 表示；
* 或直接基于连续帧预测 latent dynamics。

我希望进一步研究：

**机器人在真实动态室内环境中，如何建立一种长期稳定的结构化空间记忆，使短暂出现的行人、遮挡以及机器人自身转向不会破坏已经形成的环境认知。**

核心思想不是恢复干净 RGB，也不是把每一帧都完整保存下来，而是：

> 将当前视觉 observation 转化为具有几何意义的 latent representation，并将这些观测持续关联到世界中的长期结构记忆。

整体目标可以概括为：

**Geometry-Aligned / Pose-Aware Persistent Latent Memory**

即：

> 透视与视觉结构负责组织“当前看到了什么”，而真正长期保存的是世界坐标中的结构和 latent memory。

---

# 二、最初的透视切分思想

以走廊为例。

普通 ViT 将图像分成固定正方形：

w1, w2, w3, ...

但这种规则 patch 与真实场景结构没有直接关系。

我的原始设想是利用：

* 消失点 Vanishing Point；
* 墙面边界；
* 地板边界；
* 天花板边界；
* 走廊结构线；
* 近、中、远关系；

把图像切分为具有空间和语义含义的区域。

例如：

* 左墙近；
* 左墙远；
* 地板近；
* 地板中；
* 地板远；
* 右墙近；
* 右墙远；
* 走廊尽头。

每一个区域不保存 RGB，而是保存一个 latent representation，例如来自 frozen DINOv2 patch features 的 pooling：

z_i = Pool(F_t | R_i)

其中：

F_t = DINOv2(I_t)

每个区域可以保存：

* Region ID；
* latent vector z；
* semantic label；
* geometry；
* static confidence；
* last seen timestamp；
* visibility；
* dynamic probability。

例如：

Region R4
semantic = right wall near
latent = z_284
static confidence = 0.97
last seen = t36

但是，**这种透视区域只能作为当前 observation representation，而不能直接成为长期 memory 的坐标系。**

# 三、机器人转弯暴露出的核心问题

机器人转弯时：

* 墙在图像中的位置变化；
* 门的位置变化；
* 地板区域变化；
* 原消失点移动；
* 原走廊的结构逐渐离开画面；
* 新走廊或新房间逐渐进入画面。

这并不意味着透视规律失效。

真正错误的是：

> 把一个固定的 Vanishing Point 和固定 Perspective Grid 当成整个世界长期不变的坐标系统。

因此不能设计：

if turning:
disable perspective
stop memory update

这样的简单规则。

机器人转弯时仍然可以获得非常有价值的信息。

事实上，转弯过程中的“旧结构和新结构同时可见”正是建立空间关系最有价值的时候。

因此应该升级成：

**当前图像是 Observation，世界结构才是 Memory。**

---

# 四、两层坐标体系

整个系统需要明确区分：

## Layer 1：Image / Observation Space

当前帧：

I_t

经过：

* DINOv2；
* Depth；
* structural line detection；
* vanishing directions；
* perspective analysis；
* segmentation；

得到当前帧的结构区域：

R_t^1, R_t^2, ..., R_t^N

这些区域回答：

> 当前这一帧我看到了什么？

它们可以随机器人转向不断改变。

它们不是长期 memory。

---

## Layer 2：World Structural Memory

真正长期保存：

M = {M_1, M_2, ..., M_K}

每个 memory slot 对应的是：

* 一个长期存在的 surface；
* object；
* door；
* wall；
* floor；
* corridor segment；
* topology；
* 或 dynamic entity。

例如：

M_wall_A:
latent = z
semantic = wall
world_position = ...
plane_normal = ...
static_confidence = 0.98
last_seen = t
visibility = ...
observation_count = ...

所以机器人转向后：

原来的 wall 不会变成另一个 wall。

只是：

wall 在当前 camera image 中的 projection 改变。

即：

World Slot 本身稳定；

Image Patch / Region 不稳定。

---

# 五、Frame-to-World Association

系统的关键不是：

w12(t) → w12(t+1)

而是：

Current Region
→ Geometry Registration
→ Persistent World Slot

例如：

t1 中椅子可能位于 image patch 37；

t20 中机器人靠近后位于 patch 129；

t50 中部分被遮挡；

t80 中重新出现于 patch 250。

长期 memory 中仍然应该是：

WorldSlot_chair

而不是：

chair_t1
chair_t20
chair_t80

---

# 六、机器人纯旋转时如何处理

如果机器人原地旋转，没有 translation：

camera rotation 为 R。

静态场景在两个 image frame 之间可以用 homography：

H = K R K^{-1}

其中：

K = camera intrinsic matrix
R = camera rotation
H = rotation-induced homography

因此上一帧中某个静态结构的位置可以根据机器人旋转预测到下一帧。

例如：

t 时门位于画面右侧；

机器人右转；

门在下一帧可能移动到画面左侧。

这不是环境变化。

而是 camera orientation 变化。

所以：

Memory_door 不应该改变。

只改变它在当前 frame 中的 projection。

---

# 七、机器人一边走一边转

真实移动机器人通常同时发生 rotation + translation。

因此使用完整 SE(3)：

T = (R, t)

对于当前像素 u：

如果有 depth D_t(u)，可以反投影：

X_t = D_t(u) K^{-1} u~

得到 camera coordinate 中的 3D point。

然后通过 camera motion：

X_{t+1} = R X_t + t

再重新投影：

u_{t+1} ~ K X_{t+1}

因此整体逻辑为：

Image Region
↓
Depth Backprojection
↓
3D Surface / World Slot
↓
Camera Motion
↓
Reprojection into New Frame

所以转弯并不应该禁用透视或记忆。

应该：

> 利用 pose 和 geometry 将旧 world memory 投影到新的 observation frame。

---

# 八、透视点不应该成为世界表示

Vanishing Point 是非常有用的 observation cue。

但不应该保存：

“这个走廊的 VP 永远位于 image center。”

应该保存世界中的 structural directions。

例如 Manhattan indoor scene 可以保存：

d_x
d_y
d_z

分别代表：

* 主要走廊方向；
* 横向墙面方向；
* 垂直方向。

这些方向属于世界。

当前 camera pose 为 R_t。

世界方向经过当前 camera projection 后，才产生这一帧的 vanishing point。

因此：

机器人转动时：

VP 会移动；

VP 甚至可以离开 image FOV；

但是 world structural direction 仍然存在。

所以应该从：

Vanishing Point
→ Partition
→ Memory

升级为：

World Structural Direction / Plane
→ Current Perspective Projection
→ Observation Partition

也就是说：

**VP 是观测线索，而不是长期 world representation。**

---

# 九、Local Structural Chart

对于简单直走廊，一个局部透视结构可能足够。

但是对于：

* 拐角；
* T 字路口；
* 房间；
* 门洞；
* 多走廊连接；
* 非规则室内区域；

不能强迫整个画面共享一个 VP 或一个 perspective grid。

因此引入：

**Local Structural Chart**

可以把整个环境看成多个局部结构坐标系统：

Chart A = Corridor A

包含：

* left wall；
* right wall；
* floor；
* doors；
* dominant direction d_A。

Chart B = Corridor B

包含：

* left wall；
* right wall；
* floor；
* doors；
* dominant direction d_B。

两个 chart 之间保存：

* relative pose；
* corner relationship；
* topology；
* connection type。

例如：

Chart A
|
| corner
|
Chart B

因此 world memory 可以表示成：

World Structural Memory
├── Chart A: Corridor A
├── Chart B: Corridor B
├── Chart C: Room
└── Topological Relations

---

# 十、机器人转弯时 Chart 不应该硬切换

机器人从 Corridor A 转到 Corridor B 时，不应该：

t1 = Chart A
t2 = switch
t3 = Chart B

而应该是连续混合：

t1:
100% evidence from Chart A

t2:
80% A + 20% B

t3:
50% A + 50% B

t4:
20% A + 80% B

t5:
100% B

因此转弯中的一帧可以同时给多个 chart 提供 evidence。

---

# 十一、转角中新结构如何形成

假设一帧同时看到：

* 原走廊墙；
* corner；
* 新走廊部分墙面；
* 新地板。

模型可以做：

Region R1
→ matches Chart A
confidence = 0.92

Region R2
→ matches known corner
confidence = 0.80

Region R3
→ does not match existing Chart A
→ candidate Chart B
confidence = 0.63

下一帧：

candidate Chart B confidence = 0.81

再下一帧：

confidence = 0.94

当满足：

* multi-frame consistency；
* geometry consistency；
* pose consistency；
* semantic consistency；

之后才把 candidate 建立成新的 persistent Local Structural Chart。

即：

candidate structure
→ multi-frame confirmation
→ persistent chart

这样新地图不是瞬间生成，而是逐渐确认。

---

# 十二、Ego-motion Compensation

另一个关键问题是：

机器人转弯时整个背景都会产生 optical flow。

如果直接把 optical flow 当作动态判断依据：

墙、地板、门都会看起来“在移动”。

因此需要：

**Ego-motion compensated motion**

系统同时获取：

* observed optical flow；
* camera pose；
* depth；
* camera intrinsics。

根据 robot ego-motion 预测静态世界理论上应该产生的 flow：

f_ego

实际观测 flow：

f_obs

然后：

f_residual = f_obs - f_ego

只有 residual motion 才更有可能来自真正的动态目标。

例如：

墙：

f_obs = 30
f_ego = 29

f_residual ≈ 1

说明：

墙没动，是机器人自己在转。

行人：

f_obs = 45
f_ego = 29

f_residual = 16

说明：

存在 camera motion 无法解释的额外运动。

于是该区域具有更高 dynamic probability。

---

# 十三、动态环境的双记忆结构

整个 memory 应该至少分成：

## Static Structural Memory

长期保存：

* wall；
* floor；
* door；
* table；
* corridor；
* room；
* topology；
* structural plane；
* stable object。

生命周期长。

---

## Dynamic / Transient Memory

保存：

* pedestrian；
* moving object；
* moving cart；
* temporary obstacle；
* movement direction；
* temporary occupancy。

生命周期短。

动态记忆可以随时间 decay：

c(t+Δt) = c(t)e^{-λΔt}

所以人走开以后：

dynamic occupancy 会自动减弱。

但是 static wall / door memory 不会消失。

---

# 十四、遮挡情况下的核心原则

例如：

t1：

door visible

→ static memory stores door

t2：

person walks in front of door

正确处理不是：

door → person

也不是必须做 RGB inpainting。

正确逻辑是：

Static Memory:
door remains

Dynamic Memory:
person temporarily occupies this region

因此：

**Occlusion means “no new static evidence”, not “the world disappeared”.**

也就是：

暂时看不到 ≠ 物体不存在。

这体现 object permanence / scene permanence。

---

# 十五、Memory Update 不能是硬开关

不要设计：

if turning:
don't update

也不要设计：

if occluded:
always freeze everything

应该对每一个 observation → memory association 使用 soft confidence。

定义：

α_ij =
C_assoc
× C_visibility
× (1 - P_dynamic)
× C_pose

其中：

C_assoc：
当前 region 与 world slot 的匹配置信度。

C_visibility：
该结构当前可见程度。

P_dynamic：
该 observation 属于动态目标的概率。

C_pose：
当前 robot pose / registration 的可靠度。

然后更新：

# M_j^{t+1}

(1 - α_ij) M_j^t
+
α_ij z_i^t

含义：

如果：

* structure match 强；
* visibility 高；
* dynamic probability 低；
* pose 非常可靠；

则：

α 高

可以大幅更新长期 memory。

---

如果机器人正在快速转弯：

C_pose 比较低；

墙只看到一点：

C_visibility 较低；

即使 latent match 很高：

α 仍然较小。

含义：

> 可以利用这一帧，但不要让一帧极端斜视 observation 强烈覆盖已有长期记忆。

---

如果完全被人挡住：

visibility ≈ 0

则：

α ≈ 0

因此：

M_new ≈ M_old

---

如果重新正面看到：

visibility ≈ 1
association ≈ 1
dynamic probability ≈ 0
pose reliability ≈ 1

则可以强力更新 memory。

---

# 十九、为什么不直接保存 RGB

目标不是生成视觉上漂亮的 scene reconstruction。

真正需要保存的是：

* object identity；
* geometry；
* spatial relation；
* structural semantics；
* visual latent；
* uncertainty；
* temporal state。

所以不一定需要 RGB decoder。

DINO latent 可以作为 representation。

如果需要知道：

“这个 latent 是什么？”

可以使用：

* semantic classifier；
* CLIP alignment；
* VLM semantic readout；
* semantic prototype matching。

因此：

latent ≠ RGB reconstruction

semantic readout ≠ decoder

# 二十一、核心研究问题

可以概括成：

**Can geometry-aligned, pose-aware latent memory preserve stable spatial knowledge under viewpoint changes, turning motion, dynamic occlusion and temporary disturbances better than image-centric patch memory?**

中文：

> 基于几何结构和机器人姿态对齐的 latent memory，能否在视角变化、机器人转弯、动态遮挡和临时干扰下，比固定图像 patch memory 更稳定地保持长期空间知识？

# 二十三、建议指标

不要只计算 next-frame prediction loss。

至少需要：

## Static Memory Retention

动态遮挡或机器人转弯之后：

原来的静态结构 latent 保持程度。

---

## Dynamic Contamination Rate

动态行人出现后：

有多少 static memory slots 被错误覆盖。

理想：

DCR → 0

---

## Reappearance Consistency

物体：

visible
→ occluded
→ visible

重新出现后是否关联回原来的 world slot。

---

## Viewpoint Consistency

机器人换视角：

door 从 patch 37
→ patch 129
→ patch 201

但：

WorldSlot_door

保持一致。

---

## Structural Chart Consistency

机器人进入拐角时：

Chart A
→ mixed A/B
→ Chart B

是否能够持续关联并建立正确 chart relation。

---

## Transient-vs-Persistent Change Accuracy

例如：

行人走过
→ 不更新 static memory

椅子永久移动
→ 应该更新 static memory

这是非常重要的核心指标。

# 二十四、最终最重要的设计哲学

整个方法不要表达成：

“用透视点把图片切成网格，然后保存。”

而应该表达成：

> **Perspective is an observation organization mechanism, not the memory coordinate system.**

中文：

> **透视只负责组织当前观测，而不是定义长期世界坐标。**

长期稳定的应该是：

* pose-aware；
* geometry-aligned；
* world-centric；
* persistent structural latent memory。

机器人转弯不是异常状态。

转弯反而提供了：

* 旧结构逐渐消失；
* 新结构逐渐出现；
* 两个局部区域同时可见；

这样的关键 overlap。

这个 overlap 可以帮助系统建立：

Chart A ↔ Chart B

之间的：

* relative transform；
* corner relation；
* topology。

可以将整个方向暂时命名为：

**Pose-Aware Structure-Aligned Latent Memory for Dynamic Embodied Environments**

**Geometry-Aligned Persistent Latent Memory for Dynamic Embodied Scene Understanding**
