# HC-024：绑定 identity 与等价关系

状态：BLOCKED_BY_HC-023

## 要决定什么

什么条件下两个 observation regions 属于同一 world node；BIND、NEW、REACTIVATE、SPLIT、MERGE、UNRESOLVED 的 oracle 如何标。

## 不变量

- 语义同类、视觉相似或共享 VP 均不足以证明同一 node。
- identity 是世界持续性，不是 region proposal 的持续性。
- 标注者无法可靠判定时必须使用 ambiguous/UNRESOLVED。

## 选项

| 选项 | Identity 主规则 | 风险 |
|---|---|---|
| A（建议） | 物理支持连续性 + 时空可达一致性 + 局部关系一致性 | 能处理视角 split/merge 和移动实体，需较细 oracle |
| B | 3D 几何重叠阈值 | 容易实现，但对遮挡、噪声和移动物体脆弱 |
| C | entity-centric 实例 identity | 对对象自然，对墙面/走廊结构不完整 |

## 建议落点

采用 A，并按 node type 定义：surface 依据同一连续物理支撑；object 依据实体持续性，移动不改变 identity；portal 依据连接的空间与物理开口；track 是短时假设，不自动等于 persistent object。

## Action oracle

- `BIND`：现有 active node。
- `REACTIVATE`：inactive/out-of-view node 再出现。
- `NEW`：无已有 node 满足 identity。
- `SPLIT`：一个旧聚合 node 需拆分为多个世界 identity。
- `MERGE`：多个旧 node 被证实为同一世界 identity。
- `UNRESOLVED`：证据不足或冲突。

Observation proposal 的一对多/多对一不自动触发世界 node SPLIT/MERGE；需额外世界证据。
