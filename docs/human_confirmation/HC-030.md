# HC-030：时间、来源与隔离语义

状态：BLOCKED_BY_HC-029

## 要决定什么

事实何时生效、何时被观察、由什么证据支持；冲突或低可靠输入如何隔离。

## 不变量

- observation time、valid time、transaction time 分开。
- provenance 指向不可变 evidence event；摘要分数不能替代来源。
- quarantine 不写入 active memory，不等于永久删除。

## 选项

| 选项 | 时间/来源模型 | 权衡 |
|---|---|---|---|
| A（建议） | 双时间语义：valid interval + observed/proposed time；显式 evidence DAG | 可支持重放、迟到证据和事实替换 |
| B | 单时间戳 + source list | 简单，但无法表达迟到观测与历史修订 |
| C | 完整 bitemporal database | 最严谨，但首篇工程成本较高 |

## 建议落点

采用 A 的最小双时间版本。每个 fact 保存 valid interval；evidence 保存 observation timestamp；transaction 保存 proposed/executed timestamp。若新事实替换旧事实，旧 interval 被关闭并由 `supersedes_fact_id` 串联。

## Quarantine 触发候选

- pose/depth 与局部图严重冲突。
- 高外观相似但空间不可达。
- transaction 违反 parent、时间或互斥关系约束。
- evidence 来源不可在线获得或版本缺失。

Quarantine 项必须保存 reason code、恢复条件、TTL/人工复核状态。
