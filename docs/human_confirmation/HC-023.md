# HC-023：世界记忆层级

状态：BLOCKED_BY_HC-022

## 要决定什么

Place、Chart、persistent slot 与 transient track 是否都进入首篇，以及各自持有什么状态。

## 不变量

- observation region 不进入持久层级。
- 动态短暂观测不得污染静态结构层。
- parent、edge、fact 与 latent 必须可分别版本化和审计。

## 选项

| 选项 | 结构 | 权衡 |
|---|---|---|
| A（建议） | Place → local Chart → persistent slots；transient tracks 平行挂接 | 保留原始 local structural chart 构想，并控制首篇范围 |
| B | 单一扁平异构图 | 实现较快，但局部坐标与生长边界含糊 |
| C | 稠密 voxel/feature field 为主，节点为查询视图 | 强几何能力，但节点 transaction 不再是核心状态 |

## 建议落点

采用 A，但首篇只要求单 Place、多 local Charts；Place 间闭环与全局图优化推迟。Chart 持有局部坐标和 frontier，slot 持有稳定 surface/object/portal，track 持有短时动态 identity。

## 最小状态

- node：ID、type、parent、lifecycle、prototype set、geometry ref、valid time、evidence。
- edge：source、target、relation、valid time、evidence。
- fact：subject、predicate、value、version、valid time、supersedes、evidence。
