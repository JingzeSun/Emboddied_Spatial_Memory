# HC-022：Projective structural tokenizer

状态：BLOCKED_BY_HC-021

## 要决定什么

如何把单帧视觉 latent 变成可与世界节点绑定的 region；透视/VP 在其中扮演什么角色。

## 不变量

- DINO 类 latent 是 substrate，不是主创新。
- VP/透视关系只是结构 cue，不被当成世界坐标或节点 identity。
- tokenizer 输出 observation regions，不直接创建 persistent nodes。

## 选项

| 选项 | Region 构成 | 权衡 |
|---|---|---|
| A（建议） | surface/plane + object + portal + occlusion boundary；附加 VP/ray/geometry cue | 与室内结构、动态体和 frontier 均对齐，能做等价区间 |
| B | 固定 patch/grid token + 位置编码 | 最简单，作为强消融合适；世界边界不稳定 |
| C | 先重建 3D superpoint 再 tokenize | 几何清晰，但容易把贡献变成 3D fusion |

## 建议落点

采用 A 的混合 tokenizer。冻结视觉 backbone；region proposal 可先规则/现成模型，主学习放在 binding 与 transaction。VP 只进入 relation cue，并必须做移除消融。

## Region equivalence

必须允许同一 world surface 在不同视角被 split/merge。训练标签不要求 region 数量一一对应；association 是带 dustbin 的 set mapping。

## 接受测试

- S00/S01 中视角改变不导致系统性 duplicate birth。
- S04 中相似透视结构不能覆盖无空间重叠证据。
- S10 中 proposal split/merge 仍可指向同一 world node。
