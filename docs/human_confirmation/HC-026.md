# HC-026：Chart/Place attachment 与空间扩张

状态：BLOCKED_BY_HC-025

## 要决定什么

新 node 或新 Chart 如何连接到既有世界记忆；何时扩展当前 Chart，何时新建 Chart。

## 不变量

- 未观测空间只能作为 uncertain frontier，不能写成 confirmed geometry。
- attachment 必须有几何与关系证据，不能仅由语义相似决定。
- Chart 间变换和不确定性必须显式保存。

## 选项

| 选项 | Attachment 机制 | 权衡 |
|---|---|---|
| A（建议） | 局部 Chart + frontier anchor；按 overlap/condition 切 Chart | 与原始构想一致，局部误差可控 |
| B | 所有 node 直接写同一全局坐标图 | 简单，但长序列漂移会全局污染 |
| C | 学习式全局 Chart split/merge | 潜力高，但首篇变量过多且 oracle 困难 |

## 建议落点

采用 A。首篇用确定性 Chart proposal：重叠充分时扩展当前 Chart；视场跨过 portal/frontier 或局部条件恶化时建新 Chart。模型预测 node/edge attachment，executor 检查 parent 唯一性与几何一致性。

## 关键区分

- `CREATE node`：在已有 Chart 中增加已观测结构。
- `CREATE chart`：建立新的局部坐标容器。
- `ATTACH`：建立 contains/adjacent/connected_by 等边。
- `frontier`：关于未观测区域的假设，不是 persistent world node。
