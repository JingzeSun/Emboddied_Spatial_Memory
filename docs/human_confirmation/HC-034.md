# HC-034：下游任务与只读评测

状态：BLOCKED_BY_HC-033

## 要决定什么

用哪个应用证明世界记忆有行动价值，同时避免下游模型掩盖 memory 质量。

## 不变量

- 下游 agent 只读 memory，不能写入或读取 oracle identity。
- 所有基线共享同一 planner/query head 与输入预算。
- memory 指标仍是主证据，任务成功率不能替代它们。

## 选项

| 选项 | 主任务 | 权衡 |
|---|---|---|---|
| A（建议） | 时间限定结构查询 + 证据引用 | 直接评价版本、absence、reappearance 和 revision，变量最少 |
| B | memory-conditioned object retrieval/navigation | 具身价值直观，但规划与控制误差会混入 |
| C | frontier-aware active exploration | 最贴合在线扩张，但需要联合学习策略，范围显著扩大 |

## 建议落点

首篇主任务选 A，B 作为最多一个次任务。查询包括最后可靠位置、当前可见性/状态、旧事实有效区间、替换证据以及已知/新区域判断。

## 评价

- 事实与 node/edge 查询准确率。
- valid-time interval 与 evidence attribution。
- unknown/abstention calibration。
- 查询延迟与 memory size。
- 若做 B：success、SPL/路径效率、错误来源分解。

## 接受测试

固定 query head 下，memory 主指标改善与 T1 改善相关；删除版本/evidence 或打乱 node identity 时任务显著退化。
