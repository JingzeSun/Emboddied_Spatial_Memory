# HC-012 — 主动观察怎样平衡任务、信息、风险和成本

> 本文件已经内嵌指标解释与数字算例；[统一术语索引](METRIC_GUIDE.md)仅供查词。示例值不等于正式阈值。

> 状态与最终回答只见 [DECISIONS.md](../DECISIONS.md)。

## 要决定什么

给多个离散动作时，先确定安全硬门，再定义任务收益、信息价值与行动成本的组合方式，以及什么时候不值得继续观察。

## 固定不变量

- 风险不可接受的动作不能因信息量高而被选；
- 歧义不影响任务时不为好奇无限观察；
- action ranking 不修改 SceneBelief；
- 多个近似最优动作可形成 acceptable set。

## Utility 候选形式

```text
先执行 hard safety filter
再比较：
task_progress
+ λ × expected_information_gain
- μ × action_cost
- ν × localization/risk_cost
```

也可采用词典序：安全 → 任务可行 → 风险上限 → 信息/成本。两种方案需要选择。

## 必须由研究者选择

1. weighted sum 还是 lexicographic constraints；
2. hard safety 包含哪些条件；
3. 信息价值按熵下降、候选淘汰还是 decision value；
4. 歧义“与任务相关”的操作定义；
5. 一步还是短视界，最大验证步数；
6. ask/reobserve/move 的成本如何比较；
7. acceptable action set 的效用容差和 tie-break。

## 推荐判题与指标

### 指标是什么意思

- **Task success gain**：主动观察后的任务成功率减去不主动观察时的任务成功率。
- **Information gain**：动作前后的关键不确定性减少量；必须明确用候选熵、候选数量还是其他定义。
- **Action cost**：多走的距离、时间、能耗或动作次数。
- **Risk / safety violation**：碰撞、进入禁区、失去定位等风险。安全要求通常应先过滤，而不是放进平均分抵消。
- **Utility**：将任务收益、信息价值、成本和风险缩放到可比较范围后加权。
- **Regret**：oracle 最佳安全动作的效用减去系统所选动作的效用。

### 数字怎么算

先把各量缩放到 0～1。以下公式只演示计算：

Utility = 0.5 × 任务收益 + 0.3 × 信息价值 - 0.1 × 成本 - 0.1 × 风险。

动作 A 的任务收益 0.8、信息价值 0.5、成本 0.4、风险 0.1：

- Utility(A) = 0.5×0.8 + 0.3×0.5 - 0.1×0.4 - 0.1×0.1 = **0.50**。

动作 B 的任务收益 0.6、信息价值 0.8、成本 0.2、风险 0：

- Utility(B) = 0.5×0.6 + 0.3×0.8 - 0.1×0.2 = **0.52**。
- 在示例权重下选择 B。

如果 oracle 最佳安全动作效用为 0.60，系统选择 B：

- Regret = 0.60 - 0.52 = **0.08**。

若 A 有 5% 碰撞概率，而安全合同规定碰撞概率必须低于 1%，A 应先被淘汰，不能靠任务收益抵消。

### 你需要冻结的选择

1. 任务收益和 information gain 的具体计算方式。
2. 距离、时间、能耗和风险如何归一化。
3. utility 权重；权重只能用 validation 冻结。
4. 哪些安全限制是不可加权抵消的硬门槛。
5. 最大动作预算，以及效用接近时是否优先更安全或更便宜的动作。

- 推荐 safety 词典序硬门，再比较 task + information - cost；
- oracle 硬门：S04/S06/S07/S12/S17 不得违反安全/停止规则；
- 指标：oracle-action-set accuracy、utility regret、steps-to-correct-belief、task success、cost、risk violations；
- 权重只在 validation 冻结，test 不调。
