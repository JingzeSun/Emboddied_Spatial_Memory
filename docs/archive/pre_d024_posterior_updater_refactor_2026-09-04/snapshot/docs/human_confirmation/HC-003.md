# HC-003 — 变化沿哪些关系传播、在哪里停止

> 本文件已经内嵌指标解释与数字算例；[统一术语索引](METRIC_GUIDE.md)仅供查词。示例值不等于正式阈值。

> 状态与最终回答只见 [DECISIONS.md](../DECISIONS.md)。

## 要决定什么

传播不是“图上可达就全改”。必须按 `operator × relation × direction × condition` 建 whitelist，并显式给出 stop edge。

## 固定不变量

- 只有 revise 路径允许 affected-subgraph propagation；
- query/attention 不产生 propagation；
- 没有许可依赖路径的 control facts 必须不变；
- 传播不能跨越 candidate/confirmed、observation/world 或不同 reference frame 的边界。

## Operator 维度

| Operator | 可能允许传播 | 通常不传播 |
|---|---|---|
| ADD | 必需 attachment/identity edge | 任意邻近关系 |
| RELINK | connects、located_in、continuation_of | contains 的所有后代 |
| INVALIDATE | 直接依赖且失去成立条件的事实 | 无因果依赖的事实 |
| SUPERSEDE | identity-continuous state/version | 类别相同的其他实例 |
| UPDATE_STATE | operator-specific state dependency | ontology 和静态结构 |
| PRESERVE | 无传播，只显式保护 control | — |

## 必须由研究者选择

1. 每个 operator 允许沿哪些 stored relation、哪个方向传播；
2. supports/attached_to/contains 的传播条件是否需要同时有新观测；
3. 隐藏对象随容器移动时是 confirmed update 还是 motion hypothesis；
4. 多跳传播最大深度是否存在，还是只由 stop semantics 决定；
5. 遇到 dependency cycle 怎样处理；
6. 两个独立变化是否允许同一 transaction；
7. derived 关系重算是否计作 propagation。

## 推荐判题与指标

### 指标是什么意思

- **Propagation recall**：应该跟着变化的节点或边中，有多少真的被更新。低说明传播没有到位。
- **Scope precision**：系统实际修改的内容中，有多少确实应该改。低说明修改范围太大、污染无关事实。
- **Collateral revision rate**：本来不该变化却被改掉的事实比例。
- **Stop violation**：传播越过人工规定停止边界的次数。身份、类型、安全约束等越界可以直接判硬失败。
- **Edit size**：一次事件修改了多少节点和边。它用于比较局部修订与全图重算，但不是越小越好，少改却漏掉必要关系仍然失败。

### 数字怎么算

椅子从房间 A 搬到 B，人工判定必须更新 5 项。系统一共修改 7 项，其中 4 项属于必要更新，另外 3 项本不该改：

- Propagation recall = 4 / 5 = **80%**。
- Scope precision = 4 / 7 = **57.1%**。
- 系统同时犯了“漏 1 项”和“多改 3 项”两类错误。

如果未受影响区域共有 100 个事实，其中 3 个被误改：

- Collateral revision rate = 3 / 100 = **3%**。

若门的 identity 被定义为停止边界，而系统把门类型一起改了，则记 1 次 stop violation。即使其余指标为 99%，仍可判该场景失败。

### 你需要冻结的选择

1. 每种 typed operator 能沿哪些依赖边传播。
2. 哪些关系、节点属性和 control state 是停止边界。
3. 漏传播和多传播分别有多严重，是否设置不同门槛。
4. stop violation 是否必须为 0。
5. 多个同样正确的最小作用域怎样组成 acceptable set。

- 推荐：whitelist + condition，不使用纯图可达性；
- oracle 硬门：required propagation recall=1、control mutation=0、cycle/非法边原子拒绝；
- 指标：node/edge scope precision/recall、propagation completeness、stop-edge accuracy、collateral revision rate；
- 同时报告漏改和多改，不能只优化 scope 大小。
