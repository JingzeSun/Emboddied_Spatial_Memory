# HC-001 — 对象搬迁时何时保持同一 identity

> 本文件已经内嵌指标解释与数字算例；[统一术语索引](METRIC_GUIDE.md)仅供查词。示例值不等于正式阈值。

> 状态与最终回答只见 [DECISIONS.md](../DECISIONS.md)。本文件是详细判题工作表。

## 要决定什么

当 A 中的 chair_1 不再可见、B 中出现一把椅子时，输出应是：

- `SUPERSEDE`：同一对象搬迁，保留 identity；
- `ADD`：B 中是新实例，A 中旧对象状态另行判断；
- `RETAIN/QUARANTINE`：证据不足，同时保留多种解释。

## 固定不变量

- 类别相同不等于 identity 相同；
- identity 不确定时不能用 top-1 静默合并；
- 是否沿用 ID 与“旧址是否失效”是两个独立问题；
- 旧版本与 identity evidence 必须保留。

## 必须由研究者选择

1. appearance、geometry、时间连续性和运动可行性是否全部为必要条件，还是允许其中三项强证据替代一项；
2. 多久的时间间隔后必须退回多假设；
3. 哪些 action/relation evidence 可以替代视觉连续轨迹；
4. A 不可见时，是否永远不得关闭旧位置；
5. removed 后重新出现是否恢复原 ID，恢复窗口多长；
6. 对象 identity 的范围是 sequence、episode、scene 还是长期地图；
7. 多假设何时必须主动观察，何时可以保持不决。

## 推荐判题与指标

### 指标是什么意思

- **Identity recovery**：遮挡或暂时离开视野后，再次出现的物体中，有多少恢复了原来的 ID。它衡量“能不能认出还是它”。
- **ID switch rate**：同一个真实物体在连续跟踪过程中被错误换 ID 的频率。
- **False split rate**：一个真实物体被错误拆成多个 ID 的频率。
- **False merge rate**：两个真实物体被错误合成同一个 ID 的频率。它通常比 split 更危险，因为系统可能搬错、删错对象。
- **Abstention rate**：证据不足时选择保留多假设或 quarantine 的比例。允许 abstain 可以避免乱猜，但比例过高代表系统不工作。

### 数字怎么算

20 个物体各经历一次遮挡：17 个恢复原 ID，2 个获得新 ID，1 个被并入旁边同类物体。

- Identity recovery = 17 / 20 = **85%**。
- False split rate = 2 / 20 = **10%**。
- False merge rate = 1 / 20 = **5%**。

再假设 100 个有歧义的重识别事件中，系统对 30 个选择 quarantine，对其余 70 个作出 identity 判断，则 abstention rate = 30 / 100 = **30%**。判断准确率必须和这 30% 一起报告，不能靠大量拒答换取漂亮分数。

### 你需要冻结的选择

1. 指标按“物体”还是按“每次重新出现事件”统计。
2. 最大遮挡时间、允许位置误差和允许外观变化。
3. false merge 是否必须为 0；若不是，和 false split 的代价比是多少。
4. 同类实例交换位置时允许保留多假设多少帧。
5. abstention 最高允许比例，以及超过多久必须主动观察或作出决定。

- 推荐：appearance + geometry + temporal/motion 至少三类互相支持；冲突则 QUARANTINE；
- oracle fixture 硬门：S01/S04/S05/S10/S15 不得判错，identity 决定必须可追溯；
- 指标：ID switch、false merge、false split、association precision/recall、abstention quality、version validity；
- 允许答案用 `{same, new, ambiguous}` acceptable set 表示，不伪造唯一答案。
