# HC-010 — 重复走廊中怎样判新区域、回环或定位不确定

> 本文件已经内嵌指标解释与数字算例；[统一术语索引](METRIC_GUIDE.md)仅供查词。示例值不等于正式阈值。

> 状态与最终回答只见 [DECISIONS.md](../DECISIONS.md)。

## 要决定什么

面对相似画面，定义 H_new、H_loop(X) 和 H_pose 的证据门、共存方式和不可逆 append/merge 条件。

## 固定不变量

- 图像相似既不自动等于 loop，也不自动等于 new；
- loop 必须引用具体历史 Place/Chart；
- pose 冲突时先保留不确定性；
- append/merge 都必须版本化并可撤销。

## 证据族

- appearance：局部/全局视觉、稳定地标；
- metric geometry：相对 pose、深度、平面和尺度；
- topology：已有连接、可达方向、闭环一致性；
- action history：实际路径和运动可行性；
- temporal change：动态对象与长期改造；
- localization uncertainty：covariance、重定位冲突。

## 必须由研究者选择

1. loop 最少需要哪些证据族共同成立；
2. H_new 的确认门；
3. 多个 loop target 怎样保留和裁剪；
4. partial overlap 是否允许“回访 + 扩图”组合；
5. loop closure 是否能触发历史 pose/belief 重放；
6. map itself uncertain 时的处理；
7. 完全失定位时停止、回退还是主动重定位。

## 推荐判题与指标

### 指标是什么意思

- **Confusion matrix**：分别统计真实为 new、loop、drift 时，系统各判成什么。它比一个总准确率更能暴露危险混淆。
- **Per-class precision / recall**：三类分别计算，不能只看数量最多的一类。
- **Macro-F1**：先算三类各自 F1，再直接平均，让少数类与多数类权重相同。
- **False map expansion**：loop 或 drift 被误判成 new，因而产生虚假扩图的次数或虚假节点数。
- **False loop closure**：真实新区域被错误合并到旧地点的次数。
- **Decision latency**：从首次发生歧义到 new/loop/drift 结论冻结所需帧数或动作数。

### 数字怎么算

测试集包含 new 40 个、loop 30 个、drift 30 个。系统分别判对 32、24、15 个：

- 总 accuracy = (32 + 24 + 15) / 100 = **71%**。
- drift recall = 15 / 30 = **50%**，说明 71% 总体分数掩盖了漂移识别失效。

若三个类别 F1 分别为 0.90、0.80、0.40：

- Macro-F1 = (0.90 + 0.80 + 0.40) / 3 = **0.70**。

30 个 loop 中 5 个被判 new，30 个 drift 中 10 个被判 new：

- False map expansion 事件数 = 5 + 10 = **15**。
- 若每次平均新增 4 个虚假节点，则虚假节点总数 = 15 × 4 = **60**。

### 你需要冻结的选择

1. new、loop 和 drift 的人工标注证据标准。
2. 是否采用 macro-F1，并为每个类别单独设置最低 recall。
3. false expansion 与 false loop closure 哪个更严重，哪些属于硬失败。
4. 位置、方向、外观和拓扑一致性的容差。
5. 多假设最多保留多少帧，超时后是主动观察还是继续 unknown。

- 推荐：loop 需要 appearance+geometry+topology 共同一致；冲突则多假设；
- oracle 硬门：S04/S05/S07/S10/S15/S16/S20 不得不可逆 append/merge；
- 指标：false append、false merge、loop precision/recall、new-segment recall、abstention、recovery steps；
- 分开报告 place association 与局部结构识别。
