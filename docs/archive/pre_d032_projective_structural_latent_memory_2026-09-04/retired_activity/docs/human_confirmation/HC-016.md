# HC-016：COMMIT、QUARANTINE 与证据提交门

## 你必须决定什么

冻结哪些证据条件允许 ASSERT/RETRACT/REPLACE，哪些情况必须 QUARANTINE 或 KEEP，以及门是按 operator 共用还是分别校准。

## 已固定不变量

- 破坏性写入必须有 supporting evidence；
- 模型概率先校准，再用于门；
- 互相冲突的高可信证据不能静默二选一；
- 投影后非法率必须0；
- QUARANTINE 不破坏 confirmed graph；
- 阈值只用 validation 冻结。

## 选项

### A：operator-specific calibrated gates（推荐）

RETRACT 对负证据要求更高；ASSERT/REPLACE 分别要求身份、互斥和时间条件。冲突或字段不足时 QUARANTINE。

### B：统一 commit threshold

简单，但不同操作风险不对称；可作基线。

### C：总取 argmax，不允许 abstain

只作故障消融，不用于正式 executor。
