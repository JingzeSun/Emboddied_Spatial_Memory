# HC-017：结构化基线准入与控制变量公平

## 你必须决定什么

冻结“结构化 world-model updater”的最低操作性定义、native system 是否进入主表，以及参数、训练 step、wall-clock、候选事实和 executor 怎样匹配。

## 已固定不变量

- 不按论文自称分类；
- updater-isolation 主表共享 prior graph、events、candidate facts、dependencies 和 executor；
- native pipeline 输入不同则进外部表并标 `not directly comparable`；
- 投影前后都报，不能把 executor 收益都算给 ESGBU；
- 同一 train/validation/test、seed、early stopping 和 checkpoint 规则。

## 结构化审计 SA1–SA8

| SA | 现场要找的证据 | 满足示例 | 不满足示例 | 是否最低条件 |
|---|---|---|---|---|
| SA1 | 稳定可寻址事实 | `fact_27`可单独读写 | 整图只有一个向量 | 是 |
| SA2 | 显式关系/依赖 | typed edge/adjacency | 只在文本顺序中暗示 | 是 |
| SA3 | 跨时刻持久增量状态 | `G_{t-1}→G_t` | 每帧重建后丢弃 | 是 |
| SA4 | event/arrival 双时间 | 两字段且排序语义不同 | 只有timestamp | 否，额外能力 |
| SA5 | provenance | edit可回查evidence IDs | 只存置信度 | 否 |
| SA6 | affected/protected | 显式写边界 | 默认全图可写 | 否 |
| SA7 | valid time | 事实成立区间 | 只有最后更新时间 | 否 |
| SA8 | dependency consistency | 有界typed closure | 无差别K-hop/无传播 | 否 |

推荐：SA1–SA3 同时满足才归为 structured updater。GNN 每帧输出 graph 只满足 SA1/SA2，未必满足 SA3；把图序列化给 Transformer 也不自动满足 SA1/SA2。

## 公平选项

### A：参数匹配 + wall-clock 匹配两张表（推荐）

例如 L2/L3/L4/M0 都做约10M±10%；另给每法6 GPU-hours的结果。结论看两表是否一致。

### B：只匹配参数

忽略稀疏方法实际速度优势或图模型吞吐差异，只可作一部分。

### C：只使用各论文原生配置

生态比较有价值，但无法归因 updater，不进主表。

## Criteria 纵列

| Criterion 组 | 在本 HC 中是什么意思 | 公平计算方式 | 数字例子 | 你要冻结什么 |
