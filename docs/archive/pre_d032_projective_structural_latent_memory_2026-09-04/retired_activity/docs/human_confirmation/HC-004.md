# HC-004：什么负证据足以撤回事实

## 你必须决定什么

定义 reliable absence 的必要字段与语义：一次 `detected=false` 在什么覆盖、可见、遮挡、来源和独立重复条件下，才可以触发 RETRACT；否则 KEEP 或 QUARANTINE。

## 已固定不变量

- `out-of-FOV`、`occluded`、`sensor-failure`、`reliably absent` 分开；
- 撤回旧位置不等于知道新位置；新位置未知时不得虚构；
- 相邻帧同一 `group_id` 不当独立投票；
- 数值阈值只在 validation 冻结，test 不参与。

## 选项

### A：多因素 evidence gate（推荐）

必须存在 expected visibility/coverage、无可信遮挡、来源健康和足够独立证据；模型学习概率，executor 按 HC-016 门处理。

### B：完全由模型学习

灵活但难保证极端 false retract；只能作为无硬门消融。

### C：detected=false 即撤回

禁止作为正式方法，只作故障基线。
