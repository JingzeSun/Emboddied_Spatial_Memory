# D-032 前活动方案快照

本目录保存 D-032 将项目从 ESGBU posterior-only 主线重构为 **Projective Structural Latent Memory** 之前的逐文件快照。

`snapshot/` 共保存 72 个文件，覆盖当时的入口、活动合同、Human Confirmation、实验包、配置、schema、接口说明与文献审计。它们只作 provenance，不再作为活动要求。

`retired_activity/` 保存从原活动路径移出的旧合同原件，以及总验证时发现的旧 `outputs/README.md`、含旧 HC-014 链接的历史笔记和未对齐 schema 的中间模板草稿。它与 `snapshot/` 的用途不同：前者释放唯一活动路径，后者是迁移前完整核验快照。

原始 `docs/source/full_technical_vision.txt`、PDF、原型、大型运行产物、脚本和更早 archive 均未删除或覆盖。

迁移后，ESGBU 的双时间、证据集合、protected controls 和确定性 executor 仅作为 Projective Structural Latent Memory 的 revision 子模块。原 D-026～D-031 只解释旧实验合同，不自动成为新主线的实验真值或启动授权。
