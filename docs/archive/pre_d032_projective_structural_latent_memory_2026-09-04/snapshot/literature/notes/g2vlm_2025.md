# G²VLM：通读记录

## 基本信息

- 论文：G²VLM: Geometry Grounded Vision Language Model with Unified 3D Reconstruction and Spatial Reasoning
- 年份/会议：2026，CVPR
- 本地文件：`papers/2511.21688v2.pdf`
- 官方来源：https://openaccess.thecvf.com/content/CVPR2026/html/Hu_G2VLM_Geometry_Grounded_Vision_Language_Model_with_Unified_3D_Reconstruction_CVPR_2026_paper.html
- 阅读层级：通读；重点核对双专家结构、几何监督与训练成本

## 一句话结论

G²VLM 证明了把“where”几何专家和“what”语义专家显式分开、再通过共享注意力协同，能提升空间推理；对本项目最有价值的是几何证据源的设计，但它没有解决在线长期记忆、关联和动态更新。

## 问题与方法

论文认为单一视觉编码器难以同时优化语义理解与精确几何。模型采用双 Mixture-of-Transformer-Experts：

- 几何专家以 DINOv2 特征为基础，预测相机位姿、像素对齐三维点图和法向等几何量。
- 语义专家以 Qwen2-VL-2B 为基础，负责对象、关系和语言推理。
- 两类专家保留各自的前馈路径，但共享自注意力，使语义 token 能访问几何 token。
- 训练先冻结语义端训练几何端，再进行空间推理联合训练。规模化配置中通常在第二阶段冻结几何端，只以语言交叉熵训练。

## 训练证据

- 几何损失包含点重建、相机位姿和表面法向监督。
- 论文比较了不同联合训练方案，并显示 DINO 与 CLIP 类双编码视觉信息有互补性。
- 训练使用多类几何数据，计算量很大：论文报告的不同阶段使用 32–64 张 A800，持续数天。

## 对本项目的启发

- 不要要求一个视觉表示同时承担精确结构、开放词汇语义和记忆更新。
- 可将本项目观测写成多证据包：`E_t = {semantic, geometry, pose, confidence}`，再由记忆层负责关联与生命周期管理。
- 几何估计器应被视为可替换上游，而不是把记忆方法绑定在某个大模型上。
- 可以借鉴“几何端先稳定、再训练推理端”的分阶段训练思想。

## 与本项目的关键差异和局限

- 模型做的是输入上的几何落地与空间问答，不维护跨长序列的持久世界状态。
- 没有定义旧证据如何被新观测确认、衰减、遮挡、覆盖或删除。
- 训练资源远超本项目 MVP 可承受范围，不适合直接复现作为第一阶段基线。
- 即使单帧/多帧几何更准，也不能自动保证转身后的实体一致性或动态场景中的记忆正确性。

## 建议采用方式

- 将其列为 **强上游几何—语义表征参考**。
- MVP 使用冻结的现成视觉/几何模型，避免复现其大规模联合训练。
- 后续做替换实验：统一记忆模块下比较弱/强几何前端，以证明收益不是单纯来自更强视觉骨干。
