# HSGM：通读记录

## 基本信息

- 论文：Bridging the 2D-3D Gap: A Hierarchical Semantic-Geometric Map for Vision Language Navigation
- 年份/会议：2026，CVPR
- 本地文件：`papers/2606.00095v1.pdf`
- 官方来源：https://openaccess.thecvf.com/content/CVPR2026/html/Li_Bridging_the_2D-3D_Gap_A_Hierarchical_Semantic-Geometric_Map_for_Vision_CVPR_2026_paper.html
- 阅读层级：通读；重点核对分层地图、规划解耦和地图消融

## 一句话结论

HSGM 说明“几何通行图 + 语义俯视图 + 高层决策”的分层地图比直接让 VLM 端到端走路更可靠；它是本项目很合适的系统级导航对照，但其地图仍不是带可见性和动态生命周期的学习式视觉记忆。

## 方法概览

系统使用前、左、右多视角 RGB-D，构建三个层次：

1. **几何层**：三维几何/占据地图，生成密集且可通行的候选点。
2. **语义层**：提供给 VLM 的二维俯视语义地图，压缩对象与空间关系。
3. **决策层**：VLM 选择高层子目标，A* 负责低层路径执行。

论文有意把语义决策与确定性路径跟随分离，以减少 VLM 高频调用和不稳定动作。

## 关键证据

- R2R-CE、RxR-CE 上，逐步增加几何、语义和决策信息会持续提升 SR/SPL。
- 一个报告的地图消融中，SR/SPL 从无地图的 46.0/30.1，提升到完整设计的 51.0/33.7。
- 去掉子任务分解、A* 解耦或结构化推理都会明显降分。
- 平均单步延迟约 4.87 秒，其中 VLM 决策远慢于路径跟随，支持高低层解耦的工程必要性。

## 对本项目的启发

- 结构记忆不必替代所有地图：可同时输出确定性通行层和学习式语义/表面层。
- 本项目的 `M_t` 应向下游暴露稳定接口，如 `query_frontier`、`query_object`、`query_surface`，让规划器不依赖内部实现。
- 评测应包含导航效用，但还要单独评测记忆本身，否则 A*、VLM 或 RGB-D 的收益会混在一起。
- 可以采用低频记忆语义决策 + 高频几何控制，减少大模型调用。

## 与本项目的差异和局限

- 使用 RGB-D 和大模型 API，系统成本、延迟与纯视觉在线设置不同。
- 语义地图主要面向当前导航，不显式建模观测证据、表面 chart、被遮挡状态或对象变化。
- 论文展示地图层级的效用，但没有专门测试动态人物、物体搬动、回环后的旧记忆污染。
- VLM 与 A* 的系统组件较多，不适合作为记忆表示优劣的唯一比较对象。

## 建议采用方式

- 作为 **结构化地图导航 baseline / downstream consumer**。
- 在同一规划器中替换 HSGM 风格语义地图与本项目记忆读出，控制规划差异。
- 增加静态、遮挡、瞬时变化、持久变化四类序列，观察下游 SR 和记忆正确率是否同时改善。
