# HC-003：依赖闭包与传播停止

## 你必须决定什么

为每种 edit operator 冻结可传播的 typed dependency whitelist、方向和停止条件，从而定义 `M_t` 的 oracle affected closure。

## 已固定不变量

- 不按“图可达”无差别传播；
- 模型只预测 seed，executor 计算合法最小闭包；
- closure 外是 protected controls；
- task 是只读 downstream dependent，不能反向改变事实真假；
- 每次传播保存 edge path 与 stop reason。

## 选项

### A：operator × edge-type whitelist（推荐）

例如 `RETRACT(at)` 可以使依赖该位置的 retrieve task 失效，但不传播到同一区域其他物体。

### B：固定 K-hop

容易实现，但 hop 数没有语义；同为2-hop可能包含必要依赖和大量无关节点。

### C：模型自由预测全部 closure

可作消融，不能替代硬合法性。否则模型能通过任意扩张隐藏漏传播。

## 候选传播表

| 起始操作 | 候选可传播边 | 候选停止条件 | 反事实 control |
|---|---|---|---|
| RETRACT `at(x,A)` | task `depends_on`；互斥位置检查 | 无更多显式依赖 | A中另一个物体不变 |
| REPLACE `at(x,A→B)` | 旧/新位置相关 task | 到只读 task 后停止 | 不重算全房间 |
| RETRACT `open(door)` | route/task depends_on | 不传播到门外无依赖事实 | 相邻门状态不变 |
| QUARANTINE | 默认不破坏 confirmed graph | 候选层停止 | confirmed controls 全保留 |
