# D-025 前 HC 与实验合同快照

本目录保存 Human Confirmation 收缩和 criteria 嵌入实验设计之前的活动版本，共 39 个文件。

- `snapshot/docs/human_confirmation/`：当时的 HC-001～HC-019 与指标指南；
- `snapshot/docs/DECISIONS.md`：当时的唯一状态表；
- `snapshot/experiments/bounded_revision_validation/`：当时的完整实验合同；
- `snapshot/PROJECT_README.md`、`snapshot/EXECUTE.md`：当时的阅读与执行入口。

现行 HC 只保留与 ESGBU 后验修订直接相关的条目。被移出活动目录的 HC 没有删除历史，可从本快照逐文件恢复。本目录只作 provenance，不作活动合同。
