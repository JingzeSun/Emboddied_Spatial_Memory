# 发表质量门

## Gate P0：可执行性

12 个手写事务通过 schema、executor 与 evaluator 自测；每个 baseline 至少触发一个预期成功和一个预期失败。只说明工程判尺可用，不说明方法有效。

## Gate P1：学习问题成立

在未触碰 test 的 symbolic validation 上，Event-Transformer 或 TGN 明显优于 last-arrival / last-observation rules，证明乱序、可见性和来源可靠性确实需要学习。若学习基线都不优于规则，应先修数据任务，不训练复杂模型。

## Gate P2：方法增量成立

ESGBU 相对参数/预算匹配的 full-graph 模型，不仅提高 edit F1，还同时降低 collateral edits、改善 calibration/time、减少 wrong dispatch，并在至少两个 OOD 轴保持优势。否则主张只能是工程权衡。

## Gate P3：RA-L 质量设计目标

需要清楚的新任务、公开或可复现生成器、学习与规则强基线、关键消融、统计不确定性、失败案例，以及 AI2-THOR 的完整 ID/OOD 结果。RA-L 是质量参照，不保证录用，也不自动等于任何国内“A类”。

## Gate P4：强国际期刊扩展

T-RO/IJRR 等通常需要在 P3 上增加真实长序列/机器人证据、跨域泛化、更深机制分析，或可证明的校准/安全保证。3RScan 仅作外部重扫测试可能还不够，需看结果强度再决定。

## 会议、SCI 与国内 A 类

- SCI 是检索体系，不等于统一质量等级；
- RSS 等强机器人会议不是“SCI 期刊”，但学术影响可能很高；
- 国内 A 类由学校/学院/项目采用的目录决定，CCF、校级和学科表可能不同；
- 投稿清单必须等用户提供目标机构最新版认定表后再冻结，不能由仓库自动猜。

对博士申请更重要的是一条能讲清楚、可复现、有失败分析的第一作者研究线，以及推荐信中可被具体证明的独立研究能力；刊名不能替代这些证据。
