# HC-011 — 怎样区分视野揭示、传感器矛盾和外部世界变化

> 本文件已经内嵌指标解释与数字算例；[统一术语索引](METRIC_GUIDE.md)仅供查词。示例值不等于正式阈值。

> 状态与最终回答只见 [DECISIONS.md](../DECISIONS.md)。

## 要决定什么

新旧观测不同，可能只是机器人移动看到了新区域，也可能是 pose/depth/detector 出错，或世界真的变化。需要定义判断优先级和可靠残差门。

## 固定不变量

- 先用 ego-motion 与几何重投影解释差异；
- never-observed 区域出现属于 reveal/expansion，不关闭旧事实；
- sensor inconsistency 进入 quarantine；
- 只有可靠且不能由视角/遮挡解释的残差才考虑 revision。

## 建议判断顺序

```text
传感器/时间/pose 是否可靠？
  否 → sensor inconsistency / quarantine
  是
    ↓
差异能否由 ego-motion、FOV 或 occlusion 解释？
  是 → reveal / visibility / preserve
  否
    ↓
是否有 identity、几何和多帧证据反驳旧事实？
  是 → revision
  否 → candidate / unknown / active verification
```

## 必须由研究者选择

1. 各传感器可靠性门和冲突优先级；
2. “可靠残差”需要哪些证据族；
3. illumination/appearance change 是否单独成类；
4. 动态对象移动何时进入长期 revision，而非 transient memory；
5. 结构施工等慢变化的时间门；
6. pose correction 后是否重放旧 assimilation；
7. 多解释时选择 quarantine 还是主动观察。

## 推荐判题与指标

### 指标是什么意思

- **Event macro-F1**：分别评价 reveal、sensor inconsistency 和 world change，再平均，避免大量普通 reveal 掩盖真实变化识别失败。
- **False world-edit rate**：视野揭示或传感器异常被错误写成真实世界变化的比例。
- **Missed-change rate**：世界真的变化了，但系统仍保留旧事实的比例。
- **Reveal completion**：新视角应补充的节点、边或可见性信息中，实际成功补充的比例。
- **Quarantine precision**：被送入待确认区的事件中，确实存在传感器或 pose 冲突的比例。
- **Recovery latency**：传感器恢复或获得新视角后，系统恢复到正确世界状态需要多少帧。

### 数字怎么算

数据有 40 次视野揭示、20 次传感器异常、20 次真实变化。系统把 5 次揭示和 4 次传感器异常误写成世界变化：

- 非真实变化共 60 次。
- False world-edit rate = (5 + 4) / 60 = **15%**。

20 次真实变化中系统只正确修订 16 次：

- Missed-change rate = 4 / 20 = **20%**。

某次转弯后人工标注应揭示 8 个新结构元素，系统补充 6 个：

- Reveal completion = 6 / 8 = **75%**。

如果“把人物遮挡误判成人永久离开”被定义为 forbidden behavior，即使总体 false world-edit rate 很低，该子场景发生一次也应单独失败。

### 你需要冻结的选择

1. reveal、sensor inconsistency 和 world change 各需要什么证据。
2. 深度、RGB、detector 和 pose 冲突时的优先顺序。
3. 哪些事件必须 quarantine，解除 quarantine 需要什么证据。
4. false world edit 是否总体设线，还是某些对象类型要求为 0。
5. 真实修订需要几次独立确认，以及最大 recovery latency。

- 推荐上述可靠性→视角解释→真实变化三级门；
- oracle 硬门：S01–S04/S07–S15/S21 不得触发 confirmed revision；
- 指标：evidence-category macro-F1、false revision、reveal recall、occlusion preservation、change detection delay；
- 每次错误保存 sensor/pose residual 与选择路径。
