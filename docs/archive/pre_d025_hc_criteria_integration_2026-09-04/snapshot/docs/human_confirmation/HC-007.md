# HC-007 — planned、executed action 与实际 pose transition 怎样记录

> 本文件已经内嵌指标解释与数字算例；[统一术语索引](METRIC_GUIDE.md)仅供查词。示例值不等于正式阈值。

> 状态与最终回答只见 [DECISIONS.md](../DECISIONS.md)。

## 要决定什么

世界预测应条件于“想做的动作”“实际下发的动作”还是“真正发生的运动”。三者不分开会把执行失败、碰撞和定位误差错误写成世界变化。

## 固定不变量

- planned、executed 和 pose transition 是三个字段；
- 只有模拟器/外部真值可标 oracle pose；
- 估计 pose 必须带来源、时间戳和不确定性；
- 动作失败不能被伪装成环境未变化。

## 必须由研究者选择

1. predictor 使用 planned 还是 executed action 产生 prior；
2. assimilation 使用哪个 pose source，冲突时怎样降级；
3. partial action 的离散标签和连续参数怎样同时保存；
4. loop correction 是否重放历史 belief；
5. pose covariance 达到什么程度必须 quarantine；
6. reset/kidnap 是否切断 episode；
7. 允许的时间同步误差。

## 推荐判题与指标

### 指标是什么意思

- **Execution-state accuracy**：planned、executing、executed、failed 等状态被正确记录的比例。
- **False execution rate**：动作没有真正完成，却被系统写成 executed 的比例。
- **Pose error / ATE**：估计位置与参考位置的距离误差；至少报告中位数和 95% 分位，不能只报平均值。
- **Pose consistency**：当前观测在所采用 pose 下是否能与已有地图合理对齐。
- **Phantom expansion rate**：因为把计划或失败动作当成已执行，而新增的虚假地图节点比例。

### 数字怎么算

机器人收到 20 次左转命令：15 次真正完成，3 次被障碍阻止，2 次尚未执行。系统却记录了 18 次 executed，其中包含 2 次失败和 1 次未执行：

- 未成功事件一共 5 次。
- False execution rate = 3 / 5 = **60%**。

一次轨迹有 100 个参考位姿，位置误差的中位数为 0.18 m、95% 分位为 0.72 m。若走廊转角只有 0.6 m 宽，0.72 m 足以制造假岔路，所以 pose 阈值必须与场景尺度共同解释。

本次扩图共新增 40 个节点，其中 6 个来自未执行动作：

- Phantom expansion rate = 6 / 40 = **15%**。

### 你需要冻结的选择

1. planned → executed 需要命令回执、里程计、视觉到达还是多者共同支持。
2. 位置误差和方向误差分别允许多大。
3. 何种 pose residual 触发“停止扩图并进入定位不确定”。
4. 未执行命令能否生成预测候选，但禁止生成 confirmed fact。
5. phantom expansion 是否为硬失败，以及按节点还是按事件统计。

- 推荐：prior 可条件于 planned/executed，posterior 几何必须依据实际 pose transition；
- oracle 硬门：S02–S05/S10/S12–S18 不得按 nominal action 扩图；
- 指标：action-record validity、pose/action consistency、failure attribution、timestamp alignment、replay determinism。
