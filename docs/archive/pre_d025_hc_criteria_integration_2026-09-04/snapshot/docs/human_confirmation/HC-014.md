# HC-014 — 透视结构区域怎样绑定并巩固为持久世界节点

> 本文件已经内嵌指标解释与数字算例；[统一术语索引](METRIC_GUIDE.md)仅供查词。示例值不等于正式阈值。

> 状态与最终回答只见 [DECISIONS.md](../DECISIONS.md)。本工作表只展开判题空间，不代表 schema、代码或实验已经实现。

## 要决定什么

当前帧按透视、深度、平面、语义和遮挡边界得到的 ObservationRegion，怎样与已有 surface、portal、object 等世界节点关联；何时强化旧节点、何时创建候选节点、何时保留 split/merge 多假设、何时允许写入 persistent latent。

这不是在问“视觉模型能否分割区域”，而是在问：

> 当前看到的区域属于旧世界中的谁，以及这条证据允许改变哪一个长期 latent。

## 固定不变量

- 单帧 region ID 不是持久 world node ID；
- near/mid/far、camera-left/right 和消失点位置是当前视角属性，不作为长期身份；
- Vanishing Point 只提供观测结构线索，世界节点必须锚定到 world/chart frame；
- predicted region、unmatched region 和 top-1 association 不得静默进入 confirmed graph；
- 多个 observation region 可以支持同一 world surface；一个 observation region 也可能覆盖多个 world nodes；
- region split/merge 首先作为关联假设，不因一次分割结果立刻分裂或合并长期节点；
- 只有 pose、depth、geometry、visibility 和 association 共同允许时，观测 latent 才能写入持久 latent；
- 动态物体和遮挡者不能污染其后方静态 surface latent；
- 每次持久写入必须保存 observation、关联分数、写入权重、版本和 provenance；
- Chart/Place 在当前 MVP 仍是稳定底座，不学习其 split/merge；HC-014 先冻结 region-to-surface/portal/object 与 candidate-chart 接口；
- 证据不足时允许 QUARANTINE，不能用强制 top-1 降低 unknown 比例。

## 建议的最小输入与输出

### 输入

```text
previous SceneBelief
current RGB-D / camera intrinsics
T_world_camera and pose uncertainty
ObservationRegion set
  - image mask or polygon
  - pooled visual latent
  - depth / plane statistics
  - semantic distribution
  - visibility / dynamic probability
candidate and confirmed world nodes
```

### 输出

```text
RegionWorldAssociationRecord
  - observation_region_ids
  - candidate_world_node_ids
  - association confidence / acceptable set
  - MATCH | NEW_CANDIDATE | SPLIT_HYPOTHESIS
    | MERGE_HYPOTHESIS | PRESERVE | QUARANTINE
  - allowed latent-write targets
  - protected world-node ids
  - geometry / pose / semantic / temporal evidence
  - proposed write weight
  - provenance and version preconditions
```

该记录只是 Structured Belief Assimilation 的输入，不直接执行 confirmed graph 修改。

## 必须由研究者选择

1. 持久结构节点的最小粒度：完整平面、局部 surface fragment、portal，还是层级组合；
2. 透视线、depth edge、plane、semantic mask、occlusion boundary 和 portal cue 如何共同决定 ObservationRegion；
3. near/mid/far 是否只作当前帧属性；推荐不持久化；
4. observation-level split/merge 何时可以提交为 world-node split/merge；
5. 一个 region 是否允许关联多个 world nodes，一个 world node 是否允许接收多个 regions；
6. persistent latent 使用单 EMA、多个 bounded prototypes，还是可学习 memory；
7. 哪些证据不足时禁止 persistent latent write；
8. 关联置信度怎样结合 pose、depth、visibility、dynamic probability 和时间证据；
9. surface/portal/object 何时允许建立 candidate chart attachment；
10. 当前 MVP 是否只评测 region-to-world association，不学习 Chart/Place split/merge；
11. 低置信证据的最长 quarantine 窗口；
12. 哪些错误属于硬失败：静态污染、false merge、false confirmed expansion、越权 latent write。

## 推荐默认设计

### 表示层级

```text
ViT/DINO patches
      ↓ mask/region pooling
ObservationRegion                 camera-relative，短期
      ↓ pose/depth association
WorldSurface / Portal / Object    world/chart-relative，持久
      ↓ overlap and topology
Local Chart                       MVP 稳定，不学习 split/merge
      ↓ place identity
Place / Route Graph
```

### 区域生成

推荐使用混合结构边界：

```text
perspective / vanishing cues
+ depth discontinuity
+ plane consistency
+ semantic or instance masks
+ occlusion boundary
+ portal/open-space cue
```

VP 只提供结构 prior，不单独决定持久节点边界。

### Latent 写入

推荐先用 deterministic/hybrid gate，并保留多个 bounded prototypes；单 EMA 只作为低层基线。

```text
write_confidence =
    association
  × visibility
  × pose_confidence
  × depth_confidence
  × static_probability
  × measurement_quality
  × temporal_support
```

阈值和各项权重只能在 validation 冻结。低于门槛时保留 observation/provenance，但不写 persistent latent。

## 推荐判题与指标

### 指标是什么意思

- **Region-to-world association precision**：系统提交的 region→world 关联中，多少是正确的；
- **Association recall**：所有应关联到旧节点的 region 中，多少被成功关联；
- **Duplicate-world-node rate**：本应复用旧节点却新建重复节点的比例；
- **False merge rate**：不同世界实体被错误写成同一节点的比例；
- **Split/merge recovery**：观测分割变化后，持久身份仍恢复正确的比例；
- **Static latent drift**：干净场景和被动态遮挡后的同一静态节点 latent 距离；
- **Latent contamination rate**：不属于目标世界节点的观测被写入其 latent 的比例；
- **Control-latent preservation**：本次事件无关节点的 latent 保持在允许容差内的比例；
- **Memory growth per meter/step**：轨迹增长时新增持久节点数，检查是否走一步复制一次；
- **Write abstention**：因证据不足拒绝持久写入的比例，必须与 association accuracy 同时报。

### 数字怎么算

100 个 observation regions 中，人工判定 80 个应匹配旧世界节点、20 个是真正新结构。系统对其中 70 个正确匹配旧节点，错误匹配 5 个，剩余 25 个输出 candidate/quarantine：

- Association precision = 70 / (70 + 5) = **93.3%**；
- Association recall = 70 / 80 = **87.5%**；
- Write abstention = 25 / 100 = **25%**。

如果 80 个应复用旧节点的区域中，有 8 个被错误新建：

- Duplicate-world-node rate = 8 / 80 = **10%**。

遮挡实验中有 50 面静态墙，其中 6 面写入了行人或推车特征：

- Latent contamination rate = 6 / 50 = **12%**。

一条 20 m 走廊的真实结构 oracle 是 12 个持久 surface/portal 节点。方法 A 每米新增 2 个节点，最终约 40 个；本方法输出 14 个：

- 方法 A memory growth = 40 / 20 = **2.0 nodes/m**；
- 本方法 memory growth = 14 / 20 = **0.7 nodes/m**；
- 但只有当 association、结构覆盖和 false merge 同时合格时，较小增长才表示更好，不能靠少建节点获得低增长。

一次椅子搬迁只应改 chair_1 及 3 条关系，另有 30 个结构 latent 是 control。系统误改 2 个 control latent：

- Control-latent preservation = 28 / 30 = **93.3%**；
- 如果其中一个误改是 wall_07 被人物特征污染，还应单独记静态污染失败。

### 你需要冻结的选择

1. association 指标按 region、world node、事件还是轨迹统计；
2. false merge、静态污染和 false confirmed expansion 是否必须为 0；
3. latent drift 使用 cosine、L2，还是下游检索/匹配稳定性；
4. 多个正确关联存在时怎样定义 acceptable set；
5. quarantine 是否计错，以及最高允许比例和最长等待时间；
6. memory growth 与结构覆盖怎样联合报告；
7. region split/merge recovery 的观察窗口；
8. 是否要求每类场景单独过线，而不是只看总体平均。
