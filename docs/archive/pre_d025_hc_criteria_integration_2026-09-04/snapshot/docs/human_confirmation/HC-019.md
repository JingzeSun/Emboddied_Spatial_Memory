# HC-019：下游任务错误是否合成单一代价

## 为什么要人决定

“错派一个任务”“漏关一个已失效任务”“无关任务被重算一次”在医院、仓库和实验室的代价不同。数据或模型只能测次数，不能替应用方决定价值权重。

## 推荐选项 A：主表只报分项

分别报告：

- wrong-dispatch rate；
- missed-invalidation rate；
- collateral-recompute rate；
- 相对 oracle state 的 task regret。

不合成单一 cost；可在附录做多组权重敏感性。优点是最诚实、跨场景可读，缺点是没有一个方便排序的总分。

## 选项 B：固定通用候选权重

候选 `wrong dispatch=5, missed invalidation=10, collateral recompute=1`。

数字例：错派 6、漏关 5、无关重算 8，则 cost=`6×5+5×10+8×1=88`。这些数字只是展示计算，不代表行业真值。

## 选项 C：按一个具体行业冻结

先选仓库、实验室或医院后台，再由领域风险给权重。例如安全任务漏关可能为 50，普通无关重算仍为 1。这样应用主张更强，但需要领域依据或专家确认。

## 与训练的关系

无论选择哪项，第一版都不把 task cost 反向作为事实 truth loss。若后续 cost-sensitive fine-tuning，必须单独消融，并确认 NUR、CPR、time 与 calibration 不下降。
