## 1. Final goal and overall chain

Under the same frozen public RGB-D front end, the same recall rule, the same executor and the same evaluation protocol, compare VSMT-lean, TAF, ELU-P, RAC and LOW to answer whether reversible lifecycle revision trained with hindsight supervision can reduce stale entities and false deletions while preserving the identity of moved objects (2026-10-01, ruling 99-2: the primary hypothesis is VSMT-lean against AssocOnly trained with the same recipe; 2026-10-08, ruling 113: claims are limited to METHOD section 2, and the gain over AssocOnly is not attributed to hindsight supervision itself).

```text
S0 Contract freeze (S0-01 → S0-06)
  ↓
S1 Front end and data pilot (S1-01 → S1-02a → S1-02b → S1-05)
  ↓
S2 Five-arm development table (S2-01 → S2-05; S2-06 SAM 2.1; S2-R redesign track, ruling 88)
  ↓
S3 Formal data, training, validation, one-time test and external validation (S3-01 → S3-07)
  ↓
S4 Paper
```

| Status | Meaning |
|---|---|
| Completed | The code and the necessary tests have been reviewed, or reusable real evidence exists |
| Implemented, awaiting authorization | The code is committed and passes its tests, but the real-execution authorization bit in the step contract is still false |
| Not started | Dependencies not met; no formal output can be produced yet |
| Sealed | Determined, but opening or using it is prohibited in the current stage |

Authorization for a real run is expressed by boolean bits in the step contract and reviewed by the user before the run; a real run requires a clean checkout and records, for every run, the git commit, contract digest, input digest, output digest, worker count and exit codes, resource usage and all failures. The "Required actions" in the tables are mandatory in full. A house or episode that cannot run successfully must leave a failure receipt; it may not be omitted, replaced or compensated by additional samples. Test fixtures prove only code behaviour; a real step is complete only when the server outputs, digests and exit receipts are all present.
