# 空间世界模型候选与历史方法合同

## 当前候选：空间历史对动作后果预测的作用（D-062，proposed）

研究问题：近期传感器信息和机器人控制指令相同，但早期观察揭示了不同遮挡区结构，模型能否预测不同的视野外交互后果，并改善固定候选动作的选择？输入为合法历史、候选控制和共同目标；输出为未来物块位置序列与接触判断。例如左侧挡板曾经可见，后来完全被遮挡，同一左推控制应与没有该挡板的场景产生不同预测。这不是证明“显式三维状态必胜”，也不是输入物体目标位移后生成视觉效果。

首轮采用固定物理参数、一个平面运动任务物块、一个笛卡尔推杆和固定观察路径。Cartesian pusher（笛卡尔推杆）是可按世界坐标速度指令运动的简化机器人末端；输入每段速度和持续时间，输出机器人及物块响应，例如向左前方推。这不是复杂机械臂抓取，也不能把物块实际位移当作速度控制。SH-02/v2的单对工程检查和审查已完成，证据见LOG-105；具体数值见下文。手工合同示例仍不代表物理结果。

### SH-03 固定开发物理审计（v1结果见LOG-106，v2服务器验证pending）

白话：这一步解决“只在一个特意搭好的场景里出现预期碰撞”的问题。输入已验收的推杆模拟器和事前登记的16种设置，输出每对场景的真实轨迹、画面以及逐项通过/失败。例如挡板从y=0.60 m改到0.52 m后，仍需检查物块是否真的在视野外碰到它；这不等于模型已经学会预测，也不等于16个独立随机环境的泛化评估。

固定组合设计（fixed factorial design，逐一覆盖登记参数的组合）采用墙中心y为0.52/0.58/0.64/0.70 m、共同物块/推杆起点x为−0.02/+0.02 m、历史弧线采样数为13/23的全部16种组合。它检验三种具体变化，输入参数表、输出完整案例清单，例如0.52 m、−0.02 m、13帧组成sh03-00；它不是搜索最容易成功的参数。case_id与顺序固定于development_audit_v1.json，整个家族仅为development，不计算把这些相关组合当成独立随机样本的置信区间。

每个组合内仍只有隐藏墙的左右位置不同；共同起点变化时，相机瞄准点x随之平移，两个世界的相机信息保持一致。弧线时长为1.2/2.2 s，随后仍保留2帧相同近期观测，总历史为15/25帧。相机轨道半径、高度、分辨率及屏、物块、推头、控制、物理参数与阈值保留。每候选49段控制、4.9 s、2450物理步；64条不同分支另做64次独立反序重放。重放用于检查恢复和执行一致，不是额外数据样本。原SH-02生成器字节不改，新增适配器仅准备配置、区分记录编号和汇总判定。

固定通过条件为16对全部满足：成对输入合同与早期视觉差异、正确的2×2分支顺序、首帧墙至少4像素、近期墙0像素且目标可见、完整非布局初态相同、观察不改积分状态、4次独立重放一致、撞墙模式[真,假,假,真]、确有2条障碍接触分支且每个已记录接触物理步目标像素为0、无物块撞屏、高度/倾角/执行器力保持原范围、两个同动作跨世界终点距离都至少0.05 m。实现将这些归为13个布尔检查；零接触不能使遮挡检查空通过。

完整生成但不通过的案例保留，继续完成固定清单并报告全部失败，不补样、不只导出通过子集；运行异常则停止余下案例。若审计失败，先读具体轨迹再登记必要修复，不能直接扩模型。当前goal半径0.5 m不改，它不能直接充当有效动作选择评分；后者仍需SH-04另行冻结。新批次验收不借用旧32项回执：先在服务器运行新增8项适配/拒绝条件测试，再生成审计数据。8项测试通过也不代表16对物理条件已经通过。

SH-03/v2墙角间隙修订（implemented，物理效果未验证）：白话，这个修订处理物块在预期通过方向擦到墙内侧角点的问题。输入原16组设置和相同控制，把两世界挡板中心分别从x=−0.31/+0.31 m移到−0.33/+0.33 m，输出重新执行的完整16对轨迹及原13项判定。例如sh03-00中的右推动作原来有8步墙接触，需要验证移动挡板后是否真正消失；这不是把短接触从标签中删除，也不表示已经修复。

挡板尺寸不变，因此内侧边从x=±0.02 m移到±0.04 m；这是左右两个反事实世界各自的墙边位置，不是往单个世界同时加入两面墙。2 cm是依据已记录的墙角擦碰选定的一次开发期几何修订：把旧4例首次额外接触的物块位姿固定下来，仅计算平面圆盘到新墙角的几何净距，得到约18.09–18.50 mm。这个只读计算用于解释选择，不是新动力学轨迹、全程间隙保证或参数最优性证据；物块倾角、推杆与墙的接触变化都仍须真实模拟检查。

该修订统一施加给原16例，墙y/起点x/历史长度组合、候选控制、物块/推杆/屏、相机、物理参数、goal和`assess`判定保持不变；可能同时影响应有碰撞，故全部16例重验，不复用v1的12个通过状态。先运行原8项加新增4项测试（共12项），验证几何改动范围、拒绝未登记间隙/缺失来源、v1不接受v2字段，以及额外隐藏碰撞仍不能通过。v1是已完成失败，v2是参考开发失败作出的受控修订，不把它称为独立未见场景确认；若仍失败，保留结果，不自动继续增大间隙或筛例。

### SH-04 研究问题与架构复审（D-068，proposed）

用户要求现在收紧小实验，并先查世界模型论文及旧CTL/CPMT架构。首帧已揭示左右布局、历史仅1.4/2.4秒、固定左右类别对应碰撞标签，使SH-03适合工程检查，但不能单独检验持续空间整合；连续轨迹和动作评分是否由首帧充分求解尚未实测。下方v1数值提案保留作审查历史；96对数据、18次训练、原停止门不再作为下一实施依据。新架构、数据、损失及预算尚未冻结。文献依据集中在[本轮核查](../literature/notes/spatial_world_models_2026.md)。

**建议研究对象：由受限视觉历史形成的状态，能否支持未见几何—控制组合中的视野外交互预测。** 白话：输入几个视角分别看到的结构、近期共同观测和真实控制，输出未来物块位置/接触及候选后果。例如两个不共视的局部结构共同决定推过去是否受阻；仅识别“左侧有墙”不应决定全部答案。这是待验证的任务候选，不是已经发现新缺口，也不要求先做复杂操作或开放世界。

场景审查需检查三种互相区别的能力：跨视角组合几何；证据离开近期窗口后仍能取回/保留；由控制与几何预测接触。必须记录每项实际需要的信息，不能仅加帧数、重复静态画面或延迟就称为更强记忆问题。主场景应给出同一单视图对应多个不同合法后果、完整历史可区分的具体记录，不能只凭模型单帧准确率低声称信息不足。关键证据位置变化、每帧/元数据的捷径及未见组合划分先审；首帧/一般检索成功是有效否证，不能据其成功反复换题。

**工作架构候选（不是创新主张）。** 输入RGBD/相机位姿/本体/过去动作，经冻结视觉编码及几何对齐形成观测；历史模块更新状态；预测模块只根据该状态和拟执行控制推演后果；固定候选评分消费预测。每个控制分支从相同决策状态独立开始，想象轨迹不能被写回为实际观测。输出可读位置/接触，暂不做高质量视频解码器。主排名不访问真值地图/初态；这些只能进入独立诊断。

| 模块候选 | 输入→输出、具体问题及非等价关系 |
|---|---|
| 完整历史Transformer | 全部合法历史特征＋控制→后果；例如直接读取两个旧视角。保留为架构对照，不把手写4层网络称作DINO-WM |
| Recurrent State-Space Model（RSSM，循环状态空间模型） | 上一步状态＋新观测/动作→更新状态，再以未来控制推演；例如相机转走后仍保留挡板证据。按DreamerV3代码参考设计，离线状态监督适配不等于完整Dreamer复现 |
| 几何检索与观测地图 | 历史RGBD/位姿→少量相关帧或观测几何；例如检索两个互补视角。完整历史和检索不可被故意截掉必要证据；真值选帧只能另列诊断上限 |
| 共享地图上的动力学 | 同一估计地图/初态＋控制→轨迹/接触；比较准静态、重建MuJoCo，必要时再审学习交互网络。图消息传递依据PropNet/GNS，不称其自身为新机制 |

上述不是一次训练所有系统的授权。具体论文方法优先核验DINO-WM与FloWM可运行资产；必须将基础架构、原设定权重重评/训练复现、迁移适配分别验收。只要改变监督、输入或动作含义就列清差异。纯视频监督若无法区分隐藏后果，其失败不能归因于记忆；状态监督的读出头是否回传梯度亦需事先写明。

**旧CPMT/CTL的复用边界。** Counterfactual Projective Memory Transactions（CPMT，反事实投影记忆事务）组织候选图修订；Counterfactual Transaction Learning（CTL，反事实事务学习）用修订后世界的事后评分教在线候选选择。旧输入为结构摘要与候选事务，输出事务分数；例如把错误关联改到另一个节点。它不等于输入机器人控制预测物块运动。

|---|---|

| 不可变克隆、独立执行、完整失败 | 继续用于分支公平性和回执；旧执行器执行图修改，并非物理引擎，不强行依赖cpmt包 |

严谨的改进机制必须由具体失败支持：几何恢复错先修感知；保留不足先比较检索/循环状态；地图已对而接触错先审动力学；状态/轨迹都对而选择错先审评分。若简单组合足够就收口，若数据/训练不足就报告未定，不借失败宣布新机制必要。

**评分与证据待修订项。** 逐时刻Brier（接触概率与真实0/1标签的平方误差）保留为诊断，不能单独作为接触充分性门；需分列碰撞分支检出率、无碰撞分支误报率和逐例接触时序。例如长期预测无碰撞可能在稀疏标签上平均误差很小，但漏掉所有关键撞击。这不等于已冻结事件概率汇总规则或新阈值。位置/终点/成对预测及真实动作regret继续分别检查；隐藏期间指标须新增完整可见性标注，不能把只有接触步不可见说成全未来不可见。

正式比较须先检查指标容差的应用含义、强对照可改善空间、训练充分性和家族独立性。新数据量依据开发阶段的学习曲线与估计精度设计，不沿用96对；确认集在方法和预算冻结后才生成/使用，所有种子与失败报告，未获明确结论就保留不确定。投稿目标不能替代实证支持，也不因首轮负结果扩模型或反复换场景。

### SH-04-R3 首批：公开文件读取边界（已实现、服务器检查待运行）

本职责只把已审`model_input`合同接到真实文件，解决“内存示例合规，但实际加载器又把整个实验目录读进来”的风险。输入为单个公共文件、外层批准的字节摘要/大小以及所查询控制，输出仍仅为历史、数值控制和公开目标；例如同一LL公共历史查询LR时，得到200段真实机器人指令，不得到LR标签或门洞位置。它不是几何恢复器、预测器、标签加载器或操作系统沙箱。

`public_reader.load_query`先按精确字节读取并验证摘要，完整校验所有历史/候选后才截取所需帧；因此未选帧中的未来字段、未选控制中的实际运动也不能悄悄通过。重复JSON字段直接拒绝，不能靠后一个同名字段覆盖污染；不跟随文件或父目录符号链接。函数只打开指定公共文件，不扫描目录、打开审查图或读取R2报告。后续调用者应把来源核验放在模型外；本批尚未提供恶意进程不能访问同机私有文件的权限隔离。

必要服务器检查含12项读取器边界及6项运维回归，使用小型手工公开帧检验错误摘要/长度、未选字段污染、非法时序、重复键、文件/父目录链接、邻近标签与改名不变性、输出独立性、原来源、失败复用与导出拒绝覆盖。手工检查通过不代表物理或几何正确。随后只读R2四个真实公共文件，对四个共同控制分别构造完整历史/近期查询；核对32项清单、原分辨率/形状、共同目标与同控制、近期完全一致和四份完整历史不同。此处“不同”只指查询字节内容不同，不证明差异可用于恢复几何或改善任务表现；全部科学判定仍沿用R2，无新阈值或结果筛选。

### SH-04-R2 双门空间证据候选（D-070/D-071工程协议，运行证据见LOG-108）

用户已认可双门四世界/四候选及真实送达任务（D-069），并接受本节全部数值、信息判定与工程预算（D-070）。下列合同已有独立实现，实际工程验收与审查证据统一见EXECUTE的LOG-108；本节只维护方法定义，工程通过不等于批准模型训练。

以下为已认可的概念方向，尚无新模拟结果。**先检验跨视角整合，不把延长几秒历史当作长期记忆实验。** 输入是分开观察到的两处门洞、共同近期观测及预先固定的机器人控制；输出是真实执行后物块的轨迹、接触与到达情况。例如第一段旧观察只见近门，第二段只见远门，两者共同决定哪条控制可能把物块送过两门。这不是已证明的新机制，也不是论文级泛化任务。

**场景定义。** 保留一个圆柱物块、一个有限力平面推头和静态障碍。在前后两道横墙各留一道门洞，每道门洞可偏左或偏右，组成左左、左右、右左、右右四个世界；第一字表示近门、第二字表示远门。两门后方设共同目标区。候选控制也有四条，分别意图从上述四种路线经过；输入仍只有每段末端速度与时长，四世界使用完全相同的候选库、时长和力限。路线名称仅供人读，模型消费数值指令，不读取真实物块路径或执行后机器人运动。

原两世界/两动作合同不能直接容纳这个构造；所选方向需要独立的新家族合同及审计，保留原SH-01至03接口与回执，不能仅修改旧计数后冒充旧测试已覆盖。这里选择四个候选是为了让近门与远门都有机会改变最佳动作，不是开放动作策略或主动探索。

| 观察条件（均须真实渲染核验） | 可获得的信息 | 仍不能分清的世界 |
|---|---|---|
| 单取历史视角A＋共同近期 | 近门位置，远门不可见 | 左左/左右，或右左/右右 |
| 单取历史视角B＋共同近期 | 远门位置，近门不可见 | 左左/右左，或左右/右右 |
| 仅共同近期 | 物块与推头当前观测，两门均不可见 | 四世界 |
| 完整合法历史＋共同近期 | 两段局部几何及其相机位姿 | 拟允许恢复两个门的位置；尚未验证 |

相机沿四世界共用的连续路径采集A、B及转场，随后回到共同近期视角；A/B只是说明名，不输入答案标签。门洞信息通过真实RGB、深度和位姿获取，不能复制公共帧、盖像素mask或用私有分割制造观测相同。本版固定采用下方局部俯视的有限视场，不设置实体遮挡屏。采集顺序和证据时刻独立于门位变化；全部转场参与检查，不边看结果边增加变体。

**可识别性审计。** 它解决“单张图是真缺信息，还是模型没学好”的区别：输入同一观察规则下的完整公开字段，输出不可区分的世界组，再检查组内同控制的真实后果是否不同。例如左左与左右在A及共同近期完全相同，却可能在同一左左控制下分别通行、卡在远门。这是有限构造的信息检查，不是学习结果。

- 等价比较包括RGB、深度/有效位、相机内外参、时间、本体状态、过去指令、候选控制和目标。不能只比较RGB而忽略元数据。除A/B外，每个转场帧也检查其区分能力；出现一帧能确定两门就不能声称任意固定单帧都不足。
- 不能要求同一对世界在**每一帧**都完全相同、却要求完整历史分辨它们。应使用上表交叉的多世界分组；单取A和单取B对应不同分组。
- 真正的后果标签只能由物理运行产生。对意图左左的控制，概念预期为左左通行、左右在远门受阻、另两世界在近门受阻；**这不是已经成立的接触矩阵**。卡住、滑脱、绕过和擦碰均原样记录，不能按路线名称生成标签。
- 单视图可能足以判断某条路线必然失败；本候选只拟证明单视图整体上不足，不承诺每个输入、每条控制都必须联合两段证据。
- 仅证明完整历史各不相同仍不够。须从公开RGBD/位姿恢复门洞几何，并检查观测地图＋动力学是否能支持后果预测；真值地图和真值初态单列诊断。记住不同截图的类别不等于形成可用空间状态。

**检索边界。** 固定只取一帧的输入不足，不适用于“先读完整历史，再决定取哪一帧”的检索器：选择过程本身能整合历史，选中的帧或位姿也可能传递信息。例如先检查两个门，再选择一张特定旧图，已经使用两段证据。合法自适应检索及取回两张互补图都保留为强对照；其成功不能被改写成无效捷径，更不能为了逼它失败不断增加场景。

**已认可的任务含义：在共同时间预算内，把物块实际送过两门并留在共同目标区。** 擦墙仍到达可以成功，无碰撞但推头滑脱、物块没到仍失败。成功区域、物块须全部越过的边界、停留时长、速度容差与统一控制时长按下方冻结数值执行；不沿用0.5 m半径，也不预填模型准确率门。碰撞单独记录，不自动作为惩罚。

动作选择价值与后果差异分别审计。令任务失败代价C为未满足所选任务定义时取1，否则取0；对同一公开输入对应的世界组G，在事先声明的世界权重下，计算：

`min_a E[C(w,a) | G] − E[min_a C(w,a) | G]`。

白话：这比较“分不清是哪一个世界时能选的最好共同动作”与“知道世界后逐个选最佳动作”差多少；输入是真实执行结果，输出因缺信息不可避免的动作损失，它不是任何模型的实验分数。若为零，即使碰撞标签不同也不能证明历史对动作选择有用。真实终点距目标区的差值另报，避免所有失败都被压成同一分数；不把未批准的多项加权和悄悄变成主评分。

若四世界等权、每世界恰好只有对应候选通行，固定单门视图最多能在两个可能世界中选对一个，完整信息则有机会选对全部；这是**以未验证物理矩阵为前提的组合推论**，不是预计模型成绩。不能由路线名称推出12条一定碰撞，也不能用总接触准确率掩盖类别不平衡；应分报实际正负分支、漏报、误报、接触时序和轨迹。若真实最佳动作无须两段信息，本构造的动作选择主张不成立，不加碰撞罚项制造成立。

**物理可行性与结论边界。** 原推头宽0.30 m、物块直径0.14 m；门需允许推头通过，不能只检查物块尺寸。冻结门宽0.38 m、左右中心±0.12 m、前后间隔1.60 m，替代概念草案的间距估计。原推面不转向，中途横移可能让物块滑脱；错误路线也可能沿墙滑入门洞。不能通过锁定物块运动、读取真值追踪控制或临时增摩擦来实现画出的路线。若此构造失败，应先呈现失败，必要修改或换设计由用户审查，不自动扫参。

工程审计保存全历史与未来采样的真实可见性，并在实际接触物理步补查；这才可区分“接触发生时不可见”与“整个未来不可见”。来源、相同非布局初态、独立恢复、反序重放、有限力、物块高度/倾角和全部动态物体接触均重新检查；不能把旧的恰好两条碰撞、49步、两个候选等固定断言直接用于新场景。

四世界与四控制仍是有限类别，最多证明存在互补信息需求。若工程通过，正式协议另审连续门位/净宽/间距、控制幅度/时长及未见组合；不能只给四种布局换颜色、加帧或扩样本就升级为论文证据。完整历史预测器、循环状态、合法检索、观测地图＋简单/较强动力学继续比较。若强方法足够，接受“该构造不需要新机制”；长期保留及复杂操作不在本次场景选择中自动加入。

**主任务判定。** 决策后20 s内按顺序实际穿过近门、远门；最后1 s（19–20 s）的每个物理步，物块整个水平投影都在共同矩形`x∈[−0.25,0.25] m、y∈[2.45,2.85] m`内，且三维线速度≤0.02 m/s。目标中心(0,2.65)，区域宽50 cm、深40 cm；正常直立物块中心约允许x在±18 cm、y在2.52–2.78 m内，能容纳两侧出门路线，又排除卡在远门前。最后1秒都满足可排除偶然掠过；2 cm/s限制该秒内的路程至约2 cm，不另要求绕圆柱自身轴停止旋转。

过门按同一次真实尝试配对：相邻步满足`y_prev < gate_y <= y_now`时建立一次向前穿面事件，用这两步线性插值得到穿面时刻与x；x须在`[门洞左边−0.001, 门洞右边+0.001] m`。中面相等不重复触发；完成前中心一旦回到`y < gate_y`，本次尝试失效，必须重新向前穿面，不能拼接两次尝试。仅仍有效的尝试可在真实步满足`y−s_y >= gate_y+0.025−0.001 m`时完成（整个后缘过墙后表面，允许1 mm边界容差）；保存尝试号、所属两步及完成步。近门完成须早于远门穿面；所有失败尝试和回退也保存，不只看终点。

物块全程完整投影不得越过侧壁内界或y范围[−0.40,3.00]，目标/走廊区间统一按下界减1 mm、上界加1 mm判断。接触时不要求整块XY包围盒始终装在门洞中，以免把允许的圆角擦碰误判成任务失败。另设独立物理质量门：任何涉及物块或推头的原始接触（含地面、相互接触及各墙，不先按法向力筛掉），最大负接触距离≤5 mm；两动态物体中心每0.002 s三维位移≤5 mm。5 mm穿透上限为墙厚的十分之一，区分有限接触柔性与深度穿模；单步位移上限对应2.5 m/s，是排除离散跳变的工程界限，不是任务速度要求。它们是D-070批准的工程界限，不能保证软接触等于现实；超过即工程失败、保留数据，不把异常分支计为正常任务失败或事后放宽。原始穿透、位姿和穿面步完整导出，不能以插值事件代替真实动力学核验。

擦墙后成功送达仍成功；滑脱没送达仍失败。通过条件不加碰撞惩罚。失败代价1、成功0；终点到目标区的距离另列连续诊断，不临时与碰撞/成功混成一个加权分数。当前单纯xyz/接触预测头不足以直接实现全部姿态/停稳判定，R4须明确各主对照如何从预测输出形成统一选择分数；本阶段不能宣称模型评分已实现。

### SH-04 首轮视觉对照协议 v1（proposed，尚未实现或授权训练）

**历史提案，D-068已要求修订；下列数值不得直接执行。** JSON状态为requires_revision_not_executable。保留原说明以便对比本次变更，不将其当作当前冻结基线。

白话：原v1拟判断“简单读回旧图、或从旧图建图后模拟，是否已经足够”。输入真正的历史RGB/深度、标定与机器人控制，输出未来49个时刻的物块位置和接触概率，再比较所选动作的真实后果。例如早期看到左墙，近期墙已被遮挡，模型应预测左推受阻并选择更接近目标的候选；这不是给模型墙坐标或物块未来变换，也不是立刻提出新记忆机制。机器提案`configs/spatial_history/baseline_protocol_v1.json`已由D-068标为待修订，不能启动其生成或训练。

**任务可识别性。** 首帧已经揭示布局，因此“取回第一帧”必须成为强对照；两种历史长度只有15/25帧，当前不主张长时持久记忆。墙始终只有两种左右布局、控制只有两个固定序列，成功也可能主要来自视觉识别与插值，不能称为任意动作动力学或通用世界模型。未来画面中的目标可能仍被遮挡，故未来图像/latent重建误差不能代替物块后果误差。

**视觉编码。** 拟固定DINOv2 ViT-S/14无register版本，官方代码修订`7764ea0f912e53c92e82eb78a2a1631e92725fc8`，公开权重地址写入JSON；下载后先形成权重SHA和依赖锁，当前不填假摘要。它是输入图像、输出局部视觉特征的冻结编码器，不是动力学模型；例如每张224×224输入得到16×16个384维patch特征，仍保留空间位置。选择S版是本轮预算选择，不称为完整复现DINO-WM。实现与维度依据[官方模型定义](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/dinov2/models/vision_transformer.py)及[官方加载接口](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/dinov2/hub/backbones.py)。

64×64原RGB先除255，双线性全图缩放224、align_corners=false、antialias=true、不裁剪或随机增强，再用均值(0.485,0.456,0.406)/标准差(0.229,0.224,0.225)归一化；均值/方差来源为[官方变换](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/dinov2/data/transforms.py)，全图缩放是本协议选择，不照搬其分类裁剪。放大不会增加原始信息。深度/投影仍用原64×64内参，不把放大RGB内参与原深度混用。每个视觉patch另附对应4×4原深度块的16个米制值和16个有效位，深度除2 m；无效值填0并保留mask。所有主方法允许相同RGB、深度、相机/本体信息和公共固定机器人/物块尺寸与物理常数，不能一方用真值地图另一方只有图像。

**学习目标。** 拟议预测器直接输出决策后0.1–4.9 s的49个三维位置和49个接触logit；训练标签来自真实执行，仅训练集标签参与梯度。位置损失为坐标除0.1 m后的均方误差，接触损失为逐时刻二元交叉熵，两项等权、均按有效元素取平均。白话：输入预测和真实未来，输出位置偏差与接触判断的惩罚，例如差10 cm不能因未来图像仍是屏幕而得零损失；这不是把未来真值塞进预测器。该监督比纯未来视觉特征损失更强，必须明确标为本任务的监督适配。[DINO-WM原文](https://arxiv.org/html/2411.04983v2)预测冻结patch特征并以目标图像规划；本任务的状态头、深度输入和固定候选评分改变了条件，不能把适配结果写成原论文复现或原方法被证明失败。

S/L/R使用相同网络与训练预算：patch输入线性投影128维，固定二维patch位置及相对时间编码，4层历史Transformer（4头、前馈512、dropout0.1），2层控制序列decoder，49个控制查询。历史encoder可读取全部合法过去；decoder只读截至所预测时刻的已计划控制前缀和历史，不能输入未来观测或teacher-forced物块真值。控制为原速度与持续时间，机器人状态为决策前观测；同一模型分别查询两候选。全patch保留，不先全局平均成一个视觉向量。具体张量顺序、mask、初始化与可重现依赖须在可审实现中锁定；本提案不冒充已经实现。

M-QS与M-PHYS的地图共用原分辨率RGB色彩筛选和深度反投影：已知红墙/绿物块任务颜色只用于像素规则，不读实例分割；拟合已知尺寸的轴对齐墙盒和圆柱中心，机器人位置/速度用公开本体输入。墙左右编号不作输入，亦不直接套用±0.33 m真实坐标；输出拟合残差及未知区域，不把未见处一概设空。准静态模型拟采用10 ms积分、推杆速度积分与非穿透投影、零反弹、每步最多8次接触投影；训练集仅选择推力传递系数{0.8,1.0,1.2}，其他常量与主方法共享。像素阈值、几何拟合及接触投影顺序仍须作为单一职责实现审查，不可等看到确认结果再补。两种动力学必须同时报告，避免把简单动力学不足错归为空间历史不足。

真值诊断单列：分别把真值地图、真值决策初态替换进同一个地图预测器，保持其动力学不变，用来区分感知/地图误差与动力学误差；这不是公平主输入，不参与主方法排名。将同一真实成对记录的完整历史换成另一世界的合法历史、保持共同近期和控制，预测应对应另一世界后果；此检查只复用已存在真实历史，不合成物理上不可能的轨迹。若只会认左右仍可通过该检查，因此不单独作为世界模型证据。

**统一动作评分与读数。** 动作代价固定为终点到原goal中心的欧氏距离（米），不使用半径命中率，也不增加碰撞罚项。预测器按预测终点距离选动作；差≤1e-6 m时按展开控制数值的字典序选，禁止按世界/样本编号破平。真实regret为所选动作真实距离减去两个候选中最小真实距离。白话：例如两个候选最终距目标30 cm和8 cm，选前者损失22 cm；这不是模型自己的预测分数。goal字段和物理任务不改，评分是事前声明的新评估定义。

同时报告49时刻平均三维位置误差、终点误差、逐时刻接触Brier分数与0.5阈值分类、成对终点正确率（同动作两个世界终点误差都≤5 cm才正确）、成对动作选择与真实regret。Brier是预测接触概率与0/1事件的平方误差，例如自信地错报碰撞惩罚较大；不只看不平衡事件的分类准确率。先按家族等权汇总两历史长度/世界/动作，再汇总家族；逐例失败全部保留。8个固定确认家族只作描述性插值小试，不给总体泛化置信区间。

**选择与停止。** S/L/R各使用AdamW、权重衰减0.01、学习率仅{1e-4,3e-4}、种子{17,29,43}，每次1500个optimizer step，microbatch1、累积8个同家族查询再更新、梯度范数裁剪1；家族按种子洗牌循环。每100步评估validation，按“位置误差/0.1 m＋Brier”选择checkpoint；先以3种子均值选一个学习率，再保留该学习率的全部3个checkpoint，不挑最好种子。共最多18次训练，不因负结果加参或加模型。M-QS的3个系数只用train标签选定，M-PHYS不调物理参数。

一个强主方法（L/R/M-QS/M-PHYS）在确认集达到成对终点正确率≥0.90、Brier≤0.10、平均regret≤0.02 m，就判当前小试不足以支持增加新记忆机制；学习方法须分别报告全部种子，并以三种子平均判门。未达门也不自动支持新机制：必须先排除视觉编码、地图恢复、动力学和训练未收敛，在同一冻结checkpoint的逐例错误中定位；只有S失败完全不够。该门是小试的实用充分性标准，不是论文显著性或研究目标成立的判据。

| 历史检索预测器 | 从完整过去按合法规则取相关帧→预测；检验简单取回旧图是否足够。未完整复现论文时标适配实现 |
| 地图加简单动力学 | 同一历史深度/位姿形成地图，固定或仅在开发训练数据标定动力学→未来轨迹；检验现有几何/碰撞办法是否足够，不偷读完整真值地图 |
| 真值诊断 | 完整状态或真值地图→同一任务预测；用来定位地图与动力学误差，例如真值地图换入后恢复。单列特权上限，不作公平主对照 |

模型输出未来状态，统一评分器选择两个候选中的一个；固定目标、候选、观测权限、监督和选参预算。长历史/地图两者均报告训练成本、存储和推理延迟。固定历史采集路径，不加入主动探索或语言接口。模型不得在预测期间接收真实未来帧或实现后的机器人轨迹。

| 拟议读数 | 作用与例子 | 边界 |
|---|---|---|
| 成对结果正确率 | 同一动作两种布局后果均对才成功，例如甲受阻、乙通过 | 不用逐例多数类准确率替代；阈值待固定 |
| 遮挡期间轨迹误差 | 比较预测/真实位置随时间偏差，例如终点对但中途穿墙 | 不等于图像清晰度；采样间隔须报告 |
| 接触概率误差 | 衡量预测接触概率与真实事件差异，例如恒报五成把握 | 不只报阈值分类；接触定义由物理合同固定 |
| 动作选择损失 | 所选动作真实效果与同一候选集最佳效果之差 | 不是模型自己的预测分数；目标与代价待固定 |

相关结构改变应改变后果预测；无关历史变化不应改变预测。控制例均需物理一致的轨迹，不能拼接不可能发生的过去。整组成对布局、动作分支和关联家族不跨后续划分；按独立场景组统计。只有短历史失败说明缺信息；长历史/简单地图成功则不强行设计新机制。先定位观察、状态整合、动力学、评分哪个环节失败，再决定后续改动。

### 第一职责批次：成对输入边界

`src/spatial_world_model/pair_contract.py` 只审计一个双世界记录并提取模型允许的字段：`audit_pair` 校验结构和成对条件，`model_input` 返回独立深拷贝，`audit_dataset` 检查一批记录且不按结果差异筛选。输入为 DATA 定义的 JSON，输出布尔诊断与 `history/controls/goal`。例如改变未来答案或配对编号不改变模型输入，而改变早期图像会改变完整历史输入；这不是物理重放、遮挡验证或模型训练。示例 `data/fixtures/spatial_history/manual_pair.json` 明确标为手工夹具，假设的未来坐标不是模拟结果。

验证器始终输出 `physics_and_visibility_verified=false`。分支 snapshot hash 相同只说明记录声明了同一基础状态；下一批须真正保存、恢复和重放快照。字段白名单只能排除显式隐藏字段，无法证明像素没有被编码答案；物理来源/遮挡/阴影/反射仍须独立审查。未显示历史差异或后果差异的记录照样返回诊断，不静默删除失败样本。

### 第二职责批次：固定物理工程夹具（实现，服务器验证及审查 pending）

`src/spatial_world_model/physics_fixture.py` 负责把固定场景、机器人控制和观察路径交给 MuJoCo，再保存真实传感器与可重放分支。输入是 `configs/spatial_history/physics_v1.xml` 和同名 JSON，输出一对世界、四条首次执行分支和四条独立重放。例如左墙世界执行左前推后应发生隐藏接触，右墙世界执行同一控制应通过；这是待检验的工程预期，不是已生成的成功样本，更不是已发现模型失败。没有随机采样、搜索成功场景、训练或动作选择器。

固定使用 MuJoCo 3.3.7、NumPy 2.2.6；直接依赖锁版本，完整间接依赖由隔离环境的 `pip freeze --all` 登记并在使用时核验。EGL（用于无显示器的 OpenGL 渲染接口）让服务器直接产生 RGB、深度和审计分割图；输入当前模拟状态，输出64×64图像，例如相机看见的挡板像素。它不是视频生成模型；不在渲染失败时静默切换后端。API依据为[3.3.7 Python文档](https://mujoco.readthedocs.io/en/3.3.7/python.html)及[对应渲染器源码](https://github.com/google-deepmind/mujoco/blob/3.3.7/python/mujoco/renderer.py)。

完整积分快照指 `mjSTATE_INTEGRATION`：恢复继续计算所需的时间、位置、速度、控制、相机运动输入与求解初值等，并绑定场景XML摘要；字段范围依据[官方状态定义](https://mujoco.readthedocs.io/en/3.3.7/APIreference/APItypes.html#mjtstate)。白话：它解决“第二个动作其实接着第一个动作的结果开始”的问题，输入某世界决策时完整状态，输出重新从该时刻开始的分支。例如两条候选各自恢复同一快照，再用新模型和新数据按反序重放；这不是只比较记录中的hash字符串。保存状态后进行观测也不能改变积分状态；重新计算衍生位置/接触后恢复积分输入，以避免额外观察改变求解初值。

工程门同时要求：原20项合同回归；近期独立渲染的全部公开输入完全相等、早期墙可见至少4像素、近期墙0像素而物块可见；两世界完整非布局积分状态相等；每个实际障碍接触步目标可见像素为0且至少有正接触；首次/独立重放的轨迹、终态、RGB和深度逐字节相同；左右墙的接触模式为受阻/通过和通过/受阻，同一动作的成对终点至少差0.05 m。物块高度限定0.02–0.065 m、倾角≤0.25 rad以检查这个平面任务没有意外翻倒，执行器力不超过已设上限。这些是固定工程场景的验收条件，不是学习指标或任意新场景通用的通过门。

可见像素检查解决“碰撞虽然发生，但模型其实一直看得见”的问题：输入模拟器实例分割图，输出目标/挡板可见像素数。例如有墙接触的每个0.002 s采样点均须目标像素为0；无接触不能自动通过。这不是解析坐标近似遮挡，也不证明连续时间或无限分辨率完全不可见。分割图/可见计数只供工程审计，不进入模型。

所有首次和重放分支先保存，再做断言；失败不换种子、不改变墙位置后悄悄续跑。该固定工程夹具不计入后续16对开发审计，不用于训练/选参/确认。工程测试通过后仍须审代码与原始画面；它不能支持任何新机制、泛化、实时性或动作选择收益主张。

## 研究问题与范围

完整方法是 Counterfactual Projective Memory Transactions（CPMT，反事实投影记忆事务），核心机制是 Counterfactual Transaction Learning（CTL，反事实事务学习）。唯一问题：**执行候选修订后形成的事后监督，能否比直接未来损失更可靠地学习在线世界记忆修订？**

白话：输入是旧世界记忆和新到达的观测，输出是保留、扩充或修订后的世界。环境结构和对象都在范围内：例如转过走廊拐角后把新墙面、地面及连接纳入旧记忆，或椅子移动后改位置且保留无关结构。这不是只识别图片，也不预设每个新向量都是新物体。

首篇只做 embodied spatial memory，固定 backbone、depth、pose、region proposals 和确定性候选器，允许固定/轻量投影。不加 learned candidate generator、主动消歧、动作策略、第二领域、端到端基础模型或大规模导航。executor、KL 损失和事务标签不能单独当创新。

新 M1 可以依据真实数据重构，旧 M1/S5 no-go 保留；阶段顺序和用户代码审查遵循 PLAN。重构不解封旧 test，也不预设 CTL 会获胜。

## 新观测怎样影响旧 latent

| 对象 | 定义与例子 | 边界 |
|---|---|---|
| observation region | 一次图像中的区域、mask 或 patch 支持，例如本次看到的墙面、地板、门口或椅背 | 不自带跨帧真实身份 |
| observation latent，z | 冻结前端对一次区域的编码 | 新到达不等于新实体 |
| world node | 系统维护的结构片段或对象的持久身份、几何、证据和版本 | 不限于可数物体；不从数据集完整真值图初始化 |
| canonical world latent，m | 节点从已归属观测形成的世界表征 | 不等于某一张照片或目标 ID 的哈希 |
| evidence / latent refs | 指向具体观测或表示的可追溯引用 | 合并引用列表不等于学会向量融合 |

一次观测可以支持旧节点、改变位置、揭示新身份或进入待定记忆。结构/引用修订与数值修订分别评价；旧 M1 主要覆盖前者。不能先把新观测混入旧向量，再决定它属于谁。

拟议数值流程：候选在不可变旧世界上独立分配证据、形成对应表示，仅选中且成功执行的版本持久化。实际数组/张量也不能共享可写缓冲区；缓存引用绑定内容 hash。撤回错误绑定、SPLIT/MERGE 后按登记规则重分配证据并重计算表示，不只修边而留下被污染的向量。此能力仍待实现验证。

白话：输入是旧档案和本次证据，输出是可追溯的新版本。例如误混了另一把椅子的特征，修复时检查证据归属和表示两层；向量变化幅度大不自动等于语义损伤，正确修订也可能改变表示。

## 环境结构的纳入与扩充（planned；D-061）

Structural latent（结构表征）要保留局部墙/地面等空间支持、描述特征、参考坐标、可见范围、证据及版本；连接关系在可审查结构中显式保存，具体 schema 仍待 R2。白话：输入旧结构记忆和转角处新到达的区域观测，输出已确认的新结构及它与旧结构的关系。例如走廊 A 后发现转角及走廊 B，可以保留 A、建立 B 并登记有证据的连接；这不等于把全图压成一个平均向量，也不等于相机一转就把墙判成移动物体。

| 情况 | 期望的记忆行为 | 必须保留的边界 |
|---|---|---|
| 原墙面从新角度再次出现 | 关联旧结构、补充证据；投影随视角变，世界结构保持 | 图像位置变化不触发世界位置变化 |
| 同一墙/地面更远部分首次可见 | 几何与关联证据支持时扩大该结构的已观测范围，保存新版本 | 不无限外推；未知边界不等于墙体终点或不可通行 |
| 转角后出现方向不同的新片段 | 建立相连局部结构或子区域，记录相对几何与有证据的邻接关系 | 全局记忆扩充不要求强行合成同一平面、同一直走廊或单个 latent |
| 后续证据否定旧连接或发现重复片段 | 修订关系、拆开误合并或合并重复档案，重分配证据并复算表示 | 地图增长与纠错分开评价，旧结构离开视野不能直接撤回 |

候选语义仍优先在 BIND/BIRTH/RELINK/SPLIT/MERGE 等现有语言及基础操作中表达。关联证据是否更新几何支持、怎样表示局部结构连接、哪些断言属于可判断真值，须在步骤 07–10 明确；不能仅把旧 object 节点改名为 corridor 就宣称实现。结构提议仍固定/确定性，不增加 learned candidate generator；只沿记录轨迹更新记忆，不加入机器人动作策略或大规模导航任务。

可靠位姿和深度下可直接确定的几何增量，应先用确定性关联/融合形成基础对照，不能把累计了更多观测当作 CTL 独特收益。CTL 仍检验错误关联、重复结构、错接关系及不确定扩充候选的执行后监督；A–E 共享观测、结构前端和候选机会。完整离线重建只供单独审计，不能预先转成在线结构 latent。具体指标待审，至少区分结构覆盖、错误连接、重复片段、旧结构损伤和对象错误，未知区域不当作负例。

## 投影表示与视觉前端

Projective Node Orbit（PNO，投影节点轨道）是固定/轻量表征基础：输入世界节点 m、视角 T 和可见性，输出可与当前区域 z 比较的预测。

\[
z_{t,i}\approx\Pi(T_t,m_j),\qquad
\mathcal O(m_j)=\{\Pi(T,m_j):T\in\mathcal T_{\mathrm{reachable}}\}.
\]

这表示同一墙面或椅子换观察角度，仍应由对应世界节点解释；轨道不是机器人路径，也不要求生成未来 RGB。

前端拟保留 feature、support、depth、camera ray、pose、visibility 和 uncertainty。Local Structural Chart 指局部结构坐标表达：输入区域几何，输出可比较的局部坐标，例如转向时分别表达两侧墙面；它不把消失点直接当世界坐标，具体实现 planned。未知表面/不可靠几何应输出 unknown，不能把未见背面当作不存在的反证。

固定 DINO-family 的具体 checkpoint、区域提议和投影/transport 规则在数据审查后选择。更强容量只在信息可用而拟合不足等具体诊断后提出，并给 A–E 同等条件。大型视觉语言模型不默认作事务决策核心，其输出也不能作未经核验的真值。

拟验证对照包括 Exponential Moving Average（EMA，指数移动平均）/均值、去掉区域几何、pose/depth transport 或 visibility，以及 PNO。输入相同观测，输出不同表示的跨视角表现；它检验收益是否来自表征，不能把全部改善归于 CTL。

## 事务、生命周期与原子执行

事务输入旧世界和证据，输出合法新版本或原子拒绝。例如 RELINK 移动同一身份，REPLACE 则建立另一个身份，二者不是同一修改的两个名字。

| Intent | Template | 语义 |
|---|---|---|
| PRESERVE | NOOP | 持久世界不变 |
| ASSOCIATE | BIND | 给 candidate/confirmed 关联证据，不创建身份 |
| ASSOCIATE | REACTIVATE | dormant 身份打开为 confirmed 新版本 |
| EXPAND | BIRTH | 建立 candidate 身份；首次看见不等于物理刚出生 |
| REVISE | RELINK | 保持身份，关闭旧关系版本并打开新关系 |
| REVISE | RETRACT | 关闭被可靠反证否定的事实/边，保留身份与历史 |
| REVISE | SPLIT | 关闭错误混合身份，建立至少两个 successor，证据恰好一次分配 |
| REVISE | MERGE | 合并重复档案证据，保留 canonical 与其他身份的 alias 历史 |
| COMPOSITE | REPLACE | 有序 RETRACT→BIRTH→ADD_EDGE，保留旧身份，不偷换成 RELINK |

生命周期与版本结束时间分开：candidate 待确认；confirmed 已确认；dormant 暂不活跃但可重激活；retracted 已否定且不能直接复活；alias 指向 canonical。valid_to 只关闭一个版本，同一身份同一时刻至多一个 open version。

既有 D-019–D-025 约束需在重构时显式兼容审查：BIRTH 不自动 confirmed，升级由 program 显式执行；独立 BIND 支持可促成确认，重复 time/view 证据保留但不重复增加独立权重。SPLIT 不向 successor 直接复制旧 aggregate latent。MERGE 按最早 valid_from、再按 ID 排序选 confirmed canonical，其他 source 新版本成为 alias。普通 node-level RETRACT 尚未实现，不能把 visible-empty 当身份从未存在。

旧 M0 的可靠缺席要求至少两条不同 time/view 的 online visible-empty、有效 pose/depth、可靠度达标且中间没有正观测；新数据阈值另行审查。白话：遮挡、视野外、漏检不等于“那里确实空了”，不能一次没看到就删除身份。

Primitive operations 是程序的基础写操作：ASSERT_PRECONDITION、CREATE_NODE、OPEN/CLOSE_NODE_VERSION、ADD_EDGE、CLOSE_EDGE_VERSION、ATTACH/MOVE_EVIDENCE、SET_CANONICAL_ALIAS、SET_LIFECYCLE、RECORD_PROVENANCE。它们将事务编译为受检查的顺序，不允许物理 DELETE。

\[
S_t^{(u)}=\operatorname{Execute}(\operatorname{Clone}(S_{t-1}),u).
\]

每个候选都从同一旧世界独立开始，前一个候选不能改变后一个候选的起点。

Versioned Deterministic Executor（版本化确定性执行器）检查 base version、precondition、引用、intent/template、生命周期、保护范围、provenance、幂等性与原子回滚。同输入/config 得同结果 hash；无梯度、不读未来，失败不得半写入。它保证修改被正确执行，不保证模型选得正确。

## 暂存与保守等价

QUARANTINE 是低置信度提交 wrapper，不是世界事务。输入暂不足以提交的证据，输出独立 pending 记录；例如模糊椅背先保留检索线索，之后再关联。它不修改 persistent world；NOOP 是选择无需修改。

Pending Memory Manager 保留弱证据、粗略表示、来源、假设和独立性权重。只在相关且可能消歧的观察机会计数；多次仍未解决可归档但可检索，消费须保留全部 evidence 与 consumed_by_transaction。旧 M1 固定 gate 与新视觉策略分开，不把通用 wrapper 说明冒充旧运行实际策略。

Canonical memory-state equality 是保守状态相等：输入同一 base 后两份世界及允许的身份映射，输出是否相同。例如只改新内部 ID 名字可比较，证据归属或历史不同不能只因 active graph 相同就合并。

既有对应合同：锚定/未声明身份固定；exchangeable 身份仅在显式集合内双射；新 local ID 可重命名但不能映到旧身份。映射后生命周期、事实、版本历史、evidence/latent 归属、protected 与 pending 一致。未来投影相似只用于评分，不定义世界等价；评价可只比较可判断语义子集，但另报证据/历史差异。

## 候选与在线提交

确定性候选只读取允许的当前观测与自身旧记忆。合法外观、几何、证据配对可以使用；内部 ID 只作寻址，不把正确目标、真值颜色、参考事务参数或其哈希编码成 query。旧 M1 的 reference_spec→query→候选/编码通道不复用于新协议；只去掉学生的 merge_queries 不足以修复仍依赖它的候选器。

K、排序、去重、不可用槽位、完整/部分修复机会在新协议单独登记，不为保证正确候选出现而补答案。保护 scope/mask 的上游来源同样审查。

拟议部署路径：固定候选与静态预检→网络选择→执行选中事务→新版本；训练/评价审计可展开全部候选。旧 M1 共享生成器执行过分支做 canonical 去重，不能据“网络不读 post-world”宣称整个系统只执行一次。新旧候选、mask 和提交结果需等价检查，系统成本不能只记网络前向。

Global reconciliation（全局记忆协调）是 M2 明确保留的慢速修订：输入截至当前已积累的证据、版本历史与相关子图，输出同一执行器接受的跨对象/较长历史补偿事务。例如快路径把同一椅子建成两个档案，后续重访支持 MERGE 并修订相关关系；它不是主动寻找新视角，也不回填过去正确性。实现仍 planned，具体步骤为 PLAN 的 29a–29d，不能把该能力从 M2 完成清单省掉。

慢路径同时覆盖结构关系：例如后续重见证明两个局部墙面档案重复，或先前把新走廊接错位置，可在累计证据支持下提交补偿事务。这仍是 planned，不能只实现对象 MERGE 就宣称结构协调也已完成。

三种过程分开：离线事后教师利用训练序列中已知的后续观测形成监督；在线快路径用当前观测即时提交；在线慢路径利用截至复核时刻的累计证据重新检查历史。慢路径不能读取尚未到达的未来，也不自动等于在线更新网络参数。

慢路径先冻结触发、截止时间、历史范围、候选预算和失败策略。若后台计算期间快路径已改变 base version，提交前必须拒绝过时结果或按登记规则重算，不能覆盖新提交。恢复同时检查事实、证据归属和数值表示，旧错误及其持续时间仍留在评价中。

公平比较包括 A/C/E 各自有无同一慢路径规则，并记录实际触发次数、等待时间及全部计算。不同自身状态可能导致不同触发，不能伪称每条轨迹机会相同；必要时在配对快照上固定证据/机会诊断。快慢双路径本身不独立包装成 CTL 创新，额外证据和算力的收益不能全部归给监督机制。

## 事后教师与在线学习

Hindsight teacher（事后教师）输入执行后的候选世界及当前/后续观测，输出监督分布。例如后来清晰可见的空位支持关闭旧位置关系；它不是在线预知未来，也不是直接读取正确对象 ID 的对应器。

\[
E(u)=\lambda_nD_{now}(u)+\lambda_fD_{future}(u)
+\beta C_{edit}(u)+\gamma C_{growth}(u)+\eta C_{collateral}(u)+I_{illegal}(u).
\]

分别衡量当前解释、未来解释、修改量、增长、连带影响和非法性，一个总分不能代替六项记录。

now/future 对可用观测评分；edit/growth 属预登记正则；collateral 检查非必要范围的影响；illegal 排除非法候选。每项保存原始值、numerator/denominator、mask 和权重。visible-empty、occluded、out-of-view、unknown 分开。未来物体再次变化须用声明的推进/对应规则处理，不能重放正确后续事务，也不能暗用真值身份。

\[
p^*(u)=\frac{\mathbf1[u\text{ legal}]e^{-E(u)/\tau}}{\sum_v\mathbf1[v\text{ legal}]e^{-E(v)/\tau}},
\qquad \mathcal L_{CTL}=KL(\operatorname{stopgrad}(p^*)\Vert q_\theta).
\]

教师对更能解释观测的修订赋更高权重，学生拟合该比较；创新假设在目标从执行后世界形成，KL 只是实现手段。无合法候选须显式失败或执行已定义 wrapper，不伪造概率。

学生只读截至 t 的观测、旧记忆和候选，不读未来、post-world 正确性或真值。人工事务标签单列预算；多个有效候选按已审查集合标签处理，不强制唯一参考索引。新教师/标签规则待审，旧损失以原配置和源码为准。

## 对照、训练与评价

| 方法 | 监督职责 |
|---|---|
| A：CTL | 执行后候选世界形成当前/未来监督 |
| B：Direct classifier | 直接事务标签 |
| C：Direct + future loss | 不读取候选 post-world 的直接未来辅助目标 |
| D：Execute current-only | 执行候选，教师去掉 future |
| E：Future scorer without execution | 不执行候选 post-world 形成预测目标，学习未来评分并监督在线选择 |
| F：Oracle | 独立审计答案下的候选上界，不是可部署模型 |

A–E 共享前端、在线字段、候选机会、分组和合理参数/调参预算；C/E 有同等可用未来观测和合理容量。E 的额外 scorer、A 的执行、C 的辅助目标均计成本。相同学习率不等于充分公平。

训练顺序是开发组选参→锁定配置→完整训练/保存加载核验→独立确认。Teacher-forced 输入参考历史，自身状态 self-rollout 承受此前错误，分别评价；自身状态训练若使用，只来自训练数据并单独登记。

拟议标签效率为 0%/1%/10%/100% 事务标签：同一观测和固定语言/执行器下，输出不同人工标签量的表现。例如 0% 仍用未来观测和结构先验，不称完全无监督。

| 评价 | 含义和边界 |
|---|---|
| candidate miss | 实际候选无正确修订，不算学生错；未知答案另列 |
| teacher / amortization error | 正确候选存在时，分别检查教师和学生的选择 |
| 语义与证据正确性 | 位置对但证据绑定错另计，内部编号不同不直接等于世界错 |
| 完整/部分修复机会 | 撤错边却补不回节点只算部分机会，不推出所有多步路径不可能 |
| 错误持续负担 | 累计 extra/missing 事实，终点修好不抹掉前面错误；未知实际时间按决策次数计 |
| 无关损伤、增长、恢复 | 检查不应变部分、多余节点、恢复分母；无机会写 null，向量变化大不直接等于损伤 |
| 成本 | 完整系统时延、存储、教师/学生训练和实际失败 |

评测器读独立审计真值，不用教师能量作正确性。active-world、open-memory、历史 exactness 和程序索引分别解释；主要指标、安全条件、A−C/A−E 和多重检验在新确认前冻结，不直接套用旧数值。按场所/真实独立组配对，帧与 learner seed 不能扩充独立样本数。

A 与 C/E 无可靠差异时不支持执行后监督独特优势；覆盖低先查候选器，教师好学生差查学习，单步好连续差不支持长期记忆。教师分布变化不等于学生收益，表征改善不全归 CTL。负结果、歧义和失败保留，论文主张见 EXECUTE 的证据表。
