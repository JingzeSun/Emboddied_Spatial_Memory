# 空间世界模型候选与历史方法合同

## 当前候选：空间历史对动作后果预测的作用（D-062，proposed）

研究问题：近期传感器信息和机器人控制指令相同，但早期观察揭示了不同遮挡区结构，模型能否预测不同的视野外交互后果，并改善固定候选动作的选择？输入为合法历史、候选控制和共同目标；输出为未来物块位置序列与接触判断。例如左侧挡板曾经可见，后来完全被遮挡，同一左推控制应与没有该挡板的场景产生不同预测。这不是证明“显式三维状态必胜”，也不是输入物体目标位移后生成视觉效果。

首轮采用固定物理参数、一个平面运动任务物块、一个笛卡尔推杆和固定观察路径。Cartesian pusher（笛卡尔推杆）是可按世界坐标速度指令运动的简化机器人末端；输入每段速度和持续时间，输出机器人及物块响应，例如向左前方推。这不是复杂机械臂抓取，也不能把物块实际位移当作速度控制。SH-02/v2的单对工程检查和审查已完成，证据见LOG-105；具体数值见下文。手工合同示例仍不代表物理结果。

### SH-03 固定开发物理审计（v1结果见LOG-106，v2服务器验证pending）

白话：这一步解决“只在一个特意搭好的场景里出现预期碰撞”的问题。输入已验收的推杆模拟器和事前登记的16种设置，输出每对场景的真实轨迹、画面以及逐项通过/失败。例如挡板从y=0.60 m改到0.52 m后，仍需检查物块是否真的在视野外碰到它；这不等于模型已经学会预测，也不等于16个独立随机环境的泛化评估。

固定组合设计（fixed factorial design，逐一覆盖登记参数的组合）采用墙中心y为0.52/0.58/0.64/0.70 m、共同物块/推杆起点x为−0.02/+0.02 m、历史弧线采样数为13/23的全部16种组合。它检验三种具体变化，输入参数表、输出完整案例清单，例如0.52 m、−0.02 m、13帧组成sh03-00；它不是搜索最容易成功的参数。case_id与顺序固定于development_audit_v1.json，整个家族仅为development，不计算把这些相关组合当成独立随机样本的置信区间。

每个组合内仍只有隐藏墙的左右位置不同；共同起点变化时，相机瞄准点x随之平移，两个世界的相机信息保持一致。弧线时长为1.2/2.2 s，随后仍保留2帧相同近期观测，总历史为15/25帧。相机轨道半径、高度、分辨率及屏、物块、推头、控制、物理参数与阈值保留。每候选49段控制、4.9 s、2450物理步；64条不同分支另做64次独立反序重放。重放用于检查恢复和执行一致，不是额外数据样本。原SH-02生成器字节不改，新增适配器仅准备配置、区分记录编号和汇总判定。

固定通过条件为16对全部满足：成对输入合同与早期视觉差异、正确的2×2分支顺序、首帧墙至少4像素、近期墙0像素且目标可见、完整非布局初态相同、观察不改积分状态、4次独立重放一致、撞墙模式[真,假,假,真]、确有2条障碍接触分支且每个已记录接触物理步目标像素为0、无物块撞屏、高度/倾角/执行器力保持原范围、两个同动作跨世界终点距离都至少0.05 m。实现将这些归为13个布尔检查；零接触不能使遮挡检查空通过。

完整生成但不通过的案例保留，继续完成固定清单并报告全部失败，不补样、不只导出通过子集；运行异常则停止余下案例。若审计失败，先读具体轨迹再登记必要修复，不能直接扩模型。当前goal半径0.5 m不改，它不能直接充当有效动作选择评分；后者仍需SH-04另行冻结。新批次验收不借用旧32项回执：先在服务器运行新增8项适配/拒绝条件测试，再生成审计数据。8项测试通过也不代表16对物理条件已经通过。

SH-03/v2墙角间隙修订（implemented，物理效果未验证）：白话，这个修订处理物块在预期通过方向擦到墙内侧角点的问题。输入原16组设置和相同控制，把两世界挡板中心分别从x=−0.31/+0.31 m移到−0.33/+0.33 m，输出重新执行的完整16对轨迹及原13项判定。例如sh03-00中的右推动作原来有8步墙接触，需要验证移动挡板后是否真正消失；这不是把短接触从标签中删除，也不表示已经修复。

挡板尺寸不变，因此内侧边从x=±0.02 m移到±0.04 m；这是左右两个反事实世界各自的墙边位置，不是往单个世界同时加入两面墙。2 cm是依据已记录的墙角擦碰选定的一次开发期几何修订：把旧4例首次额外接触的物块位姿固定下来，仅计算平面圆盘到新墙角的几何净距，得到约18.09–18.50 mm。这个只读计算用于解释选择，不是新动力学轨迹、全程间隙保证或参数最优性证据；物块倾角、推杆与墙的接触变化都仍须真实模拟检查。

该修订统一施加给原16例，墙y/起点x/历史长度组合、候选控制、物块/推杆/屏、相机、物理参数、goal和`assess`判定保持不变；可能同时影响应有碰撞，故全部16例重验，不复用v1的12个通过状态。先运行原8项加新增4项测试（共12项），验证几何改动范围、拒绝未登记间隙/缺失来源、v1不接受v2字段，以及额外隐藏碰撞仍不能通过。v1是已完成失败，v2是参考开发失败作出的受控修订，不把它称为独立未见场景确认；若仍失败，保留结果，不自动继续增大间隙或筛例。

### SH-04 研究问题与架构复审（D-068，proposed）

用户要求现在收紧小实验，并先查世界模型论文及旧CTL/CPMT架构。首帧已揭示左右布局、历史仅1.4/2.4秒、固定左右类别对应碰撞标签，使SH-03适合工程检查，但不能单独检验持续空间整合；连续轨迹和动作评分是否由首帧充分求解尚未实测。下方v1数值提案保留作审查历史；96对数据、18次训练、原停止门不再作为下一实施依据。新架构、数据、损失及预算尚未冻结。文献依据集中在[本轮核查](../literature/notes/spatial_world_models_2026.md)。

**建议研究对象：由受限视觉历史形成的状态，能否支持未见几何—控制组合中的视野外交互预测。** 白话：输入几个视角分别看到的结构、近期共同观测和真实控制，输出未来物块位置/接触及候选后果。例如两个不共视的局部结构共同决定推过去是否受阻；仅识别“左侧有墙”不应决定全部答案。这是待验证的任务候选，不是已经发现新缺口，也不要求先做复杂操作或开放世界。

场景审查需检查三种互相区别的能力：跨视角组合几何；证据离开近期窗口后仍能取回/保留；由控制与几何预测接触。必须记录每项实际需要的信息，不能仅加帧数、重复静态画面或延迟就称为更强记忆问题。主场景应给出同一单视图对应多个不同合法后果、完整历史可区分的具体记录，不能只凭模型单帧准确率低声称信息不足。关键证据位置变化、每帧/元数据的捷径及未见组合划分先审；首帧/一般检索成功是有效否证，不能据其成功反复换题。

**工作架构候选（不是创新主张）。** 输入RGBD/相机位姿/本体/过去动作，经冻结视觉编码及几何对齐形成观测；历史模块更新状态；预测模块只根据该状态和拟执行控制推演后果；固定候选评分消费预测。每个控制分支从相同决策状态独立开始，想象轨迹不能被写回为实际观测。输出可读位置/接触，暂不做高质量视频解码器。主排名不访问真值地图/初态；这些只能进入独立诊断。

| 模块候选 | 输入→输出、具体问题及非等价关系 |
|---|---|
| 完整历史Transformer | 全部合法历史特征＋控制→后果；例如直接读取两个旧视角。保留为架构对照，不把手写4层网络称作DINO-WM |
| Recurrent State-Space Model（RSSM，循环状态空间模型） | 上一步状态＋新观测/动作→更新状态，再以未来控制推演；例如相机转走后仍保留挡板证据。按DreamerV3代码参考设计，离线状态监督适配不等于完整Dreamer复现 |
| 几何检索与观测地图 | 历史RGBD/位姿→少量相关帧或观测几何；例如检索两个互补视角。完整历史和检索不可被故意截掉必要证据；真值选帧只能另列诊断上限 |
| 共享地图上的动力学 | 同一估计地图/初态＋控制→轨迹/接触；比较准静态、重建MuJoCo，必要时再审学习交互网络。图消息传递依据PropNet/GNS，不称其自身为新机制 |

上述不是一次训练所有系统的授权。D-073取消默认优先运行DINO-WM，先核验DreamerV3、PointWorld、FloWM分别作为后果评分、三维动力学、历史记忆对照的条件；具体出版与资产证据见[文献核查](../literature/notes/spatial_world_models_2026.md#reviewed-baselines-20260912)。必须将基础架构、原设定权重重评/训练复现、迁移适配分别验收。只要改变监督、输入或动作含义就列清差异。纯视频监督若无法区分隐藏后果，其失败不能归因于记忆；状态监督的读出头是否回传梯度亦需事先写明。

白话（以下适配均planned）：DreamerV3用历史观测和控制更新循环状态，并预测未来奖励；例如对四条固定控制估计送达收益，用来检验普通循环世界模型是否已经够用。只抽取世界模型离线学习不等于完整Dreamer策略复现，奖励正确也不等于轨迹/接触正确。PointWorld把场景点云和机器人计划几何运动变成未来场景点流；例如估计箱子受推后的点位置。它的原路径实现假设不能替代本任务有限力控制，公共历史建图和控制适配须单列，绝不能输入执行后真实推头轨迹。FloWM把旧观察保留在随自运动对齐的状态中并推演动态；例如相机转走后仍预测旧物体的位置。把它改为接收推头速度控制、输出接触/送达是新任务适配，原有视野外预测结果不证明这种适配成立。

另一个已评审候选ParticleFormer以对象/末端点云、运动和材料编码预测下一步点位置，用来处理多物体材料交互，例如推箱子；它不是长历史记忆系统。本轮未核得官方可运行实现/权重，不能以自写相似Transformer冒充复现。DINO-WM仍可作视觉特征预测参照，但须先检验其完整未来监督是否能区分本任务后果；R2所有末帧PNG相同只说明末帧，不能外推整段未来RGBD/本体都相同。新增统一后果读出时分别登记冻结表征诊断和允许回传梯度的任务适配，不能混报。

### 三条适配路线与模块组合（D-074，planned）

白话：模块划分是为了定位模型到底错在“没看清、没记住、推演错还是选错”，不是把三个论文名字串起来就算新方法。输入统一的公开历史、机器人控制与目标，输出后果预测及固定候选评分。例如先从两个旧视角保留两门，再推演物块能否依次穿过；记住门不保证能预测接触，预测轨迹也不保证评分正确。下表是功能划分，原论文实现并不保证能原样拆开。

| 功能 | 输入→输出与例子 | 三个模型中的对应关系 |
|---|---|---|
| 观测编码 | RGBD、标定/位姿、本体→观测特征或测得的点；例如把旧帧墙边定位到共同坐标 | 三者都有自己的观测前端；公共输入权限相同不等于必须强行换成同一个编码器 |
| 历史状态 | 过去状态＋当前观测→决策时状态；例如保留A/B两门证据 | DreamerV3的循环状态、FloWM的空间记忆；PointWorld需配公开历史建图/检索前端 |
| 动态推演 | 决策状态＋拟执行数值控制→未来状态序列；例如预测物块碰门后停下 | DreamerV3的潜状态转移、FloWM的动态记忆推进、PointWorld的场景点流预测；后两者都须适配动作语义 |
| 后果读出与评分 | 预测状态＋共同目标→位置/接触/成功预测及四候选分数 | Dreamer原奖励头可供参考；三条都要有任务读出，统一评估规则。不能把Dreamer奖励头直接套在别人的隐状态上 |

三个独立适配系统均须交付（实现和训练另按依赖审查）：

1. **DreamerV3适配**：保留观测编码—循环状态—控制条件转移的主要结构，补齐合法RGBD/位姿输入、完整历史和任务读出；用固定候选推演替代策略选动作。检查非显式地图记忆能否解决任务，不称完整在线Dreamer复现。
2. **FloWM适配**：保留空间组织的记忆、观测更新和动态推进机制；分别接入连续相机变换及独立推头控制，补齐深度/本体和后果读出。检查空间记忆是否更利于组合旧结构；不能只关闭等变更新、改成普通网络后仍称原机制已比较。保留机制、必要替换及其消融须具体登记。
3. **PointWorld适配**：公开历史形成场景几何及关联视觉特征，配合控制到计划/预测机器人运动的模块，再作三维点流推演和任务读出。检查显式场景加学习动力学能否解决任务。机器人受阻时不能使用执行后的真实路径补齐，控制模块误差需与场景动力学误差分列。

三者先保持各自有意义的内部状态，只统一外层输入权限和结果语义。共同输出接口至少覆盖未来物块位置、接触及按原整段规则定义的任务成功/候选评分；未实现字段明确缺失，不能用奖励数字冒充轨迹。具体张量、单位、时间采样、缺失处理、读出结构、标签权限和梯度范围已在下方[D-079规格提案](#r4-common-contract)登记，实现仍待审查，不把当前工程四世界直接划成训练集。

**可组合，但先做独立适配，再做有明确问题的模块替换。** “FloWM历史状态→场景读出/转换→PointWorld动力学→共同任务评分”仅为待审的组合示例，是否实施由独立比较暴露的错误决定，不预设为最终架构。白话：转换模块输入FloWM保留的历史状态，输出带坐标、尺度、可见/未知区分和对象对应的场景点及特征；例如把记住的两门表示成PointWorld可读的结构。它不自动得到真值地图，也不是免费转格式：若要学习，必须记录监督、额外参数、训练成本和误差；对象速度、当前动态物体与静态旧几何不可混淆。Dreamer状态接PointWorld同样需要这种显式转换，不承诺隐空间直接通用。

模块比较应一次固定一侧：比较记忆时，令合法检索/观测地图与FloWM读出使用同一PointWorld推演和评分；比较动力学时，在同一公开估计地图和机器人控制适配条件下比较简单动力学与PointWorld。原生Dreamer/FloWM潜动力学不能为方便对照被强制解码成点云后冒称原生性能。转换后的混合系统单列名称与成本，不覆盖三个独立适配结果，也不自动启动全排列组合。

不将三个现成权重机械串联为“FloWM记忆→PointWorld运动→Dreamer奖励”：Dreamer的奖励头依赖自身训练出的状态表示，跨模型评分应采用共同任务规则，或另行训练并公平登记的读出。组合本身不构成创新；若长历史、检索或地图加简单动力学已足够，仍应如实收口。

### 同一研究流程中的独立比较与失效条件（D-074补充，proposed）

**共同框架统一研究问题、合法信息、物理任务与证据链，允许三个系统保留不同的内部机制。** 用户明确更关心各方法在相应方面何时失效，以及这些能力能否共同支撑更通用的系统。因此三个独立适配均进入同一流程：公开历史 → 决策时状态 → 固定机器人控制的后果预测 → 候选选择 → 实际后果核验。模块划分服务于解释错误，不要求三个模型变成同一种网络，也不以各自原任务指标各赢一项作为本项目结论。

白话：同一条控制在两种早期历史下可能分别通过和卡住，三个系统都要给出自己的预测和选择，再追查差异在哪一环消失。例如FloWM保留的旧结构看起来正确，但后续接触推演错误，应核查动力学与控制适配；这不等于空间记忆无效，也不能用记忆可视化好看来替代任务成功。下述流程与诊断尚未实施，表中是待检验的问题，未认定任何模型已经失败。

| 独立适配系统 | 对本项目优先检验的问题 | 支持定位所需的证据 |
|---|---|---|
| DreamerV3 | 两段互补旧证据能否保留在循环状态中，并在相同控制的推演中产生正确后果差异？预测收益正确时，位置与接触是否也正确？ | 完整历史覆盖及状态初始化记录；同控制跨世界的预测差异；状态读出诊断与实际后果分别报告。不能仅因状态难以解释就认定没记住 |
| FloWM | 空间对齐后的历史是否支持连续控制引起的视野外变化？旧几何保留正确时，动态推进和接触是否仍可靠？ | 连续位姿/推头控制适配的核验；保留结构、预测位置/接触与任务选择相互核对。必要替换须与保留的原机制分开说明 |
| PointWorld | 公开历史形成的场景与合法计划机器人运动，能否支持长时段的接触后果预测？计划运动与有限力实际执行不一致时，错误来自哪一侧？ | 历史建图及旧视图特征误差；控制到计划/预测机器人运动的误差；在可比场景输入下的点流推演误差。不能把执行接口失配全部归因于场景动力学 |

**共同评估与原机制诊断分层报告。** 共同任务层比较未来物块位置、接触、原整段成功及固定候选选择；原机制层保留各方法有意义的状态/点流/观测预测证据。三者接入任务读出时登记新增参数、标签、冻结或回传梯度范围：冻结表示上训练读出用于检查信息是否可被提取，允许任务梯度进入主体则是任务适配，两种结果不能合并。例如冻结读出能识别两门只证明该读出提取到了信息，不证明模型推演真正使用了它；读出失败也不能单独证明状态中完全没有信息。原生输出缺失属于待适配，不直接计为论文失败。

共同任务层沿用原控制和任务含义：在R2工程接口中，每条候选为200段、每段0.1 s的世界坐标速度控制；每个候选从同一决策状态独立推演，不能读取未来观测或实际机器人路径，也不能把某一分支的想象状态带入下一分支。拟议位置/接触输出按控制间隔对齐，而成功标签仍来自原物理步级判定；每0.1 s的位置采样及最后一帧不能准确替代按序过门和19–20 s整段稳定条件。模型可有不同内部时间步，但对齐方式、200段覆盖及额外计算必须明示，不因原生预测短就只评容易的前段。

失效条件须由事先登记的条件与全部逐例结果支持。下面给出可审实验设计：先检查信息通路，再定位错误；不预先把某个模型指定为某类失败。具体模型接口、探针训练数据、容差与资源仍须在实施前登记。

**公平性统一权限与任务，另外披露资源差异。** 三条适配使用相同的数据划分、合法历史和候选控制、共同任务标签权限与评估规则；各自原生辅助目标、外部预训练数据/权重、可训练参数、调参次数、显存和耗时分别登记。相同训练步数不自动代表训练充分或计算量相同；额外状态监督不得只给其中一条后仍称同监督比较。长历史预测器、合法历史检索、地图加简单动力学与三条论文适配共同承担主对照，三个论文名称不能替代这三类信息充分的检验。

**通用性的后续证据要求。** 当前双门四世界仅是已见工程家族，16条分支不是16个独立场景，也不据此宣称通用世界模型优劣。后续需按冻结协议检查未见几何—控制组合，以及再后的独立具身来源；共享的输入输出语义不应依赖LL/LR等类别、文件名或私有门位置。几何组合、证据出现位置/间隔、推演时长等只是可审的条件轴，当前不新增数据或授权全组合实验。模型在登记范围内成功同样是结果；只有公平适配后仍重复出现、且有证据定位的缺口，才据此选择SH-06的单一改进机制。更广泛的适用性由跨条件证据支持，不由模块数量或论文名称支持。

### 历史信息到错误动作的诊断实验（D-075，proposed，未运行）

白话：给同一条预测链设置几个检查点，输入合法历史和固定控制，输出“刚看到时能否读出结构、决策时能否读出、未来预测是否正确响应、成功分数是否排对”的连续记录。例如远门的右开口在决策状态里可读，LL控制的预测却没有体现受阻，就能把问题缩小到状态之后；这还不能唯一断定动力学坏了，因为任务读出也可能遗漏信息。此实验先形成可审设计，不在已见四世界上拟合模型/探针，也不把诊断器当作新世界模型。

**实验单元与复用。** 一个工程单元仍是原四世界家族：4条完整历史，各自从同一决策状态推演4条控制，共16条预测，与原16条首次物理分支匹配；反序重放只验证确定性，不作为第二份真值样本。对三个适配及长历史、合法检索、观测地图加简单动力学分别记录，不能用混合系统替代其中一项。近期2帧条件另从空状态开始，禁止使用完整历史缓存，只作信息不足参照。正式模型/探针的训练、选参及独立确认使用后续另行冻结的家族，当前单元仅用于工程演示，重复时间步/控制/种子均不冒充独立场景。

| 检查 ID | 固定与改变什么 | 具体读取和输出 | 支持的判断 |
|---|---|---|---|
| E0 公开信息正向检查 | 固定公开RGBD/标定权限；分别检查A/B观测和完整历史形成的观测几何 | 只从观测恢复门边位置、来源帧及未知区域；私有真值仅由评估端计算误差 | 先验证必要结构能被合法观测恢复。恢复器失败仍可能是算法失败，不能直接宣称观测信息不足 |
| E1 编码与保留检查 | 冻结已训练主体；按历史前缀记录观测编码和状态 | A/B时刻的观测编码；登记历史检查点的状态；独立训练的几何读出误差 | 区分刚看到时可提取、后来仍可提取，或可提取性下降。探针失败不能证明信息完全不存在 |
| E2 同控制结构干预 | 模型和数值控制固定，只换一个门不同的完整真实历史 | 四条单门配对边×四控制，核对真实与预测的轨迹/接触/成功差异 | 判断相关历史是否转化为正确后果差异；单看输出变了不算正确利用 |
| E3 推演过程检查 | 固定决策状态和控制，开环推演全20 s，不读未来观察 | 全部200段位置/接触输出；0/5/10/15/20 s原生预测状态的几何读出 | 定位差异在决策前、推演期间或任务读出时出现；最早定位仅到采样区间 |
| E4 错误动作检查 | 固定E3输出及原整段成功标签 | 成功概率、候选排序、实际选择代价；另列冻结未来状态上的成功诊断读出 | 区分选择器实现错误、分数排序错误，以及预测状态中存在但主读出未提取的决策信息 |

**E0先检查“看得到并可测得什么”。** 目标是恢复可观测门边的世界坐标，而不是从图像分类LL/LR。A/B语义下标只供诊断切片，主模型/合法检索不能收到正确选帧标签；观测建图也不能按私有门位置取点或把未观测区域填成自由空间。完整历史恢复成功仅支持被核验几何量的可恢复性，不证明模型学到了它们或已足够预测物理。公开几何恢复已按下方D-078以独立worker调度实现并完成服务器运行，结果与支持范围只登记在[LOG-110](../EXECUTE.md#log-110e0公开开口恢复并行运行与服务器结果审查)；E1–E4仍为诊断设计，不能从E0结果推出模型已经恢复或利用了历史。

**E1的冻结探针（frozen-state probe，主体不更新的诊断读出）** 用于检查一个固定读出能否从状态提取任务相关结构。输入为指定层的观测编码或历史状态，输出两门内侧边界的连续坐标；例如读出近门的左边、右边及纵向位置，目标字段见DATA。真值坐标只进入独立探针的训练目标/评估端，不进入主体、主任务头或选择器；不能只拟合四种已知类别。

R2的历史状态检查点拟定为原帧下标`25,40,49,65,81,89,101,120`，分别覆盖A、近门证据段末/其后、B、远门证据段末/其后、近门再次出现后及决策时；观测编码单独取25/65。每个检查点只能消费截至该帧的前缀。批量编码完整121帧后再截取早期token不能冒充前缀诊断；递归增量与从空状态重放同一前缀的对应关系须先工程核验。主预测始终使用完整合法历史，这些抽样点不限制主模型的历史窗口。未来新家族的检查点依据预登记观察协议确定，不按模型失误选择。

主体训练完成后锁定checkpoint，再用另行冻结的训练家族拟合诊断读出，验证家族选参，确认家族只评估。每种状态接口的同一读出跨登记时间点共享；诊断侧分开报告“已经有观测证据”的几何量，未见部分标未观测，不用猜中未见结构冒充记忆。模型间不同形状可用各自登记的适配读出，但不把探针分数直接当作统一架构排名。必须登记读出容量、样本与优化上限，并设常量预测和按家族打乱目标的负对照；已知观测几何输入作为正向参照。探针的跨时间泛化需验证；不能凭早期读出好、晚期读出差直接把表示变化叫作遗忘。以上训练均未获预算，不在本轮运行。

**E2的完整真实历史配对** 避免以相互矛盾的拼接图像作为首个干预。原工程四世界仅供审计命名：改变远门的边为`LL↔LR`、`RL↔RR`；改变近门的边为`LL↔RL`、`LR↔RR`。每条边复用四条相同数值控制，共16个配对核对，全部来自原16分支的重组，不需新增物理执行。按实际结果分别检查成功变化与成功不变的项；成功不变不代表轨迹或接触也相同，不能从名称推导标签。比较整个真实历史提供的是“布局改变引起的合法观测整体变化”的行为证据，不能直接证明模型只利用了门边而非相关视觉线索。

配对位置误差`pair_position_error_m`定义为：每个对齐时刻先求两世界的预测位置差，再减去实际位置差，取三维长度后沿未来时间平均，单位米。白话：它检查模型是否预测对了历史差异造成的位移差；例如两世界实际分别通过和卡住，模型却预测相同轨迹，就会漏掉这部分差异。它不替代各世界本身的位置误差，因为共同偏移可能在相减时抵消。接触概率与整段成功概率同样报告有符号的预测差及对应真实差，不能只统计预测是否变化。近期条件的相同输入须产生同一预测分布；随机模型的配对比较需按登记样本数和对应随机流控制采样噪声，分布不同与单次采样不同分开。

**E3区分“状态里有”与“后果预测对”。** 决策状态能读出两门、E2却不能正确响应时，先记为“可读几何未转化为正确后果”，不直接写“没有使用历史”。继续检查未来状态中的几何读出、原生预测及共同位置/接触头。历史观测更新后的状态与开环预测状态可能有不同分布，几何探针的独立训练/验证必须覆盖登记的两类来源及未来时刻；尚未验证这种适用性时，未来读出下降仅记`probe_domain_unverified`（诊断读出在该状态来源上尚未核验），不能当作推演遗忘。排除这一解释后，下降才支持保留不足的候选解释；结构仍可读而轨迹错误支持控制/交互或读出环节继续定位。注意力热图、潜状态距离或梯度非零只作辅助记录，不能替代真实后果核对。PointWorld的计划/预测推头路径另与实际执行核对，实际路径仅在评估侧出现；执行误差不归并为物块动力学错误。场景点到任务物块的对应须由公开前端/登记读出形成，不能靠评估侧真值对象mask完成主预测。

**E4分别检查预测分数和选择器。** 主选择依据四候选整段成功概率最大值；严格并列时，诊断报告按最大值候选间均匀选择计算期望实际代价，明确这是期望值，不声称进行了随机执行。动作regret是该代价减去同世界真实最优候选代价；例如所有分数相同而只有一条成功，就如实体现无法分辨的选择损失。缺失、非有限或越界概率记为推理失败，不能补零、删候选或用真值打破并列。任一候选预测不合格或实际任务标签缺失/为null时，该世界的四候选代价与regret记不可计算，保留原因和分母；不能对剩余候选重归一化，也不能把物理无效填成代价1。选择器违反登记排序规则属于工程错误；遵守规则仍选错，则检查预测分数为何错误。

成功诊断读出输入冻结的未来预测状态序列和公开目标，仅用训练侧原整段成功标签训练自身，不更新主体。若其在未参与选参的家族上改善排序，支持“另一个读出提取到了决策信息”，不证明原生物理预测全部正确，也不能把诊断器的最好结果回填主排名。若位置/接触看似正确而成功分数错误，仍需保留归因未定：200个控制末采样不足以还原物理步级按序过门、物块完整投影及19–20 s整段停稳。不能把粗轨迹准确直接判为成功头单独有错。

**条件性干预只用于缩小解释范围。** 最小E0–E4不要求给模型真值地图、实际未来机器人运动或跨模型潜状态。在已适配的显式场景接口上，可另行登记“同一公开地图＋同一合法控制适配，替换简单动力学/PointWorld”的单侧比较；历史检索或记忆读出也只有经过可审转换后才可接相同预测器。一个替换改善不证明唯一根因，多个环节可能耦合；接口不兼容时记未比较。真值修复若后续单独获准，必须标特权诊断和额外信息，不能计入可部署成绩。

**交付判读。** 每例给出主结果和证据标记：`input_unverified`（公开恢复条件未核验）、`encoding_readout_limited`（观测编码读出受限）、`retention_candidate`（跨时可提取性下降）、`consequence_mismatch`（可读几何未转化为正确后果）、`readout_candidate`（替代冻结读出改善）、`selector_error`（选择实现不符）或`unresolved`（解释未分开）。这些可并存，不能强迫每例只归一因；具体门限按开发验证登记，当前不生成诊断标签或宣称失败。成功案例同样完整保留。只有在信息充分、接口合格、训练预算内充分性得到检查、且跨独立家族重复后，才据此选择一个SH-06改进点。

### E0公开几何恢复（D-076提案、D-078并行工程；结果见LOG-110）

白话：本职责检查不读取答案时，旧RGBD究竟能把门边定位到多窄的范围。输入全部合法历史和共同相机规格，输出任意数量的开口候选、三条边的坐标区间及其像素来源。例如墙顶面像素旁边是更远的地面像素，门边应位于两条观测射线之间；它不等于根据红色识别门、不等于恢复完整三维墙，也不证明模型可以预测碰撞。活动配置为[public_geometry_parallel_v1.json](../configs/spatial_history/public_geometry_parallel_v1.json)，它保持D-076/D-077科学数值，另登记并行运维；原配置和[提案JSON](../configs/spatial_history/public_geometry_proposal_v1.json)保持原字节。以下描述已有实现，不预填服务器结果。

**观测语义。** 当前R2固定相机垂直向下，`observe`提供的相机到世界旋转为`diag(1,−1,−1)`；主要可见的是墙体水平顶面。深度按相机轴向距离解释，不能当作归一化射线上的长度；像素中心使用整数u/v和公开内参，不再加0.5。依据为固定`two_gate_physics.py::observe`以及[MuJoCo 3.3.7深度逆投影源码](https://github.com/google-deepmind/mujoco/blob/3.3.7/python/mujoco/renderer.py#L170)。所有世界共用的裁剪距离0.04/20 m由原参考的znear/zfar乘固定extent得到，作为公开传感器规格共享；恢复器不打开每世界XML。近/远裁剪附近及0深度标无效，不能当作表面或用于闭合边界。

反投影为`p_world = camera_position + R × depth × [(u−cx)/fx, (v−cy)/fy, 1]`。这一步把一个合法深度像素转到共同世界坐标，物理单位为米；相机移动由公开位姿抵消。恢复器先校验原帧合同和严格时间顺序，再核对旋转的每个元素与上述姿态相差不超过1e−6；不支持的姿态明确拒绝，不能继续套俯视公式。静态水平面、轴对齐矩形轮廓与理想已知标定是本工程算法的适用假设；不把它称为任意视角、动态场景或真实噪声下的通用建图。

**公开提取器接口为`public_geometry.recover_openings(history, public_sensor_spec, extractor_parameters)`。** [public_geometry.py](../src/spatial_world_model/public_geometry.py)只做无文件读取的标准库计算。三个参数中不允许世界/门类别、门数、高度、宽度、中心、固定A/B下标、私有mask或路径。原帧保留完整校验，但恢复运算只消费深度、图像尺寸、相机位姿和内参；RGB、本体、控制、goal不用于定位。来源使用该输入列表中的局部帧下标和像素行列，外层再映射原始下标；候选编号不带近/远门答案。输出可以为0、1、2或更多个候选，不能强制保留“最像的两个”。纯函数验证参数白名单和合法范围，冻结版本的逐值核验由阶段入口负责。

**私有评估接口为`public_geometry_audit.targets_from_xml(xml_text)`与`assess_geometry(prediction, targets, evaluation_parameters)`。** [public_geometry_audit.py](../src/spatial_world_model/public_geometry_audit.py)从已绑定的实际XML文本计算门边答案，再核对全部封存候选的唯一匹配、包含、宽度和中点误差；例如多恢复一个开口会成为额外候选，不能挑两个最接近真值的消除错误。它不生成公开候选、不选历史，也不执行物理；提取器不导入评估模块，评估数据不返回提取器。

| 步骤 | 确定性实施规则 | 保留的证据与拒绝条件 |
|---|---|---|
| G1 发现水平面 | 每帧有效像素反投影，按世界z排序；从最小未分组值开始，贪心加入使整组最大最小高度差≤0.0002 m的点，不用相邻连锁跨过总跨度。组高度区间为观测最小/最大值各扩0.0001 m | 不预给地面或墙高。每侧面片须有至少2×2像素支撑；超容差不自动增阈值，未归类像素保留计数 |
| G2 提出开口 | 按每帧、每个面组、每行从左到右枚举相邻的同面片段；每侧至少2个连续像素，中间至少1个像素，全部间隙像素均须有效，且各自深度超过对应射线与候选面高度区间的最远交点深度至少0.0002 m | 0深度、裁剪、较近遮挡均不算空隙。至少2个连续行的左右边区间共同相容，才形成行组，不按门洞宽度筛选 |
| G3 夹住三条边 | 左/右边各取顶面与较远背景的相邻像素；两像素的完整±0.5像素足迹均与同一顶面高度区间相交，再取相应世界x的外包区间并扩1e−6 m数值保护。前缘同理取较小世界y一侧，每个墙片至少2列提供顶面→较远背景的行边界，所有前缘区间须相交 | 不能把地面回投点的XY当成墙顶边界；图像外侧不当成物体边。三条边缺一则记未闭合观察，不凭矩形假设补齐 |

相邻行只在左右边区间存在共同交集时组成行组，前缘证据同时核对两侧，避免把错开的两个顶面配成一扇门。每条边保存全部支持帧/像素对及原始区间；裁剪或更近遮挡造成的未闭合观察单列为`incomplete_observations`，不补成候选，也不因正常局部视野自动判整批失败。已形成候选之间的矛盾另记`conflicts`，必须进入验收。G4只融合输出，不把想象/插值点回写原观察。

**区间的含义和例子。** 假设一张手工说明图中相机高2 m、顶面高1 m、fx=100、cx=31.5、相机x=0；相邻u=32/33的中心射线与顶面相交于x=0.005/0.015 m。取两像素足迹后的理想外包范围为[0,0.020] m，再按G3扩高度与数值误差。若u=33实际命中更低地面，其回投x会更远，不能直接拿来量顶面开口。这是公式说明，未运行物理或恢复器。区间是依赖理想深度及轮廓假设的确定性包络，不是95%置信区间；跨帧交集收紧也不代表获得独立观测统计证据。

**有效观察不等于全局自由空间。** G2只证明记录射线在该顶面高度处穿过，没有在那里先撞到表面；像素之间、视野外和被遮挡部分仍未知。开口顶面轮廓不能直接沿z外推成完整竖直墙，更不能证明物块整体可通过。未来地图/动力学若需要这种外推，须把结构假设与实际观测分别标注并单独审查。

**固定只读评估清单。** 每个原世界分别输入full全部121帧、A单帧25、B单帧65、recent两帧119/120，共16个查询、500个提取器输入帧；每个查询从空恢复状态开始。这是`4×(121+1+1+2)`的恢复计算清单，不是磁盘读取次数：原读取器每次先校验完整公共文件及全部历史，再返回切片。A/B只用于已登记的观测可恢复性诊断，不作为完整历史恢复器或后续合法检索的选帧提示。提取器只接公共文件的合法帧、共享规格和提取参数，不能接评估配置或完整提案JSON；运维层保存选择下标，所有16份预测文件均写完并封存摘要后才启动独立评估及私有XML解析。评估端按原manifest读取实际world.xml的门墙位置/尺寸，计算三条前缘真值，不按LL/LR名称给答案；不读取任务成功矩阵作为定位目标。来源核验可以预先核对私有文件字节摘要，但不能在封存前解析答案。这里是代码与进程输入边界，不宣称同机恶意代码的操作系统权限隔离。

full预期每世界恰有2个已解析候选，A/B各1个，recent为0个；数量只在评估端核对。评估须唯一一对一匹配全部候选和目标，不允许挑最佳子集忽略额外候选。匹配要求每个目标坐标落入对应区间，三个坐标区间宽度各≤0.025 m、中点绝对误差各≤0.0125 m，且真值顶面高度位于恢复高度区间；多解、漏检、误检或冲突均失败。recent全无候选表示未恢复隐藏门，不表示门不存在；四世界recent几何输出须一致，审计世界名不参与比较。A/B的单门匹配不能替代full的双门组合通过。

25 mm宽度与真值包含是本协议的工程精度要求，尚未经过实际数据选参；它们已蕴含中点误差≤12.5 mm，后者仅作复算一致性检查，不是第二份独立精度证据。作为尺度参照，固定传感器35°/64像素在约1 m轴向距离的一像素足迹约10 mm，两像素包络约20 mm；这说明为何不用亚毫米边界门。该尺度推导不进入提取器作为墙高，也不证明此误差已足以预测擦碰或送达；真实恢复若未达要求，保留失败，不按结果放宽。

**小型输入输出例（解析预期，未执行）。** 手工构造一个16×12帧，相机位置`[0,0,2] m`、四元数`[1,0,0,0]`、内参`[100,100,7.5,5.5]`；背景深度2 m，行3–6中左列1–5、右列10–14深度1 m，其余字段满足原公开帧合同。按上述公式，预期恢复1个候选，`coordinate_intervals_m`约为`[[-0.030004,-0.009998],[0.009998,0.030004],[-0.020003,0.000001]]`，顶面区间约`[0.9999,1.0001] m`，并保存8条左右边与10条前缘像素支持。手工解析真值`[-0.02,0.02,-0.01] m`及顶面高1 m应落入相应区间。这里的数值是可检查的公式例子，不是服务器输出、真实渲染或门恢复通过证据；对应检查尚未运行。

**同阶段工程检查与成本。** [public_geometry_check.py](../ops/spatial_history/public_geometry_check.py)已提供只读`capacity`及`run / verify / export`入口。`capacity`只列出可见CPU/RAM容许的1–16路范围，不创建阶段或运行查询；正式`run`仍重新核验。默认4个worker只并行16项公共查询，测试和私有评估串行；例如四个独立历史可同时恢复，输出仍按固定查询ID封存，这不是四个模型或四份新物理样本。总97项服务器检查为28项恢复、17项评估、21项入口、20项调度和11项资源；不重模拟。全部公共预测封存后才读取私有XML；失败/中断保存原现场并拒绝自动重跑。

登记预算覆盖`run`与首次成功`export`合计墙钟≤1800 s，二者各计入1 s收尾保守上界；阶段目录与导出报告合计≤64 MiB。每个进程的地址空间上限512 MiB，进程树RSS门为`(workers+1)×512 MiB`，默认4路为2.5 GiB，最多16路为8.5 GiB；启动前还要求额外512 MiB可用余量。白话：worker数只改变同一固定清单的并发调度，例如4路要求至少3 GiB可见可用内存，并不保证四倍速度。50 ms采样和存活进程高水位只作保守保护，不宣称连续精确峰值或资源预留。

`run`和首次导出的时间上界持久保存。导出内存保护采用该次登记worker数对应的树上限；回执分开记录已启动进程、未启动任务和缺退出回执，避免将清理故障写成未运行。回执和首次导出先写`pending`临时JSON，通过时间与内存收尾门后才发布；可选`verify`及相同报告重导出复用原worker登记，失败诊断不冒充预算或几何通过。全阶段前台运行，0新模拟步、0训练、0权重、0新划分。

验收须分开报告读取工程、算法完成、坐标包络/精度及各查询通过情况。即使全部通过，也只支持“当前理想俯视工程家族的两个开口前缘可从公开历史恢复到登记精度”；不更新旧报告中的false字段、不声称完整地图/物理预测/模型利用历史已经成立。该产物未来可作为E1几何读出的正向参照，进入PointWorld或简单动力学还须各自适配合同。

### SH-04-R4共同接口（D-079，规格冻结供审查，尚未实现）

本节及下方三份适配合同将D-074/D-075细化为首批可审规格；数值登记见[protocol_r4_v1.json](../configs/spatial_history/protocol_r4_v1.json)，数据分组见[DATA](DATA.md#r4-data)。`frozen_for_review_not_executable`表示本版本固定了比较规则，后续修改须另记原因和版本；不表示用户已经审过尚未交付的实现，也不构成下载、生成或训练命令。旧v1的49步、两世界、首帧检索、终点距离选动作及6 GPU小时预算不适用。

白话：共同接口解决“不同模型预测的不是同一件事”。输入是截至决策时的真实公开历史、一条拟执行控制和公开目标，输出200段的物块位置/接触概率及整段成功概率。例如相同的向前推指令在两种旧门洞下可以产生不同结果；模型不能收到LL/LR类别或实际执行路径。内部可用循环状态、空间网格或点云，不要求相互转换。

**一次查询的因果顺序。** `encode_history`按时间从空状态消费121帧；单帧更新使用刚结束的控制、对应位姿和观察。前缀诊断只能消费该前缀。`clone_state`将同一个决策状态分别提供给四条候选，`predict`只消费该候选的200段世界坐标速度，输出相对决策时刻0.1至20.0 s的结果；不输入其他候选的预测或真实未来，不把预测画面当真实观察回灌。模型可在推演内部使用自己的预测，但须记录来源。`read_state`只导出原生状态副本和公开对齐信息，探针不修改主体。重置、前缀分块/一次性一致、候选正反序不变、标签文件更换不影响预测、ID重命名不变均是后续必要工程检查。

公共帧维持原64×64 RGB、米制轴向深度、相机到世界位姿和本体字段。张量化时历史时间减末帧时间得到−12至0 s，控制时长保持0.1 s；RGB转float时除255，深度单独转float32并保留原float64源字节，0的有效性掩码独立，不转uint8或做按场景归一化。空间位置以米、速度以m/s，网络输入位置固定除1 m、控制除0.5 m/s；四元数先用原合同单位化约定，表示相同旋转的正负四元数不可造成不同几何。resize只用于原生视觉前端，必须保留全视野并记录插值/内参变换，深度几何始终从原64×64计算。ID、路径、摘要、split、语义A/B帧号、真值可见性与世界类型只留外层审计。

公开`domain_spec`为所有系统提供相同且跨家族固定的机器人外形/质量、速度伺服增益/力限、物块外形/质量、摩擦、重力、障碍厚度/高度和传感器约定，逐值引用D-071登记常量；这是本小试的已知物性假设。实例门位置/宽度/侧别、物块真实姿态、未来本体和真实接触仍不公开。后续若改变物性，必须另定哪些可观测，不能把本批常量权限扩成真值地图权限。

**共同任务头与监督。** 每个已学习系统从自身每步原生预测状态经两层256宽GELU读出位置3值及一个接触logit；整段状态经单层256宽GRU（Gated Recurrent Unit，门控循环单元）汇总，拼接公开目标后经256宽GELU层输出成功logit。输入宽度可随原生状态不同，新增参数逐项计数。PointWorld位置另直接由公开识别的物块点及其预测位移计算，共同位置头只作附加诊断，不替换原生点运动；接触/成功头同权训练。短语“共同”指语义、权限和头的容量规则相同，不表示共享训练权重。

主损失固定为三项等权：200步位置误差按0.1 m缩放后的坐标均方误差、200段接触的二元交叉熵、整段成功的二元交叉熵；每项先在一条轨迹内取均值，再按家族/世界/候选等权。白话：输入真实训练标签与预测，输出位置、接触和送达三方面的惩罚，例如全部预测无接触不能靠大量空白画面得到主任务合格；状态标签只在训练端算损失，不进入推演初态。任务梯度回传适配主体，不能称冻结原模型探针。原生辅助损失按三份合同另列，全部系统拥有相同的训练侧标签权限；实际选用的额外目标、外部预训练数据与成本必须列出，不能把任务相同解释为架构、预训练或监督目标完全受控。

主训练标签权限为训练家族的未来RGBD、物块姿态/位置、接触和整段成功；物块姿态仅允许生成训练侧刚体点流目标，不向主输入提供对象mask/身份。实际未来机器人运动仅用于评估控制误差。门坐标仅给独立几何探针及评估，不给主体几何损失。所有归一化统计只来自model_train；probe_train统计不能回流主体。验证只选登记配方，确认只评估。没有真实标签的字段不能补零；推理异常保留原因并计入完整注册分母。

**随机推演。** 每个已锁checkpoint对一个世界保存16条随机推演；确定性系统只计算一次并显式标为点预测。四候选共享对应随机流，同控制跨配对世界使用同一索引的流，流种子由训练seed和样本序号生成，不以world/family/布局摘要生成。最终位置为样本均值，概率为样本概率均值；逐样本任务结果保留，不能平均logit代替概率。近期2帧从空状态另算，等输入须给出同分布；这是同一已训练系统的信息消融，不冒称近期模型充分训练。原生预测状态在0/5/10/15/20 s及历史检查点保存schema、摘要和可再生引用，实际落盘范围见DATA，禁止只保存地图幅值图来代替状态。

### R4三份独立适配合同（D-079，planned）

以下是任务适配系统的设计，不是原论文复现完成。作者源码锚点沿用已有文献审查，当前又核对了关键forward/状态接口；固定链接随各项列出。每条适配交付时必须附上完整模块图、实际张量例、保留/替换的源文件清单、参数量、全部辅助损失及梯度路径、依赖/权重摘要、原生小样例工程回执。checkpoint原任务重评、任务适配及自建基础架构分别记录，不能凭新名字视为原作者系统。原生检查只用于排除接线错误，不能单独认证训练充分。

**D：DreamerV3离线世界模型适配。** 基于作者[e3f0224的RSSM](https://github.com/danijar/dreamerv3/blob/e3f02248693a79dc8b0ebd62c93683888ddaccfe/dreamerv3/rssm.py)，保留确定性循环状态、离散随机状态、观测后验、动作条件先验及两向停止梯度的KL约束；用作者JAX实现的世界模型职责，明确移除actor/critic训练调用，不通过loss乘0留下策略数据路径。首批从头学习，`deter=1024, hidden=512, stoch=32, classes=32, blocks=8`，其余RSSM标量按绑定配置原值列入实现manifest。RGB沿用原生图像分支，新增独立float深度+有效mask卷积分支（通道32/64/128/128，3×3、stride2、GELU），本体/相机经两层256宽MLP后与编码token合并。第一帧reset，完整121帧消费，无64帧截断；未来200步只调用控制序列imagine。E1导出观测融合token和`deter/stoch/logit`，E3导出同类prior状态；主任务头用deter与stoch展开拼接。未来RGBD只作训练侧观测重建/后验目标，不进入主开环轨迹。辅助为RGB均方误差、有效深度按1 m缩放均方误差，权重各1；dyn/rep KL系数0.5/0.1、free_nats=1。新增任务三项照共同合同，不训练策略/价值。

白话：这条路线输入完整历史及速度控制，输出循环状态推演和任务后果；例如两门在最后画面外仍可能通过循环状态影响成功分数。输入深度和状态任务头是本项目适配，缩小的已登记容量也不是完整DreamerV3训练复现。原生重置、动作晚/早一拍、固定动作与无策略依赖须先有服务器检查，未收敛不能记成记忆机制失败。

**F：FloWM连续相机与独立操纵控制适配。** 基于[c909c54的空间记忆实现](https://github.com/hlillemark/flowm/blob/c909c54a3d58ae240de03f5ebbec222d3e6b1264/algorithms/mem_wm/backbones/flowm/flowm_models_3d.py)，保留可见网格与图像token联合更新、门控写入、未见区状态及动态速度通道。首批从头学习3D文件中的平面空间记忆实例：49×49格、每格0.15 m、5个速度通道、宽256、8头、6层，覆盖相机移动中整个登记任务范围；RGB原64×64、patch8，增加同宽的深度/mask patch分支并相加。相机是俯视，原前向扇形FOV替换为由公共内外参计算的地面投影范围，保留“只更新可见区域”职责；遮挡/未知区由公开深度形成，不用geom分割。

相机位置变化按相邻公开位姿计算网格坐标变换，采用双线性重采样、越界未知mask和零填充，不做整数动作映射、不循环卷回出界内容。当前俯视家族只含连续平移；旋转接口须保留来源，非本批验证范围不称已支持任意SE(3)。速度通道推进也用无环绕移位，一格/0.1 s是登记的通道基速度，不是假称物块实际速度；通道混合和观测更新保持原机制。独立推头速度、dt、当前/预测本体经两层256宽MLP形成动作token，既不驱动相机变换，也不因未来相机不动而关闭物体动态更新。开环预测禁止target_seq写入；可用自己解码的预测token更新，必须单列，不能标成真实观测。E1/E3输出完整`[V,H,W,D]`地图、有效性mask和坐标变换；固定位置编码加注意力汇聚为256维供任务头，几何探针可读取完整地图。辅助RGB和有效深度重建损失各权重1，任务梯度进入主体。

白话：输入旧图、相机实际移动和另一路推头控制，输出随相机对齐的历史状态及动态后果；例如相机转移后近门留在记忆里，推头受阻仍需动力学预测。替换扇形视野和离散自运动、增加操纵动作是实质改动，不能称原FloWM零样本失败。原离散变换在整数平移测试中应与连续适配的重叠区域一致，越界不环绕；还须检查单次/分块历史状态一致、图外旧信息不被新视图覆盖、零相机位移不抑制非零操纵动作。关闭全部空间对齐只能作为另审消融，不能替换F主结果。

**P：PointWorld公开历史场景与受限控制适配。** 基于[0548482的BaseModel](https://github.com/NVlabs/PointWorld/blob/05484826dfef74cbe278a3974179a5a16705d35d/pointworld/base.py)，保留场景点/视觉特征、机器人点序列条件和点流预测器；不把121帧堆到只读取初始时刻的时间轴。公共前端按世界坐标累计历史静态表面，每个点保存原像素、视图、时间、有效/未知信息及外观特征；当前物块与推头由近期公开深度和已知外形做几何拟合、关联，失败记`perception_unresolved`，不用真值mask补齐。静态表面按0.01 m体素融合，点上限4096、机器人固定外形点512；超限采用空间最远点采样，起点为世界坐标字典序最小点，不按门位置或真值物块分配点数；实际保留的近/远门及物块支持只由评估端报告。历史像素特征随原观测点保留，不能给旧门挂上最近空白图像的特征。

PointWorld计划使用small-droid权重及原DINOv3 ViT-L/16冻结视觉特征；版本/权重字节锚点沿用文献登记。该路线带额外外部预训练，比较对象是完整适配系统，不能把与从头学习D/F的差异全部归于动力学结构。DINO资产权限、准确revision/hash、small-droid嵌入配置与原生前向仍须先核验；未落实记`asset_unverified`，不得换随机DINO或随意缩小网络后仍用P名称。新增线性任务层随机初始化、点流主体微调；官方主体尺寸由精确checkpoint配置决定，加载缺失/多余参数逐项报告，不能静默strict=false。

未来机器人点流由下方M的公开地图有限力近似执行器产生：计划速度先经过伺服/力限，再与观测到的障碍和物块发生近似接触；这一控制模块不是原PointWorld的一部分。P输入只拿该预测机器人路径，不拿实际路径，也不把M的物块轨迹当P主预测。按0.1 s重标定原10个未来点到1 s，一次10步、连续20个chunk覆盖20 s。每chunk起点来自上次预测点，外观特征按点身份传播，不从未来真实RGBD再编码；增加两层128宽的公开/预测点速度嵌入，依据相邻预测点位移得到速度后投影到特征宽度。该新增速度记忆改变原静止初态假设，必须登记参数/梯度和单步误差，不能宣称原版开环等效。

主物块位置为公开拟合物块初始中心加被其公开支持权重选中的点的预测平均位移；支持权重在决策时封存，不能由真值对象身份更新。接触/成功头读取全场景点/机器人预测的256维位置注意力汇聚。训练侧物块姿态把这些公共选点变为刚体点流目标，静态公共点目标为原位置，权重由公共关联形成；身份不确定的点显式mask。原生归一化点流损失（连同方差项）权重1、任务三项各1；本任务归一化只拟合model_train，不冒用DROID的单位/时间尺度。主轨迹训练必须包含由自身预测续接的全部20 chunks，可梯度检查点重算，但不以每chunk重置真值初态或detach全部跨chunk梯度替代全时域训练。E1记录公共场景、关联/特征及scene encoder状态；E3记录预测点、特征、速度缓存和机器人计划。M与P的机器人误差和P的场景动力学误差分列。

白话：输入过去看过的场景点及合法预测的推头运动，输出物块点未来位置、接触和送达；例如门几何正确但推头实际卡住时，先检查控制模块。继承原权重的10步点流预测并不自动支持200步接触，新增历史前端、控制模块、速度缓存与读出都要单独核验。P不与FloWM/Dreamer强制串联；任何混合系统仍是后续另审。

### R4信息充分主对照与评分（D-079，planned）

**L长历史预测器与R多帧历史检索。** 两者使用相同RGB/深度双分支编码器、原生4×4空间token（每帧16个，宽256）及6层8头、feedforward1024的时空Transformer；121帧共1936视觉token，不能先全局平均为一个门侧别。L保留全体历史token，R的可检索库包含同样全部公共帧。R固定采用观测覆盖检索：每帧有效非远裁剪深度投影到0.02 m世界体素，先选近期2帧，然后贪心选取相对已选集合新增表面体素最多的一帧，重复8次，分数并列按时间早者；选完去重后按原时间编码，最多10帧。该选择无需训练，不用实例门位置、私有可见性、语义A/B或别人家的标签；新增覆盖为0仍保留登记的选择规则，不自动补正确帧。两者使用同一结构的2层8头控制解码器和共同任务头，任务三项等权、从头学习、同配方搜索；200步控制解码因果掩码，不能用未来标签做query。R的像素/体素来源与实际检索支持留存，若必要门证据未被保留则单列检索覆盖失败。L/R是基础架构，不冠论文复现名称。其决策历史token、未来解码token供E1/E3诊断。

L/R每个视觉分支固定4层3×3卷积、stride2/padding1、通道32/64/128/256和GELU，得到4×4 token，RGB与深度分支逐位置相加；相机/时间/本体经256宽两层MLP加到各空间token，另加二维像素位置编码。模型的完整历史在决策前可双向注意，历史前缀读取须从对应前缀重算；E3第k状态只由已消费历史与第1至k控制形成。探针可变token输入按登记池化后读取，不能将所有未来token拼回早期状态。

白话：L直接保留全部旧图的特征，R从同一份完整历史找能补充空间覆盖的旧帧，再结合拟执行控制输出同一后果预测。例如检索可同时取两道门的旧帧，不限于首帧。它们用于检查现成的长上下文和检索是否已足够；检索未获得相关帧应记为检索环节问题，不能直接证明空间记忆必要。

**M观测地图加简单动力学。** 与P共享公共深度融合、当前对象拟合、机器人外形/物性和有限力控制模块；地图有可见自由/占据/未知三种状态，不把未知填自由或补两道真值门。E0开口只作前缘约束，不能单靠六坐标宣称完整地图。已观测墙顶面/边界按共同已知厚高形成平面刚体障碍，物块为圆盘、推头为矩形，质量/摩擦沿公开domain_spec；0.002 s步长、半隐式Euler、每步10次顺序冲量求解、恢复系数0、库仑摩擦。受限速度伺服力为`clip(kv*(v_command-v_pred), ±force_limit)`，接触联合推进物块与推头。白话：输入观测地图和控制，输出有限力推动的近似轨迹，例如推头受门阻挡时会偏离积分计划；这不是打开原XML重放真值，也不预设准静态“控制必达”。无拟合参数；求解与接触容差作为实现单元合同核验，禁止按确认结果校准。

M在0.002 s预测轨迹上用原任务语义计算整段成功，接触概率/成功概率为0或1的确定性输出，200个末点另存。原生公共几何不确定/运动进入未知区域则记未决并保留完整分母，不用真值填补。M若频繁未决应修查公共建图覆盖，不能删未决后称可用动力学基线。L/R/D/F/P均不得读取M预测作额外主输入（P只获上述合法机器人路径），日后单侧模块替换另审。

**主评分。** 每世界选择成功概率最大的候选，数值完全相同才为并列，均匀分配计算期望真实失败代价；不按名称或真值破平局。代价为1−实际整段成功，regret为该代价减四候选真实最优代价。以家族内4世界等权平均regret为主指标；同时报告期望成功率、有效预测覆盖率和未决/工程失败。任一候选预测或标签无效，该世界主regret为null；额外报告完整注册分母上的失败代价上下界，缺失贡献分别取0/1，不能用条件有效集均值隐藏失败。

位置报告200步平均欧氏误差、末点误差和D-075同控制配对差误差，单位米；给出5/10/15/20 s分段及物块不可见采样子集（可见性仅评估端）。接触报告区间Brier、0.5阈值下正区间召回/负区间误报、整分支“至少一次预测阳性”的检出率/误报率、首接触误差和真实接触段匹配（允许±1个0.1 s区间）。`max(p_k)`只用作是否有预测阳性事件的分数，不称全程接触概率；不采用独立性乘积。真实无正例时召回记null并给分母，不能记1。成功另报Brier与0.5阈值正确率，不能以位置好推定按序过门/停稳标签正确。

白话：评分输入封存预测和真实结果，输出动作代价以及时间上哪里偏离。例如长期预测无接触即使Brier很小，也会在正区间召回和分支检出上暴露；这些是互补证据，不是把一个低误差数字当世界模型通过。首批“登记范围内足够”的描述门为家族平均regret≤0.05、位置平均误差≤0.05 m、接触Brier≤0.10、正区间召回≥0.90、负区间误报≤0.10，且注册有效覆盖=1；所有seed逐一报告，门值只用于有限范围描述，不等于统计证明或新机制门。

### SH-04-R2 双门空间证据候选（D-070/D-071工程协议，运行证据见LOG-108）

用户已认可双门四世界/四候选及真实送达任务（D-069），并接受本节全部数值、信息判定与工程预算（D-070）。下列合同已有独立实现，实际工程验收与审查证据统一见EXECUTE的LOG-108；本节只维护方法定义，工程通过不等于批准模型训练。

以下为已认可的概念方向，尚无新模拟结果。**先检验跨视角整合，不把延长几秒历史当作长期记忆实验。** 输入是分开观察到的两处门洞、共同近期观测及预先固定的机器人控制；输出是真实执行后物块的轨迹、接触与到达情况。例如第一段旧观察只见近门，第二段只见远门，两者共同决定哪条控制可能把物块送过两门。这不是已证明的新机制，也不是论文级泛化任务。

**场景定义。** 保留一个圆柱物块、一个有限力平面推头和静态障碍。在前后两道横墙各留一道门洞，每道门洞可偏左或偏右，组成左左、左右、右左、右右四个世界；第一字表示近门、第二字表示远门。两门后方设共同目标区。候选控制也有四条，分别意图从上述四种路线经过；输入仍只有每段末端速度与时长，四世界使用完全相同的候选库、时长和力限。路线名称仅供人读，模型消费数值指令，不读取真实物块路径或执行后机器人运动。

原两世界/两动作合同不能直接容纳这个构造；所选方向需要独立的新家族合同及审计，保留原SH-01至03接口与回执，不能仅修改旧计数后冒充旧测试已覆盖。这里选择四个候选是为了让近门与远门都有机会改变最佳动作，不是开放动作策略或主动探索。

| 观察条件（均须真实渲染核验） | 可获得的信息 | 仍不能分清的世界 |
|---|---|---|
| 单取历史视角A＋共同近期 | 近门位置，远门不可见 | 左左/左右，或右左/右右 |
| 单取历史视角B＋共同近期 | 远门位置，近门不可见 | 左左/右左，或左右/右右 |
| 仅共同近期 | 物块与推头当前观测，两门均不可见 | 四世界 |
| 完整合法历史＋共同近期 | 两段局部几何及其相机位姿 | 拟允许恢复两个门的位置；尚未验证 |

相机沿四世界共用的连续路径采集A、B及转场，随后回到共同近期视角；A/B只是说明名，不输入答案标签。门洞信息通过真实RGB、深度和位姿获取，不能复制公共帧、盖像素mask或用私有分割制造观测相同。本版固定采用下方局部俯视的有限视场，不设置实体遮挡屏。采集顺序和证据时刻独立于门位变化；全部转场参与检查，不边看结果边增加变体。

**可识别性审计。** 它解决“单张图是真缺信息，还是模型没学好”的区别：输入同一观察规则下的完整公开字段，输出不可区分的世界组，再检查组内同控制的真实后果是否不同。例如左左与左右在A及共同近期完全相同，却可能在同一左左控制下分别通行、卡在远门。这是有限构造的信息检查，不是学习结果。

- 等价比较包括RGB、深度/有效位、相机内外参、时间、本体状态、过去指令、候选控制和目标。不能只比较RGB而忽略元数据。除A/B外，每个转场帧也检查其区分能力；出现一帧能确定两门就不能声称任意固定单帧都不足。
- 不能要求同一对世界在**每一帧**都完全相同、却要求完整历史分辨它们。应使用上表交叉的多世界分组；单取A和单取B对应不同分组。
- 真正的后果标签只能由物理运行产生。对意图左左的控制，概念预期为左左通行、左右在远门受阻、另两世界在近门受阻；**这不是已经成立的接触矩阵**。卡住、滑脱、绕过和擦碰均原样记录，不能按路线名称生成标签。
- 单视图可能足以判断某条路线必然失败；本候选只拟证明单视图整体上不足，不承诺每个输入、每条控制都必须联合两段证据。
- 仅证明完整历史各不相同仍不够。须从公开RGBD/位姿恢复门洞几何，并检查观测地图＋动力学是否能支持后果预测；真值地图和真值初态单列诊断。记住不同截图的类别不等于形成可用空间状态。

**检索边界。** 固定只取一帧的输入不足，不适用于“先读完整历史，再决定取哪一帧”的检索器：选择过程本身能整合历史，选中的帧或位姿也可能传递信息。例如先检查两个门，再选择一张特定旧图，已经使用两段证据。合法自适应检索及取回两张互补图都保留为强对照；其成功不能被改写成无效捷径，更不能为了逼它失败不断增加场景。

**已认可的任务含义：在共同时间预算内，把物块实际送过两门并留在共同目标区。** 擦墙仍到达可以成功，无碰撞但推头滑脱、物块没到仍失败。成功区域、物块须全部越过的边界、停留时长、速度容差与统一控制时长按下方冻结数值执行；不沿用0.5 m半径，也不预填模型准确率门。碰撞单独记录，不自动作为惩罚。

动作选择价值与后果差异分别审计。令任务失败代价C为未满足所选任务定义时取1，否则取0；对同一公开输入对应的世界组G，在事先声明的世界权重下，计算：

`min_a E[C(w,a) | G] − E[min_a C(w,a) | G]`。

白话：这比较“分不清是哪一个世界时能选的最好共同动作”与“知道世界后逐个选最佳动作”差多少；输入是真实执行结果，输出因缺信息不可避免的动作损失，它不是任何模型的实验分数。若为零，即使碰撞标签不同也不能证明历史对动作选择有用。真实终点距目标区的差值另报，避免所有失败都被压成同一分数；不把未批准的多项加权和悄悄变成主评分。

若四世界等权、每世界恰好只有对应候选通行，固定单门视图最多能在两个可能世界中选对一个，完整信息则有机会选对全部；这是**以未验证物理矩阵为前提的组合推论**，不是预计模型成绩。不能由路线名称推出12条一定碰撞，也不能用总接触准确率掩盖类别不平衡；应分报实际正负分支、漏报、误报、接触时序和轨迹。若真实最佳动作无须两段信息，本构造的动作选择主张不成立，不加碰撞罚项制造成立。

**物理可行性与结论边界。** 原推头宽0.30 m、物块直径0.14 m；门需允许推头通过，不能只检查物块尺寸。冻结门宽0.38 m、左右中心±0.12 m、前后间隔1.60 m，替代概念草案的间距估计。原推面不转向，中途横移可能让物块滑脱；错误路线也可能沿墙滑入门洞。不能通过锁定物块运动、读取真值追踪控制或临时增摩擦来实现画出的路线。若此构造失败，应先呈现失败，必要修改或换设计由用户审查，不自动扫参。

工程审计保存全历史与未来采样的真实可见性，并在实际接触物理步补查；这才可区分“接触发生时不可见”与“整个未来不可见”。来源、相同非布局初态、独立恢复、反序重放、有限力、物块高度/倾角和全部动态物体接触均重新检查；不能把旧的恰好两条碰撞、49步、两个候选等固定断言直接用于新场景。

四世界与四控制仍是有限类别，最多证明存在互补信息需求。若工程通过，正式协议另审连续门位/净宽/间距、控制幅度/时长及未见组合；不能只给四种布局换颜色、加帧或扩样本就升级为论文证据。完整历史预测器、循环状态、合法检索、观测地图＋简单/较强动力学继续比较。若强方法足够，接受“该构造不需要新机制”；长期保留及复杂操作不在本次场景选择中自动加入。

0.25是四世界有限设计中“一例实际失败差”的最小非零均匀粒度，不是从未来结果挑出的显著性门；每世界有成功候选时，完整真实信息的最佳代价为0。必须报告全部逐帧信息损失而非只选A/B。这里固定单帧指同一次决策的全部候选查询共用同一帧；若不同候选分别取不同旧帧，整个决策已使用多帧，归合法检索，自适应检索也不受此下界约束。R2工程通过仍只满足必要条件；从公开RGBD恢复两门几何的正向对照在R3另实现，并在R4用同一观测地图检查动力学。未完成这两项，不能宣布“完整历史足够”或把模型失败归因于空间整合。

#### R2 实现与证据分层（已实现，服务器验证pending）

白话：把“怎样读输入”“怎样推进物理”“怎样判断结果”分别实现，避免生成器按路线名自填答案。输入是冻结参数和真实记录，输出是公开查询、原始执行文件及逐项审计；例如物块擦门后成功送达，任务为成功，但若穿透超过5 mm，整条分支的物理证据仍无效。这不是模型训练或新架构验证。

实际任务的几何结果保存为`raw_task_success`；物理无效时`task_success=null`，同时保存失效条件、首次失效步和物理极值。汇总可保留原始布尔矩阵及其信息数值供诊断，但明确`information_is_valid_physical_evidence=false`，不得把它当正常任务失败或单帧下界证据。运行异常则没有完整任务结果，不能补成false。

每个世界另保存首帧、A/B和近期真实PNG；每次执行保存末帧及一张私有俯视图。私有俯视图使用固定相机`(0,1.3,3.2) m`、wxyz=`(1,0,0,0)`、视场65°，仅帮助人查看门与物块；它不增加采集路径、不参与控制，也不进入公开帧、未来传感器数组或模型输入。独立重放仍比较这些原始图的字节。

### SH-04 首轮视觉对照协议 v1（proposed，尚未实现或授权训练）

**历史提案，D-068已要求修订；下列数值不得直接执行。** JSON状态为requires_revision_not_executable。保留原说明以便对比本次变更，不将其当作当前冻结基线。

白话：原v1拟判断“简单读回旧图、或从旧图建图后模拟，是否已经足够”。输入真正的历史RGB/深度、标定与机器人控制，输出未来49个时刻的物块位置和接触概率，再比较所选动作的真实后果。例如早期看到左墙，近期墙已被遮挡，模型应预测左推受阻并选择更接近目标的候选；这不是给模型墙坐标或物块未来变换，也不是立刻提出新记忆机制。机器提案`configs/spatial_history/baseline_protocol_v1.json`已由D-068标为待修订，不能启动其生成或训练。

**任务可识别性。** 首帧已经揭示布局，因此“取回第一帧”必须成为强对照；两种历史长度只有15/25帧，当前不主张长时持久记忆。墙始终只有两种左右布局、控制只有两个固定序列，成功也可能主要来自视觉识别与插值，不能称为任意动作动力学或通用世界模型。未来画面中的目标可能仍被遮挡，故未来图像/latent重建误差不能代替物块后果误差。

**视觉编码。** 拟固定DINOv2 ViT-S/14无register版本，官方代码修订`7764ea0f912e53c92e82eb78a2a1631e92725fc8`，公开权重地址写入JSON；下载后先形成权重SHA和依赖锁，当前不填假摘要。它是输入图像、输出局部视觉特征的冻结编码器，不是动力学模型；例如每张224×224输入得到16×16个384维patch特征，仍保留空间位置。选择S版是本轮预算选择，不称为完整复现DINO-WM。实现与维度依据[官方模型定义](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/dinov2/models/vision_transformer.py)及[官方加载接口](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/dinov2/hub/backbones.py)。

64×64原RGB先除255，双线性全图缩放224、align_corners=false、antialias=true、不裁剪或随机增强，再用均值(0.485,0.456,0.406)/标准差(0.229,0.224,0.225)归一化；均值/方差来源为[官方变换](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/dinov2/data/transforms.py)，全图缩放是本协议选择，不照搬其分类裁剪。放大不会增加原始信息。深度/投影仍用原64×64内参，不把放大RGB内参与原深度混用。每个视觉patch另附对应4×4原深度块的16个米制值和16个有效位，深度除2 m；无效值填0并保留mask。所有主方法允许相同RGB、深度、相机/本体信息和公共固定机器人/物块尺寸与物理常数，不能一方用真值地图另一方只有图像。

**学习目标。** 拟议预测器直接输出决策后0.1–4.9 s的49个三维位置和49个接触logit；训练标签来自真实执行，仅训练集标签参与梯度。位置损失为坐标除0.1 m后的均方误差，接触损失为逐时刻二元交叉熵，两项等权、均按有效元素取平均。白话：输入预测和真实未来，输出位置偏差与接触判断的惩罚，例如差10 cm不能因未来图像仍是屏幕而得零损失；这不是把未来真值塞进预测器。该监督比纯未来视觉特征损失更强，必须明确标为本任务的监督适配。[DINO-WM原文](https://arxiv.org/html/2411.04983v2)预测冻结patch特征并以目标图像规划；本任务的状态头、深度输入和固定候选评分改变了条件，不能把适配结果写成原论文复现或原方法被证明失败。

| 主对照（均planned） | 输入→输出、具体用途与边界 |
|---|---|
| 短历史 S | 仅最后2帧及相同控制→49步位置/接触。检验缺历史时的基线，例如两世界查询相同；它不是主要竞争方法。截取发生在特征读取前，禁止通过全历史缓存统计泄漏 |
| 完整历史 L | 全部15/25帧，无抽帧→同样输出。检验直接长上下文是否够用；它不是显式地图或新机制 |
| 首帧检索 R | 从已有历史固定取首帧与最后2帧→同样输出。例如直接保留已知揭示时刻，检验廉价检索能否解决；这是针对固定采集路径的强检索基线，不宣称通用检索算法 |
| 观测地图＋准静态动力学 M-QS | 全历史RGB/深度/位姿→估计墙/物块几何→控制条件轨迹/接触。忽略惯性但包含推杆–墙、物块–墙和推杆–物块碰撞；不是读取私有布局或只用直线穿墙的弱对照 |
| 观测地图＋重建物理 M-PHYS | 同一观测地图和估计初态→独立MuJoCo实例预测。同样使用公开固定尺寸/控制器/物理参数，例如从旧图恢复墙位置后模拟两候选；不加载真实世界XML、积分快照、墙坐标或实际未来机器人运动。它检验地图搭配较强动力学，不把真实环境查询冒充模型预测 |

S/L/R使用相同网络与训练预算：patch输入线性投影128维，固定二维patch位置及相对时间编码，4层历史Transformer（4头、前馈512、dropout0.1），2层控制序列decoder，49个控制查询。历史encoder可读取全部合法过去；decoder只读截至所预测时刻的已计划控制前缀和历史，不能输入未来观测或teacher-forced物块真值。控制为原速度与持续时间，机器人状态为决策前观测；同一模型分别查询两候选。全patch保留，不先全局平均成一个视觉向量。具体张量顺序、mask、初始化与可重现依赖须在可审实现中锁定；本提案不冒充已经实现。

M-QS与M-PHYS的地图共用原分辨率RGB色彩筛选和深度反投影：已知红墙/绿物块任务颜色只用于像素规则，不读实例分割；拟合已知尺寸的轴对齐墙盒和圆柱中心，机器人位置/速度用公开本体输入。墙左右编号不作输入，亦不直接套用±0.33 m真实坐标；输出拟合残差及未知区域，不把未见处一概设空。准静态模型拟采用10 ms积分、推杆速度积分与非穿透投影、零反弹、每步最多8次接触投影；训练集仅选择推力传递系数{0.8,1.0,1.2}，其他常量与主方法共享。像素阈值、几何拟合及接触投影顺序仍须作为单一职责实现审查，不可等看到确认结果再补。两种动力学必须同时报告，避免把简单动力学不足错归为空间历史不足。

真值诊断单列：分别把真值地图、真值决策初态替换进同一个地图预测器，保持其动力学不变，用来区分感知/地图误差与动力学误差；这不是公平主输入，不参与主方法排名。将同一真实成对记录的完整历史换成另一世界的合法历史、保持共同近期和控制，预测应对应另一世界后果；此检查只复用已存在真实历史，不合成物理上不可能的轨迹。若只会认左右仍可通过该检查，因此不单独作为世界模型证据。

**统一动作评分与读数。** 动作代价固定为终点到原goal中心的欧氏距离（米），不使用半径命中率，也不增加碰撞罚项。预测器按预测终点距离选动作；差≤1e-6 m时按展开控制数值的字典序选，禁止按世界/样本编号破平。真实regret为所选动作真实距离减去两个候选中最小真实距离。白话：例如两个候选最终距目标30 cm和8 cm，选前者损失22 cm；这不是模型自己的预测分数。goal字段和物理任务不改，评分是事前声明的新评估定义。

同时报告49时刻平均三维位置误差、终点误差、逐时刻接触Brier分数与0.5阈值分类、成对终点正确率（同动作两个世界终点误差都≤5 cm才正确）、成对动作选择与真实regret。Brier是预测接触概率与0/1事件的平方误差，例如自信地错报碰撞惩罚较大；不只看不平衡事件的分类准确率。先按家族等权汇总两历史长度/世界/动作，再汇总家族；逐例失败全部保留。8个固定确认家族只作描述性插值小试，不给总体泛化置信区间。

**选择与停止。** S/L/R各使用AdamW、权重衰减0.01、学习率仅{1e-4,3e-4}、种子{17,29,43}，每次1500个optimizer step，microbatch1、累积8个同家族查询再更新、梯度范数裁剪1；家族按种子洗牌循环。每100步评估validation，按“位置误差/0.1 m＋Brier”选择checkpoint；先以3种子均值选一个学习率，再保留该学习率的全部3个checkpoint，不挑最好种子。共最多18次训练，不因负结果加参或加模型。M-QS的3个系数只用train标签选定，M-PHYS不调物理参数。

一个强主方法（L/R/M-QS/M-PHYS）在确认集达到成对终点正确率≥0.90、Brier≤0.10、平均regret≤0.02 m，就判当前小试不足以支持增加新记忆机制；学习方法须分别报告全部种子，并以三种子平均判门。未达门也不自动支持新机制：必须先排除视觉编码、地图恢复、动力学和训练未收敛，在同一冻结checkpoint的逐例错误中定位；只有S失败完全不够。该门是小试的实用充分性标准，不是论文显著性或研究目标成立的判据。

| 对照/诊断 | 输入、输出、例子及边界 |
|---|---|
| 短历史预测器 | 共同近期观测加控制→轨迹/接触；两种隐藏墙对应不同答案时它缺信息。只检验信息不足，不是新机制的主要对手 |
| 长历史预测器 | 全部合法历史加控制→同样预测；必须真正看到早期揭示帧。例如能从旧帧读回左侧墙，不因抽帧遗漏造失败 |

| 地图加简单动力学 | 同一历史深度/位姿形成地图，固定或仅在开发训练数据标定动力学→未来轨迹；检验现有几何/碰撞办法是否足够，不偷读完整真值地图 |

| 拟议读数 | 作用与例子 | 边界 |
|---|---|---|
| 成对结果正确率 | 同一动作两种布局后果均对才成功，例如甲受阻、乙通过 | 不用逐例多数类准确率替代；阈值待固定 |
| 遮挡期间轨迹误差 | 比较预测/真实位置随时间偏差，例如终点对但中途穿墙 | 不等于图像清晰度；采样间隔须报告 |

| 动作选择损失 | 所选动作真实效果与同一候选集最佳效果之差 | 不是模型自己的预测分数；目标与代价待固定 |

相关结构改变应改变后果预测；无关历史变化不应改变预测。控制例均需物理一致的轨迹，不能拼接不可能发生的过去。整组成对布局、动作分支和关联家族不跨后续划分；按独立场景组统计。只有短历史失败说明缺信息；长历史/简单地图成功则不强行设计新机制。先定位观察、状态整合、动力学、评分哪个环节失败，再决定后续改动。

### 第一职责批次：成对输入边界

`src/spatial_world_model/pair_contract.py` 只审计一个双世界记录并提取模型允许的字段：`audit_pair` 校验结构和成对条件，`model_input` 返回独立深拷贝，`audit_dataset` 检查一批记录且不按结果差异筛选。输入为 DATA 定义的 JSON，输出布尔诊断与 `history/controls/goal`。例如改变未来答案或配对编号不改变模型输入，而改变早期图像会改变完整历史输入；这不是物理重放、遮挡验证或模型训练。示例 `data/fixtures/spatial_history/manual_pair.json` 明确标为手工夹具，假设的未来坐标不是模拟结果。

验证器始终输出 `physics_and_visibility_verified=false`。分支 snapshot hash 相同只说明记录声明了同一基础状态；下一批须真正保存、恢复和重放快照。字段白名单只能排除显式隐藏字段，无法证明像素没有被编码答案；物理来源/遮挡/阴影/反射仍须独立审查。未显示历史差异或后果差异的记录照样返回诊断，不静默删除失败样本。

### 第二职责批次：固定物理工程夹具（实现，服务器验证及审查 pending）

`src/spatial_world_model/physics_fixture.py` 负责把固定场景、机器人控制和观察路径交给 MuJoCo，再保存真实传感器与可重放分支。输入是 `configs/spatial_history/physics_v1.xml` 和同名 JSON，输出一对世界、四条首次执行分支和四条独立重放。例如左墙世界执行左前推后应发生隐藏接触，右墙世界执行同一控制应通过；这是待检验的工程预期，不是已生成的成功样本，更不是已发现模型失败。没有随机采样、搜索成功场景、训练或动作选择器。

完整积分快照指 `mjSTATE_INTEGRATION`：恢复继续计算所需的时间、位置、速度、控制、相机运动输入与求解初值等，并绑定场景XML摘要；字段范围依据[官方状态定义](https://mujoco.readthedocs.io/en/3.3.7/APIreference/APItypes.html#mjtstate)。白话：它解决“第二个动作其实接着第一个动作的结果开始”的问题，输入某世界决策时完整状态，输出重新从该时刻开始的分支。例如两条候选各自恢复同一快照，再用新模型和新数据按反序重放；这不是只比较记录中的hash字符串。保存状态后进行观测也不能改变积分状态；重新计算衍生位置/接触后恢复积分输入，以避免额外观察改变求解初值。

工程门同时要求：原20项合同回归；近期独立渲染的全部公开输入完全相等、早期墙可见至少4像素、近期墙0像素而物块可见；两世界完整非布局积分状态相等；每个实际障碍接触步目标可见像素为0且至少有正接触；首次/独立重放的轨迹、终态、RGB和深度逐字节相同；左右墙的接触模式为受阻/通过和通过/受阻，同一动作的成对终点至少差0.05 m。物块高度限定0.02–0.065 m、倾角≤0.25 rad以检查这个平面任务没有意外翻倒，执行器力不超过已设上限。这些是固定工程场景的验收条件，不是学习指标或任意新场景通用的通过门。

可见像素检查解决“碰撞虽然发生，但模型其实一直看得见”的问题：输入模拟器实例分割图，输出目标/挡板可见像素数。例如有墙接触的每个0.002 s采样点均须目标像素为0；无接触不能自动通过。这不是解析坐标近似遮挡，也不证明连续时间或无限分辨率完全不可见。分割图/可见计数只供工程审计，不进入模型。

所有首次和重放分支先保存，再做断言；失败不换种子、不改变墙位置后悄悄续跑。该固定工程夹具不计入后续16对开发审计，不用于训练/选参/确认。工程测试通过后仍须审代码与原始画面；它不能支持任何新机制、泛化、实时性或动作选择收益主张。

## 研究问题与范围

完整方法是 Counterfactual Projective Memory Transactions（CPMT，反事实投影记忆事务），核心机制是 Counterfactual Transaction Learning（CTL，反事实事务学习）。唯一问题：**执行候选修订后形成的事后监督，能否比直接未来损失更可靠地学习在线世界记忆修订？**

白话：输入是旧世界记忆和新到达的观测，输出是保留、扩充或修订后的世界。环境结构和对象都在范围内：例如转过走廊拐角后把新墙面、地面及连接纳入旧记忆，或椅子移动后改位置且保留无关结构。这不是只识别图片，也不预设每个新向量都是新物体。

首篇只做 embodied spatial memory，固定 backbone、depth、pose、region proposals 和确定性候选器，允许固定/轻量投影。不加 learned candidate generator、主动消歧、动作策略、第二领域、端到端基础模型或大规模导航。executor、KL 损失和事务标签不能单独当创新。

新 M1 可以依据真实数据重构，旧 M1/S5 no-go 保留；阶段顺序和用户代码审查遵循 PLAN。重构不解封旧 test，也不预设 CTL 会获胜。

## 新观测怎样影响旧 latent

| 对象 | 定义与例子 | 边界 |
|---|---|---|
| observation region | 一次图像中的区域、mask 或 patch 支持，例如本次看到的墙面、地板、门口或椅背 | 不自带跨帧真实身份 |
| observation latent，z | 冻结前端对一次区域的编码 | 新到达不等于新实体 |
| world node | 系统维护的结构片段或对象的持久身份、几何、证据和版本 | 不限于可数物体；不从数据集完整真值图初始化 |
| canonical world latent，m | 节点从已归属观测形成的世界表征 | 不等于某一张照片或目标 ID 的哈希 |
| evidence / latent refs | 指向具体观测或表示的可追溯引用 | 合并引用列表不等于学会向量融合 |

一次观测可以支持旧节点、改变位置、揭示新身份或进入待定记忆。结构/引用修订与数值修订分别评价；旧 M1 主要覆盖前者。不能先把新观测混入旧向量，再决定它属于谁。

拟议数值流程：候选在不可变旧世界上独立分配证据、形成对应表示，仅选中且成功执行的版本持久化。实际数组/张量也不能共享可写缓冲区；缓存引用绑定内容 hash。撤回错误绑定、SPLIT/MERGE 后按登记规则重分配证据并重计算表示，不只修边而留下被污染的向量。此能力仍待实现验证。

白话：输入是旧档案和本次证据，输出是可追溯的新版本。例如误混了另一把椅子的特征，修复时检查证据归属和表示两层；向量变化幅度大不自动等于语义损伤，正确修订也可能改变表示。

## 环境结构的纳入与扩充（planned；D-061）

Structural latent（结构表征）要保留局部墙/地面等空间支持、描述特征、参考坐标、可见范围、证据及版本；连接关系在可审查结构中显式保存，具体 schema 仍待 R2。白话：输入旧结构记忆和转角处新到达的区域观测，输出已确认的新结构及它与旧结构的关系。例如走廊 A 后发现转角及走廊 B，可以保留 A、建立 B 并登记有证据的连接；这不等于把全图压成一个平均向量，也不等于相机一转就把墙判成移动物体。

| 情况 | 期望的记忆行为 | 必须保留的边界 |
|---|---|---|
| 原墙面从新角度再次出现 | 关联旧结构、补充证据；投影随视角变，世界结构保持 | 图像位置变化不触发世界位置变化 |
| 同一墙/地面更远部分首次可见 | 几何与关联证据支持时扩大该结构的已观测范围，保存新版本 | 不无限外推；未知边界不等于墙体终点或不可通行 |
| 转角后出现方向不同的新片段 | 建立相连局部结构或子区域，记录相对几何与有证据的邻接关系 | 全局记忆扩充不要求强行合成同一平面、同一直走廊或单个 latent |
| 后续证据否定旧连接或发现重复片段 | 修订关系、拆开误合并或合并重复档案，重分配证据并复算表示 | 地图增长与纠错分开评价，旧结构离开视野不能直接撤回 |

候选语义仍优先在 BIND/BIRTH/RELINK/SPLIT/MERGE 等现有语言及基础操作中表达。关联证据是否更新几何支持、怎样表示局部结构连接、哪些断言属于可判断真值，须在步骤 07–10 明确；不能仅把旧 object 节点改名为 corridor 就宣称实现。结构提议仍固定/确定性，不增加 learned candidate generator；只沿记录轨迹更新记忆，不加入机器人动作策略或大规模导航任务。

可靠位姿和深度下可直接确定的几何增量，应先用确定性关联/融合形成基础对照，不能把累计了更多观测当作 CTL 独特收益。CTL 仍检验错误关联、重复结构、错接关系及不确定扩充候选的执行后监督；A–E 共享观测、结构前端和候选机会。完整离线重建只供单独审计，不能预先转成在线结构 latent。具体指标待审，至少区分结构覆盖、错误连接、重复片段、旧结构损伤和对象错误，未知区域不当作负例。

## 投影表示与视觉前端

Projective Node Orbit（PNO，投影节点轨道）是固定/轻量表征基础：输入世界节点 m、视角 T 和可见性，输出可与当前区域 z 比较的预测。

\[
z_{t,i}\approx\Pi(T_t,m_j),\qquad
\mathcal O(m_j)=\{\Pi(T,m_j):T\in\mathcal T_{\mathrm{reachable}}\}.
\]

这表示同一墙面或椅子换观察角度，仍应由对应世界节点解释；轨道不是机器人路径，也不要求生成未来 RGB。

前端拟保留 feature、support、depth、camera ray、pose、visibility 和 uncertainty。Local Structural Chart 指局部结构坐标表达：输入区域几何，输出可比较的局部坐标，例如转向时分别表达两侧墙面；它不把消失点直接当世界坐标，具体实现 planned。未知表面/不可靠几何应输出 unknown，不能把未见背面当作不存在的反证。

固定 DINO-family 的具体 checkpoint、区域提议和投影/transport 规则在数据审查后选择。更强容量只在信息可用而拟合不足等具体诊断后提出，并给 A–E 同等条件。大型视觉语言模型不默认作事务决策核心，其输出也不能作未经核验的真值。

拟验证对照包括 Exponential Moving Average（EMA，指数移动平均）/均值、去掉区域几何、pose/depth transport 或 visibility，以及 PNO。输入相同观测，输出不同表示的跨视角表现；它检验收益是否来自表征，不能把全部改善归于 CTL。

## 事务、生命周期与原子执行

事务输入旧世界和证据，输出合法新版本或原子拒绝。例如 RELINK 移动同一身份，REPLACE 则建立另一个身份，二者不是同一修改的两个名字。

| Intent | Template | 语义 |
|---|---|---|
| PRESERVE | NOOP | 持久世界不变 |
| ASSOCIATE | BIND | 给 candidate/confirmed 关联证据，不创建身份 |
| ASSOCIATE | REACTIVATE | dormant 身份打开为 confirmed 新版本 |
| EXPAND | BIRTH | 建立 candidate 身份；首次看见不等于物理刚出生 |
| REVISE | RELINK | 保持身份，关闭旧关系版本并打开新关系 |
| REVISE | RETRACT | 关闭被可靠反证否定的事实/边，保留身份与历史 |
| REVISE | SPLIT | 关闭错误混合身份，建立至少两个 successor，证据恰好一次分配 |
| REVISE | MERGE | 合并重复档案证据，保留 canonical 与其他身份的 alias 历史 |
| COMPOSITE | REPLACE | 有序 RETRACT→BIRTH→ADD_EDGE，保留旧身份，不偷换成 RELINK |

生命周期与版本结束时间分开：candidate 待确认；confirmed 已确认；dormant 暂不活跃但可重激活；retracted 已否定且不能直接复活；alias 指向 canonical。valid_to 只关闭一个版本，同一身份同一时刻至多一个 open version。

既有 D-019–D-025 约束需在重构时显式兼容审查：BIRTH 不自动 confirmed，升级由 program 显式执行；独立 BIND 支持可促成确认，重复 time/view 证据保留但不重复增加独立权重。SPLIT 不向 successor 直接复制旧 aggregate latent。MERGE 按最早 valid_from、再按 ID 排序选 confirmed canonical，其他 source 新版本成为 alias。普通 node-level RETRACT 尚未实现，不能把 visible-empty 当身份从未存在。

旧 M0 的可靠缺席要求至少两条不同 time/view 的 online visible-empty、有效 pose/depth、可靠度达标且中间没有正观测；新数据阈值另行审查。白话：遮挡、视野外、漏检不等于“那里确实空了”，不能一次没看到就删除身份。

Primitive operations 是程序的基础写操作：ASSERT_PRECONDITION、CREATE_NODE、OPEN/CLOSE_NODE_VERSION、ADD_EDGE、CLOSE_EDGE_VERSION、ATTACH/MOVE_EVIDENCE、SET_CANONICAL_ALIAS、SET_LIFECYCLE、RECORD_PROVENANCE。它们将事务编译为受检查的顺序，不允许物理 DELETE。

\[
S_t^{(u)}=\operatorname{Execute}(\operatorname{Clone}(S_{t-1}),u).
\]

每个候选都从同一旧世界独立开始，前一个候选不能改变后一个候选的起点。

Versioned Deterministic Executor（版本化确定性执行器）检查 base version、precondition、引用、intent/template、生命周期、保护范围、provenance、幂等性与原子回滚。同输入/config 得同结果 hash；无梯度、不读未来，失败不得半写入。它保证修改被正确执行，不保证模型选得正确。

## 暂存与保守等价

QUARANTINE 是低置信度提交 wrapper，不是世界事务。输入暂不足以提交的证据，输出独立 pending 记录；例如模糊椅背先保留检索线索，之后再关联。它不修改 persistent world；NOOP 是选择无需修改。

Pending Memory Manager 保留弱证据、粗略表示、来源、假设和独立性权重。只在相关且可能消歧的观察机会计数；多次仍未解决可归档但可检索，消费须保留全部 evidence 与 consumed_by_transaction。旧 M1 固定 gate 与新视觉策略分开，不把通用 wrapper 说明冒充旧运行实际策略。

Canonical memory-state equality 是保守状态相等：输入同一 base 后两份世界及允许的身份映射，输出是否相同。例如只改新内部 ID 名字可比较，证据归属或历史不同不能只因 active graph 相同就合并。

既有对应合同：锚定/未声明身份固定；exchangeable 身份仅在显式集合内双射；新 local ID 可重命名但不能映到旧身份。映射后生命周期、事实、版本历史、evidence/latent 归属、protected 与 pending 一致。未来投影相似只用于评分，不定义世界等价；评价可只比较可判断语义子集，但另报证据/历史差异。

## 候选与在线提交

确定性候选只读取允许的当前观测与自身旧记忆。合法外观、几何、证据配对可以使用；内部 ID 只作寻址，不把正确目标、真值颜色、参考事务参数或其哈希编码成 query。旧 M1 的 reference_spec→query→候选/编码通道不复用于新协议；只去掉学生的 merge_queries 不足以修复仍依赖它的候选器。

K、排序、去重、不可用槽位、完整/部分修复机会在新协议单独登记，不为保证正确候选出现而补答案。保护 scope/mask 的上游来源同样审查。

拟议部署路径：固定候选与静态预检→网络选择→执行选中事务→新版本；训练/评价审计可展开全部候选。旧 M1 共享生成器执行过分支做 canonical 去重，不能据“网络不读 post-world”宣称整个系统只执行一次。新旧候选、mask 和提交结果需等价检查，系统成本不能只记网络前向。

Global reconciliation（全局记忆协调）是 M2 明确保留的慢速修订：输入截至当前已积累的证据、版本历史与相关子图，输出同一执行器接受的跨对象/较长历史补偿事务。例如快路径把同一椅子建成两个档案，后续重访支持 MERGE 并修订相关关系；它不是主动寻找新视角，也不回填过去正确性。实现仍 planned，具体步骤为 PLAN 的 29a–29d，不能把该能力从 M2 完成清单省掉。

慢路径同时覆盖结构关系：例如后续重见证明两个局部墙面档案重复，或先前把新走廊接错位置，可在累计证据支持下提交补偿事务。这仍是 planned，不能只实现对象 MERGE 就宣称结构协调也已完成。

三种过程分开：离线事后教师利用训练序列中已知的后续观测形成监督；在线快路径用当前观测即时提交；在线慢路径利用截至复核时刻的累计证据重新检查历史。慢路径不能读取尚未到达的未来，也不自动等于在线更新网络参数。

慢路径先冻结触发、截止时间、历史范围、候选预算和失败策略。若后台计算期间快路径已改变 base version，提交前必须拒绝过时结果或按登记规则重算，不能覆盖新提交。恢复同时检查事实、证据归属和数值表示，旧错误及其持续时间仍留在评价中。

公平比较包括 A/C/E 各自有无同一慢路径规则，并记录实际触发次数、等待时间及全部计算。不同自身状态可能导致不同触发，不能伪称每条轨迹机会相同；必要时在配对快照上固定证据/机会诊断。快慢双路径本身不独立包装成 CTL 创新，额外证据和算力的收益不能全部归给监督机制。

## 事后教师与在线学习

Hindsight teacher（事后教师）输入执行后的候选世界及当前/后续观测，输出监督分布。例如后来清晰可见的空位支持关闭旧位置关系；它不是在线预知未来，也不是直接读取正确对象 ID 的对应器。

\[
E(u)=\lambda_nD_{now}(u)+\lambda_fD_{future}(u)
+\beta C_{edit}(u)+\gamma C_{growth}(u)+\eta C_{collateral}(u)+I_{illegal}(u).
\]

分别衡量当前解释、未来解释、修改量、增长、连带影响和非法性，一个总分不能代替六项记录。

now/future 对可用观测评分；edit/growth 属预登记正则；collateral 检查非必要范围的影响；illegal 排除非法候选。每项保存原始值、numerator/denominator、mask 和权重。visible-empty、occluded、out-of-view、unknown 分开。未来物体再次变化须用声明的推进/对应规则处理，不能重放正确后续事务，也不能暗用真值身份。

\[
p^*(u)=\frac{\mathbf1[u\text{ legal}]e^{-E(u)/\tau}}{\sum_v\mathbf1[v\text{ legal}]e^{-E(v)/\tau}},
\qquad \mathcal L_{CTL}=KL(\operatorname{stopgrad}(p^*)\Vert q_\theta).
\]

教师对更能解释观测的修订赋更高权重，学生拟合该比较；创新假设在目标从执行后世界形成，KL 只是实现手段。无合法候选须显式失败或执行已定义 wrapper，不伪造概率。

学生只读截至 t 的观测、旧记忆和候选，不读未来、post-world 正确性或真值。人工事务标签单列预算；多个有效候选按已审查集合标签处理，不强制唯一参考索引。新教师/标签规则待审，旧损失以原配置和源码为准。

## 对照、训练与评价

| 方法 | 监督职责 |
|---|---|
| A：CTL | 执行后候选世界形成当前/未来监督 |
| B：Direct classifier | 直接事务标签 |
| C：Direct + future loss | 不读取候选 post-world 的直接未来辅助目标 |
| D：Execute current-only | 执行候选，教师去掉 future |
| E：Future scorer without execution | 不执行候选 post-world 形成预测目标，学习未来评分并监督在线选择 |
| F：Oracle | 独立审计答案下的候选上界，不是可部署模型 |

A–E 共享前端、在线字段、候选机会、分组和合理参数/调参预算；C/E 有同等可用未来观测和合理容量。E 的额外 scorer、A 的执行、C 的辅助目标均计成本。相同学习率不等于充分公平。

训练顺序是开发组选参→锁定配置→完整训练/保存加载核验→独立确认。Teacher-forced 输入参考历史，自身状态 self-rollout 承受此前错误，分别评价；自身状态训练若使用，只来自训练数据并单独登记。

拟议标签效率为 0%/1%/10%/100% 事务标签：同一观测和固定语言/执行器下，输出不同人工标签量的表现。例如 0% 仍用未来观测和结构先验，不称完全无监督。

| 评价 | 含义和边界 |
|---|---|
| candidate miss | 实际候选无正确修订，不算学生错；未知答案另列 |
| teacher / amortization error | 正确候选存在时，分别检查教师和学生的选择 |
| 语义与证据正确性 | 位置对但证据绑定错另计，内部编号不同不直接等于世界错 |
| 完整/部分修复机会 | 撤错边却补不回节点只算部分机会，不推出所有多步路径不可能 |
| 错误持续负担 | 累计 extra/missing 事实，终点修好不抹掉前面错误；未知实际时间按决策次数计 |
| 无关损伤、增长、恢复 | 检查不应变部分、多余节点、恢复分母；无机会写 null，向量变化大不直接等于损伤 |
| 成本 | 完整系统时延、存储、教师/学生训练和实际失败 |

评测器读独立审计真值，不用教师能量作正确性。active-world、open-memory、历史 exactness 和程序索引分别解释；主要指标、安全条件、A−C/A−E 和多重检验在新确认前冻结，不直接套用旧数值。按场所/真实独立组配对，帧与 learner seed 不能扩充独立样本数。

A 与 C/E 无可靠差异时不支持执行后监督独特优势；覆盖低先查候选器，教师好学生差查学习，单步好连续差不支持长期记忆。教师分布变化不等于学生收益，表征改善不全归 CTL。负结果、歧义和失败保留，论文主张见 EXECUTE 的证据表。
