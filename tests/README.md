# CPMT Test Plan

定位：测试覆盖与待补测试规格；最近实际执行数量、是否通过及失败记录只写 [EXECUTE.md](../EXECUTE.md)。测试代码存在不等于本次已运行，也不等于方法有效。

test_vsmt_lean_memory.py 是 D-224 / S0-01 的合同测试：检查实体记忆的字段、状态机与版本链合法性，五个原子（NOOP/BIND/BIRTH/RETRACT/REACTIVATE）各有正例与反例，REPLACE 展开为 RETRACT+BIRTH 且两半都须合法，非法程序整帧回滚且调用者手里的旧记忆逐字节不变，共享 dormancy 与共享去重是确定性的且数值必须显式传入，实体 token 字段顺序与机器合同一致且不含私有或场景标识，帧级稀疏残差只列改动过的实体。白话：输入是手写的小记忆和帧程序，输出是通过或拒绝；例如 REACTIVATE 一个仍然活动的实体必须被拒绝且整帧不生效。它只证明机械语义正确，不证明 VSMT-lean 有效、数据已生成或任何数值已冻结。D-224-X 之后另检查：每个版本记录带 `opened_by` 且与快照状态绑定、首版本必是 birth、六种打开方式各有一例，篡改或删除该字段被拒；去重把被折叠 ID 归档进 `canonical_of` 并留日志；合同 v2 的折叠口径与 `physical_deletion_allowed=false` 翻转即拒。

test_vsmt_lean_intervention.py 是 D-224 / S0-02 的只读检查测试：检查 house 划分是 (seed, house_id) 的纯函数且三份互斥、清单被篡改即拒；路线只能使用八个登记动作且观察数等于动作数加一；三类干预的端点规则、每 episode 上限、同一物体不得被干预两次、窗口不得越界；干预窗口内每个相关容器每一帧都必须被判为不可见，判定缺失、缺少深度帧摘要或只是「假值」而非严格 False 都拒绝；三面文件互斥且部署读取器不得挂载 private 或 provenance；公开帧记录任何层级不得出现 house/scene/object/instance 等标识；失败 house 必须留回执且不得替换，计划数必须等于成功数加失败数。白话：输入是手写的划分、路线、干预计划与可见性判定，输出是通过或拒绝；例如源容器在窗口中间重新可见，整条 episode 必须失败而不是缩短窗口。它不生成数据、不调用模拟器、不读取 RGB-D，也不证明干预在科学上可构造。D-224-X 之后另检查：前缀分配顺序是 test→validation→train，改 train 规模不动 test/validation 成员，而改 test/validation 规模会挪动 train 块；合同 v2 的顺序与两条冻结声称翻转即拒。

test_vsmt_lean_assignment.py 是 D-224 / S0-03 的合同测试：检查冻结前端一帧的字段与几何合法性；活动实体召回受距离上限约束而休眠与已撤回实体不受约束；召回顺序不随记忆列表排列变化；三张特征表的字段顺序与元数一致；存在特征确实依赖分配结果，因此必须在求解之后计算；自写矩形匈牙利在 40 个随机矩阵上与暴力枚举的最优值一致、重复调用结果不变、行多于列或参差矩阵被拒；召回之外的组合拿到有限但极大的代价，两个色块不能共用一个实体，一个色块不能占用别的色块的新建列；只改私有数据时召回顺序、特征矩阵、封存摘要与参考分数必须逐字节相同，任何一项被改都会被抓到。白话：输入是手写的一帧、一份旧记忆和三个头的 logit，输出是通过或拒绝以及一次分配；例如两个色块都最像同一个旧实体时，只有一个能拿到它。它不训练模型、不读取私有数据，也不证明这些特征有用。D-224-X 之后另检查：等式子图上的字典序规范化与 v1 的逐列重解版本（原样留在测试文件里作参照）在 60 个随机浮点矩阵、60 个含哨兵与常数新建 logit 的规则臂式矩阵和三个 20～30 行矩阵上逐列相同，5 行以内与暴力枚举的字典序最优解一致，且整个求解只调用一次核心求解器。

test_vsmt_lean_arms.py 是 D-224 / S0-05 的合同测试：检查四个规则臂怎样填同一张 S0-03 代价表——余弦门内 logit 是余弦本身而不是常数、门外是登记的哨兵、d_a 为 null 时远处候选也合格、不承认复活的臂对 retracted 行给哨兵，LOW 最近实体得分最高且新建 logit 落在门上；并把规则臂送进真实的 S0-03 求解器：分级代价让余弦更高的色块拿到被争抢的实体，而平代价下改由行序决定；无门选项让 5 m 外的被搬动物体重新关联；全部不合格时只新建，哨兵永不被选；ELU-P 复活 retracted 实体而 RAC 只能新建。存在判定：候选按应可见下限与状态过滤并计数被排除者；TAF/LOW 恒 NOOP、AssocOnly 跳过；ELU-P 的 log-odds 在自由空间覆盖下跌破门记 RETRACT、匹配后回升；RAC 连续负渲染计数到 n_rac 记 RETRACT 并清零；学习臂按 sigmoid 阈值。编译：BIND/REACTIVATE/BIRTH 与 RETRACT/NOOP 各有正例，AssocOnly 出现 NOOP 或 REACTIVATE、TAF 出现 RETRACT、对已分配实体做存在决定、占用别人的新建列均被拒；NoVersion 物理删除 retracted 并重新封存。网格按登记顺序枚举，13 个配置被拒，规则臂距离门网格缺 null 被拒；LLM-op 只允许 validation；ctx 只在 amortization error 严格最大时准入。合同的全部布尔声称逐条翻转、缺失或新增均被拒，哨兵值、12 上限与 D-224 冻结的训练常量改动被拒，七个待冻结数值提前填入被拒，词表、网格参数名、规则臂梯度、附录臂划分与主表名单改动均被拒；填入网格值后自动检查预算与无门选项。白话：输入是手写的记忆、帧和各臂参数，输出是 logit、决定、原子程序或通过/拒绝；例如 TAF 在两个合格实体之间按余弦高低选而不是按 ID 顺序选。它不训练、不选参、不证明任何臂有效。D-224-X 之后另检查：预登记的 ELU-P `rollout_config` 必须是补上 d_a=None 后的网格成员，非成员即拒，网格冻结而它仍为 null 允许，填入它则触发待冻结规则；第 0 轮 DAgger 与 HeuristicLabel 标签都指向这一格；AssocOnly 与 HeuristicLabel 的重训声称、拟合程序的三条声称与九个待冻结数值均被绑定。复审修订（LOG-225）后另检查：`arms_without_atom("RETRACT")` 返回 TAF、LOW、AssocOnly，供 S0-04 的不适用规则使用，未知原子即拒。
