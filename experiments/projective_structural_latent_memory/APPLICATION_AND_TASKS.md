# 应用目标与下游任务

状态：候选，主任务待 HC-034。

## 1. 目标应用

优先面向重复访问、布局基本稳定但局部持续变化的室内共享空间：实验室、办公室、仓储通道或服务机器人区域。这里同时存在视角变化、遮挡、相似结构、移动物体和“旧事实已失效”的问题，适合检验长期世界记忆。

## 2. 第一主任务候选：时间限定结构查询

机器人在探索和环境变化后回答：

- 某目标最后一次可靠出现在哪里、证据是什么？
- 当前走廊/房间是否为已知位置，还是新区域？
- 某入口目前可见、被遮挡、已移除，还是状态未知？
- 某事实在什么时间区间有效，后来由什么证据替代？

评价包括事实准确率、时间区间、evidence attribution、abstention calibration 和查询延迟。

## 3. 次任务候选

- Memory-conditioned object retrieval：在目标移动、遮挡和重访后定位目标。
- Frontier-aware navigation：区分已知但暂不可见区域与真正未探索 frontier。
- Change-aware inspection：把“视角不同”与“世界发生变化”分开。

## 4. API 边界

下游 agent 只能通过只读接口查询：node、relation、valid time、confidence、evidence 和 visibility。它不能写入 memory，也不能读取 oracle-only identity。写入只能经 transaction executor 完成。

## 5. 防止任务绑架方法

- 第一篇论文只选一个主任务和最多一个次任务。
- 下游策略应尽量固定或简单，使收益能归因于 memory。
- 同时给所有 memory baseline 相同查询接口和规划器。
- 若任务收益来自额外语义模型而非记忆质量，必须单独消融。

## 6. 暂不作为首篇主任务

端到端语言导航、开放世界对象本体扩张、多人协作地图合并、主动探索策略学习和真实机器人全栈控制均推迟；它们会把绑定、生长、修订的因果证据淹没在系统变量中。
