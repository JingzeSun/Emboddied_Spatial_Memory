# CPMT Publication Gates

## 保留主 claim

必须同时满足：

1. M1 的 CPMT-CTL Core 在 A vs C/E 上通过预注册门槛；
2. graph correctness 与长期 contamination 改善；
3. growth/collateral/invariant 不恶化；
4. online student 保留 hindsight teacher 的有意义收益；
5. transaction-label reduction 有实证；
6. 一个 external/现实来源与 artifact 可复现。

只有在 M2 接入 Projective Node Orbit、world graph、executor 与 CTL 后，系统才称 Full CPMT；M1 A 不能借用该名称提前形成完整方法 claim。

## 降级

- 只有 Node Orbit 有效：representation work；
- 只有 executor/oracle 有效：deterministic system；
- 只有 future loss 有效：future-supervised association；
- 只有 simulator 有效：明确 controlled study。

## 停止

A≈C/E 且 CI 排除有意义效果时，停止继续堆模型。主动消歧、第二领域和端到端视觉训练不得被用来挽救失败的核心假设。
