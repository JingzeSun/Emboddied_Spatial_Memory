\section{Conclusion}
\label{sec:conclusion}

We tested a learned, versioned lifecycle vocabulary for object-level memory against the same learned association without it.
Under a protocol frozen before validation and test and a single test read, the answer for this training procedure (five seeds) is yes for near-ideal instance masks on both stale entities and identity continuity, and yes for stale entities only with SAM~2.1 masks; on ProcTHOR, a descriptive ablation ties identity continuity to keeping retracted entities' versions.
The low absolute identity continuity, especially with a learned segmenter, is the main open problem.

\textbf{Reproducibility.}
Every table and data figure is generated by scripts from the saved outputs, and a read-only re-run reproduced the test statistics value for value.
Four released layers serve to recompute every statistic (results and weights), re-run the evaluation (validation and test inputs), check training (training and audit records) and retrain without regenerating data (training inputs).
Weights are bit-identical for the same commit and thread count on the only hardware verified (Intel AVX-512 with MKL); the data generator reproduces episode structure but not every byte, and SAM~2.1 outputs were not checked byte for byte.
