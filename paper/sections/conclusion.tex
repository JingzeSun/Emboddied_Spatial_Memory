\section{Conclusion}
\label{sec:conclusion}

We tested a learned, versioned lifecycle vocabulary for object-level memory against the same learned association without it.
Under a protocol frozen before validation and test and a single test read, the answer for this training procedure (five seeds) is yes for near-ideal instance masks on both stale entities and identity continuity, and yes for stale entities only with SAM~2.1 masks.
In a descriptive ablation on ProcTHOR, identity continuity depends on keeping the versions of retracted entities.
The low absolute identity continuity, especially with a learned segmenter, is the main open problem.

\textbf{Reproducibility.}
Every table and data figure is generated by scripts from the saved outputs, and a read-only re-run reproduced the test statistics value for value; weights are bit-identical for the same commit and thread count on the hardware we verified.
