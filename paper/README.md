# Paper source

LaTeX source of the manuscript *Versioned Lifecycle Transactions for Object-Level Spatial Memory: A Pre-Registered
Evaluation Under Unobserved Changes*, formatted for IEEE Robotics and Automation Letters (RA-L).

Claims follow the claim scope of [docs/METHOD.md](../docs/METHOD.md) (section 2, ruling 113) and the sentence-level
wording audited in EXECUTE LOG-307 (A2, A4), LOG-308 and LOG-309. Every table and data figure is generated by a script
from the committed exports in `results/`; no number is copied by hand. [docs/REPRODUCE.md](../docs/REPRODUCE.md#2-paper-results-index-l0)
maps each table and figure to its file and fields.

## Versions

One switch at the top of `main.tex` selects the version:

- `\finalversionfalse` (default): the anonymous review version for RA-L's double-blind review. The author block reads
  "Anonymous Authors", and the GitHub and Hugging Face links read "link withheld for review"; the PDF metadata carry
  no creation date or trailer ID.
- `\finalversiontrue`: the final version with author (Jingze Sun, The University of Sydney) and all links.

RA-L limits (checked 2026-10-08 on the RA-L Information for Authors page): 6 pages plus at most 2 paid pages, with
figures, tables, references and appendices counted; text or figures cannot be moved to supplementary material
(which accepts only videos, data sets, code and documentation); every figure and table is numbered and cited in the
text. The manuscript therefore has no appendix.

## Build

From the repository root (MiKTeX or TeX Live; a per-user MiKTeX on Windows is found automatically):

```bash
python paper/tools/make_tables.py
python paper/tools/make_figures.py
python paper/tools/check_draft.py
bash paper/tools/build.sh
```

`build.sh` compiles both versions to `paper/build/vsmt_review.pdf` and `paper/build/vsmt_final.pdf` (the directory is
not tracked) and fails if a PDF has more than 8 pages, an overfull box or an undefined reference, or if the review PDF
contains the author's name, affiliation, e-mail or personal repository names.

For Overleaf, `python paper/tools/pack_overleaf.py` writes `paper/build/vsmt_overleaf.zip`; upload it with New
Project → Upload Project. Overleaf builds the review version by default. Tables and figures are always regenerated
here, never edited on Overleaf.

| `tools/build.sh` | builds and checks both versions |
| `tools/pack_overleaf.py` | Overleaf zip |
